# 多维估值与投资决策方法论

版本：2026-10-20。适用美股、港股、A 股公司研究；行业方法按主体选择。由用户提出的四维框架，经 Codex 核查、Claude 独立讨论后整合。四维问题嵌入既有五步研究流程，不另设相互冲突的评级体系。

这是一套决策纪律，不是已验证具有超额收益的策略。各模块须给证据、假设、反证和更新条件。名人观点只作思想来源，不能声称芒格、德鲁肯米勒与马克斯采用同一套公式、阈值或仓位规则。

## 1. 四维问题与交付物

| 决策问题 | 核心判断 | 最低交付物 |
| --- | --- | --- |
| 买什么 | 商业模式、治理、资本配置能否持续创造现金价值 | 业务驱动树、调整后 ROIC/WACC、增量投资回报、现金与债务约束、最大反证 |
| 什么价格 | 当前价格要求什么经营结果，内在价值对假设多敏感 | 财务调整桥、适用的主辅估值锚、反向检查、三情景、企业到每股桥 |
| 什么时候 | 自己的判断与已定价预期差在哪里，何时能检验 | 有日期的共识快照或明确缺失、差异变量、传导链、催化和失效日历 |
| 买多少 | 在估计错误、尾部损失和组合共振时能否承受 | 压力情景、风险预算、相关暴露、流动性与持仓上限、退出触发 |

四维是研究视角，五步是执行顺序：立论 → 取数 → 估值 → 对抗 → 收口。资产质量连接前两步，价格连接第三步，预期差连接第一与第四步，仓位与验证连接第五步。

## 2. 资产质量：资本回报、再投资与每股现金

- ROIC = 正常化 NOPAT / 平均投入资本。分子分母采用一致的研发、租赁、商誉与税务口径；负投入资本、资本基数过小时注明不可解释，不能把极高 ROIC 自动当护城河。
- 核心是未来投入资本回报相对资本成本的利差及持续期，没有适用于所有国家、行业、币种的“ROIC 必须超过 15%”。银行保险优先普通股回报与股权成本、监管资本约束。
- 历史平均高回报不保证新增项目高回报。增量 ROIC 可用跨数年的增量 NOPAT / 滞后增量投入资本近似，但须解释投产时滞、并购、周期与分母接近零造成的失真。
- 在回报率稳定、经营口径一致的简化条件下，经营利润增长约等于再投资率 × 投入资本回报率。增长预算必须同时解释资本开支、研发、营运资本和融资来源，不能只提高增长率。
- 每股价值还取决于股权激励、回购价格、稀释融资、并购回报、关联交易和少数股东权益。只看总利润增长会遗漏资本配置损耗。
- 低回报不必一票否决全部投资机会；清算、重组、周期反转作为独立事件框架处理，列现金消耗与退出条件，不混入长期复利公司评价。

增长与再投资的基础关系见 [Damodaran：增长的基本决定因素](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/growth.htm)。上述证据与行业边界为项目研究规则。

## 3. 估值修正：先桥接，再计算

### 3.1 研发与获客资本化

估值用经济重分类不改变正式会计报表。先核实公司已资本化部分，不能重复加回。研究阶段和开发阶段的会计要求不同，须读适用准则；[IAS 38 官方说明](https://www.ifrs.org/issued-standards/list-of-standards/ias-38-intangible-assets/)区分研究费用与满足条件的开发资产。

基础桥：调整后 EBIT = 披露 EBIT + 本期重分类研发 − 对应研究资产摊销；同时建立历年未摊销研究资产并计入投入资本，处理失败项目减值。寿命取决于产品迭代与收益持续期，3–5 年只能作为待验证假设。获客成本只有在 cohort 留存、增量毛利和回收期证据充分时才作补充视图，不能把全部营销费用资本化。

研发实际现金支出必须进入再投资，现金税依据当地税法与实际扣除时点单独处理，不能机械给调整 EBIT 乘税率后声称税务桥已完成。在现金税、经营预测和实际支出不变时，单纯重分类不会增加当期 FCF。调整后利润不等于 Owner Earnings；后者仍须扣除维持竞争地位所需的资本投入及营运资金，难以区分维护/增长开支时给范围。

方法依据见 [Damodaran：研发费用、盈利与估值](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/R%26D.htm)。这是经济分析视图，不是把研发支出直接认定为等额可变现资产。

### 3.2 方法适配与独立性

| 公司类型 | 主要锚 | 交叉检查与边界 |
| --- | --- | --- |
| 稳态盈利公司 | 正常化 EPS × PE、FCFF/FCFE DCF | 资本需求、现金转换、增长期限、可比公司溢价来源 |
| 多分部公司 | SOTP，分部按适用方法估值 | 分部总和与合并勾稽；中央成本、税、净债务、少数权益与非经营资产单列 |
| 高增长或暂亏公司 | 收入→毛利→成熟利润率→再投资的现金流模型 | EV/收入仅作辅锚，须连接成熟利润率、资本需求、融资与稀释；PEG 可能不适用 |
| 周期制造/资源 | 中周期盈利、资产/产能重置或现金流 | 盈利峰谷、负债、维护 Capex、成本曲线；不用峰值低 PE 当便宜证据 |
| 银行、保险、REIT | PB/普通股 ROE、保险分部/营运指标、FFO/AFFO/NAV | 行业专用资本与派息约束，不能统一套工业企业 ROIC 与 PE |
| 临床生物科技、早期项目 | 管线 rNPV、分阶段现金与净现金 | 成功概率、后续融资、失败回收和资金耗尽，不默认亏损业务有正期权价值 |

DCF、PE、PEG 如果共享同一套增长和退出倍数，不构成三份独立证据。正向与逆向 DCF 是同一模型的两个方向。交叉验证应至少包含不同约束的适用锚，注明共同假设，解释分歧，不机械取平均。

SOTP 混合企业价值与股权价值前先统一口径，再做一次股权桥；不得重复扣债或重复加现金。亏损业务要扣预计资金投入，不能同时在分部现金流中扣损失、又在集团重复扣。集团折溢价要有治理、税、资本配置或可比证据，不固定打八折。

### 3.3 逆向 DCF

固定估值日期、价格、股数、企业/股权桥、显式期、利润率路径、再投资约束、折现率和终值，才反解增长率等一个关键未知量。一个价格对应多种增长/利润率/资本效率组合，不能把解写成唯一“市场共识”。

同时列低/中/高折现率下的隐含增长或经营边界，与订单、市场份额、竞争、单位经济及市场容量核对。若无法求解或假设不可识别，写明原因。反解结果是“给定这些假设，现价要求……”，不是公司必然实现。

DCF 必须配对 FCFF/WACC 或 FCFE/股权成本，列终值占比与敏感性，继承主入口 >75% 的终值依赖提示。终值增长须有相应再投资；币种、通胀、名义/实际及折现时点一致。

## 4. 预期差、回报拆解与周期

当起末 EPS 为正、同口径且 P = EPS × PE 时：

`价格回报 = (EPS_T / EPS_0) × (PE_T / PE_0) − 1`。

这是价格分解恒等式，不能由此预测 PE 扩张。EPS +30%、PE 从 15 到 25，价格回报为 1.3 × 25/15 − 1 = 116.67%；若 EPS +30%、PE 从 60 到 25，则为 −45.83%。例子为假设演算，均非收益预测。未来 EPS 已体现回购或摊薄后，不再额外叠加回购收益。

不再投资分红时，总持有回报 = (期末价格 + 期间累计每股现金分红 − 初始价格) / 初始价格；分红再投资按实际时点计算财富路径。基准币种投资者另计汇率、税费和交易成本。起末盈利口径不适用 PE 时改用业务与现金驱动桥。

预期差卡必须写：市场证据/快照日期 → 自己的不同假设 → 量价/利润/现金传导 → 为什么可能未定价 → 哪个公开指标在何时能验证。卖方一致预期并不等于市场定价的全部；没有共识资料时写 [MISSING]，不能自己编共识。公开渠道信息与解读足以形成假设，不把内幕或未公开重大信息作为优势来源。

宏观作为条件情景：利率、信用利差、股权风险溢价、盈利、汇率和融资条件共同作用。降息可能来自衰退，盈利下修与风险溢价上升可以抵消无风险利率下降；WACC 不一定同步下降。历史低 PE 也可能是业务永久衰退。马克斯明确质疑依赖宏观预测，见 [Thinking About Macro](https://www.oaktreecapital.com/insights/memo/thinking-about-macro)；不能把不同投资人的风格合并为宏观择时定律。

## 5. 概率、赔率与尾部压力

先区分：**今日内在价值 V0** 为折现到今天的现金流价值；**未来情景价 P_T** 为 T 时点假设的交易价格。两者不能直接互当未来卖出价；用未来倍数估值时固定 T，DCF 模型需先明确价值时点。与 P 比较 V0 得到估值折溢价；与 P 比较 P_T 才得到该期限情景收益。

三情景共享期限、币种、股本、分红处理；每个情景把经营、融资与估值联动起来，不把“高增长、扩利润率、低折现率、高退出 PE”随意堆叠。分别列：经营驱动、利润/FCF、再投资、估值输入、每股价值、触发与证伪。

若有可解释概率 p_i，可计算 `E[R_T] = Σ p_i × R_i,T`，要求 p_i ≥ 0 且合计为 1。概率是研究假设，不能当实证胜率；没有依据时保留三情景范围与敏感性，不强制填 25%/50%/25%。用户示例的期望收益为 0.25×(−15%)+0.5×25%+0.25×80% = 28.75%，不是承诺回报。跨期比较须给期限；`(1+E[R_T])^(1/T)−1`只是期望终值的年化等价，不等于期望 CAGR。

主入口赔率沿用 `R = (Base − P)/(P − Bear)`，仅在 Bear < P < Base 有效。同期限未来情景价与今日估值锚分开标注；分红、成本须说明是否计入。2:1 是初筛偏好，不证明正期望值，不能从价差比反推出胜率。

悲观情景不是最低价、最大回撤或本金保障。必须另做融资断裂、技术替代、监管冲击、流动性冻结、经营与估值同时恶化的尾部压力，可包含股权归零。PB/NAV/清算值先扣优先债权、变现折价、税费与现金消耗；DCF 是模型价值，不能托底市场价格。未覆盖尾部的三情景概率不能冒充完整损失分布。

## 6. 仓位：先有约束，再谈凯利

普通研究给风险条件，不自动输出个人交易比例。只有用户明确采用项目个人策略后才应用既有单一标的占总资产 4%–5% 上限；必须在该区间内确定实际采用上限，“打满”表示达到已核准上限。新增框架不能覆盖既有资金隔离和风控规则。

仓位约束示意：`w ≤ min(单标的上限, 单标的损失预算 / 压力损失率, 流动性上限, 行业/因子剩余额度)`。分子分母按同一总资产基数，压力损失须覆盖跳空与无法止损；预算和压力损失缺失时不计算比例。该式为初步约束，不代替组合压力模型，也不保证实际损失不会超过预算。

同时评估行业、久期、利率、币种、地域、客户与融资相关性；持有五家 AI 公司可能仍是同一个风险。组合压力至少估计 Σ(w_i × L_i) 并加上融资、现金和对冲影响；正常时期相关系数不能代替危机共振场景。

经典 `f* = (b×p − (1−p))/b` 适用已知概率的二元赌局与明确的下注损失定义，不能直接套“股票胜率 70% + 目标价盈亏比”。一般多情景可研究最大化 `Σ p_i ln(1 + w×r_i)`，要求每种情景财富为正，并对齐期限、现金机会成本和杠杆。现实概率误差、尾部漏项、相关性与非平稳性会使满凯利脆弱；分数凯利也不自动安全。

项目默认将凯利作为辅助敏感性工具；不能用它绕过上述上限。研究基础见 [Stanford：Risk-Constrained Kelly Gambling](https://web.stanford.edu/~boyd/papers/kelly.html)，其把回撤约束显式加入财富增长目标。

退出与重评分四类记录：论点证伪、价格使赔率不足、组合风险超限、验证期限届满仍缺证据。价格下跌本身不证明便宜，价格上涨本身不证明逻辑正确。止损价不能保证成交或限制跳空损失。

## 7. 可复用研究卡与最低通过条件

| 字段 | 必填内容 |
| --- | --- |
| 锚点 | 公司/证券、价格日期、财报期、币种、财年、估值/兑现时点、摊薄股数 |
| 资产质量 | 主导变量、现金转换、ROIC/WACC 与增量回报、治理/资本配置、债务到期 |
| 调整桥 | 披露→调整；研发、SBC、租赁、税、维护投资、营运资本；缺项明确标记 |
| 定价 | 主辅锚与共同假设、反向要求、三情景经营与每股桥、方法分歧 |
| 预期差 | 共识快照或缺失、差异变量、幅度、公开证据、催化、阈值、日期 |
| 赔率 | 期限、Base/Bear/Bull、分红成本、有效价差比、概率依据或不赋概率 |
| 压力与组合 | 尾部情景、资金缺口/摊薄、组合共振、风险预算；未适用个人策略则不填比例 |
| 行动条件 | 条件化研究区间、证伪、减仓/退出/重评、下次验证、未决问题 |

缺关键财务口径、现金/债务桥或无法解释的高终值依赖时，不认证为“已验证低估”；标等待证据。缺可核验预期差时不宣称有 Alpha；可继续作为价值或长期复利观察。完整研究沿用 0–14 模块，将研究卡字段分别纳入既有模块，避免再生成一套重复报告。

未来若实现自动化，先做数据结构与口径校验，再做可复现计算、敏感性与人工裁决。验证效果需时点正确的历史数据、退市样本、成本与滑点、基准和样本外检验；本次方法论整合不代表已完成回测、自动算价或交易执行。

本报告仅供研究参考，不构成个人投资建议。
