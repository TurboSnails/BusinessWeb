# 综合股票估值

目标：把“为什么值这个价格”变成可复算、可追溯的研究结果。用资产质量、定价、预期差、压力风险四个问题组织证据；不要用综合分数或多个模型赞成替代证据。

## 开始

先确定公司/证券清单、估值日期、现价及时间、报价币种、财报期、估值时点和用户要的交付。复用已核实材料，保留原始日期；旧资料不冒充本轮重核。查取最新资料时用公司/交易所/监管原件核财务，报价记录供应商与交易时段。拿不到最新价格时，展示最后可核实报价和日期，不称“实时”。

单家公司读取 [方法与计算](references/methodology.md)。批量、多人协作、公司详情/列表回写时另读 [交付与数据契约](references/delivery.md)。可使用已有股票研究技能补业务与财务证据，但本技能不依赖特定平台、连接器或本仓库。

## 研究与计算

1. **买什么**：拆收入→利润→再投资→现金及每股价值；记录正常化调整、现金转换、资本回报/资本成本、稀释、治理和最大反证。金融公司采用相应资本框架。
2. **什么价格**：按行业选适用主锚和辅锚。PE/PEG/PB 都须评估适用性，不强制都给数值。列事实、预测、研究假设和推导；解释倍数来源、可比差异和共同输入，不机械平均方法结果。
3. **预期差与验证**：有来源的一致预期或价格隐含要求，与自己的假设分开；给业务验证变量、阈值与日期。没有共识就标缺失，不能把自己模型当市场预期。
4. **压力风险**：悲观价不托底，另外检验融资、经营与倍数双杀、监管、稀释、流动性及股权归零。不基于主观胜率自动给个人仓位。

## 不能混淆的输出

- `present`：指定估值基准日价值，可同币种对比价格；不是承诺成交价。
- `future`：有明确兑现日期的未来情景价格，比较得到的是相应期限价格回报；不能直接贴上“今日低估”标签。
- `undated`：兑现时点未定义的旧情景/敏感性，不认证为今日内在价值，不报年化。
- 对比统一为 `(估值或情景价 / 现价 − 1)`，称“相对现价差额/空间”。如果另报 `(价值−价格)/价值` 的折价率，必须分开命名，不能把两个分母混用。
- 无目标价推导或关键口径冲突时，输出 `insufficient` 并给具体补证据步骤。期限未定义但输入和公式可复算时，只可作为 `undated` 条件敏感性。仍覆盖该公司，但不能计入“数值估值完成”。有依据的假设可以输出 `conditional`；只有逐项复核且能追溯才用 `reviewed`。
- 程序化批处理必须标为批量条件初稿；套行业规则生成并校验不等于逐家读财报或多人独立认证。

## 关键禁区

- 不能用营收增速冒充 EPS 增速；不能把当前价除以当前 PE 后乘回相同 PE 当独立估值。
- PEG 的增长率百分数单位与期限必须明确；PEG 与 PE 共享增长假设，不算两份独立证据。
- 不能以 PB<1、PEG<1、ROIC>15%、价差比2:1或降息直接推出买入；不硬设统一目标PE或要求回报率。
- 不因金融股就禁止收益/价差比较；应更换目标价推导方法。
- 研发/获客经济资本化同步桥接利润、资本、现金税及再投资，重分类不能凭空增加现金。
- 正向/逆向DCF是同一模型两个方向；不能自动把 SOTP、PE、DCF 的异时点数值取平均。
- 三情景概率可留空。填满100%只证明算术合法，不证明分布完整；尾部单列无概率压力，或重分配完整概率，不能再额外叠加固定3%–5%。
- 2:1未折现价差只作描述；期限和要求回报单列。它不含乐观情景也可以定义自洽，不强制改成乐观赔率或二元隐含胜率。
- 单次情景算术期望不等于长期复利；期望对数增长需要重复投资、权重、再平衡等额外假设，不能当这次投资的“实际CAGR”。

## 交付与验收

精简公司研究保留：价格/日期/币种 → 生意与口径 → 主辅方法及适用性 → 可复算输入和三情景 → 方法分歧 → 相对现价 → 最大风险/证伪/缺项/下次验证。详情放过程，列表放状态、主方法、区间/基准、对比价格和日期；旧研究评级与本轮价格判断分列，不能静默改写。

批量结果按 delivery.md 导出后运行：

```bash
python3 scripts/validate_records.py /path/to/results.json
```

这里的 `scripts/` 相对本技能目录。校验脚本只验证结构、日期、数值、来源引用及覆盖清单，不认证财务事实或策略表现。每个数值方法必须用披露的 inputs 和公式重算得到 values；不得复制旧情景价后换上新的 EPS/BVPS/DPS 标签，不能隐藏情景系数。旧模型明确撤回/暂停时，不得仅改名 conditional 后恢复其数值。报价币种不自动证明财报分母、ADR/ADS换算已核实；有冲突先停数值。发布前由协调者核对实际产物、复算异常和抽查原件；失败记录保留状态、原因与可续做清单。用户只授权分析时不擅自部署；要求同步公司网站时再按目标项目约定写入。

本报告仅供研究参考，不构成个人投资建议。
