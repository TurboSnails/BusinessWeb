# 市场雷达升级：口径修正、补全数据、改版交互

模式：标准。理由：同时改数据脚本（`scripts/lib/market-radar/`）与页面（`src/features/market-radar/`）两层，新增 4 个外部数据源与约 18 项指标；不涉及认证、支付、数据库与破坏性迁移。

一句话目标：让市场雷达的每个数字经得起核对，一屏能看出股市冷热在哪、和上月比变了什么，并补上专业平台常见而本站缺的指标。

用户原话（2026-11-24）：「市场雷达 帮我严谨分析，完善数据，优化交互，可以尝试参考专业商业平台」。

## Why

2026-11-24 做了三项调查，记录在本文件与 `design.md`：

1. **独立审计**（离线重建管线，36/37 项指标与 645/646 个月度档位能复现）：今天的档位（中性）与冷热（偏热）没有算错，但有 3 处数据问题、6 处口径弱点。
2. **对标专业平台**（OFR 金融压力指数、CNN 恐惧与贪婪、美银牛熊指标、高盛风险偏好指标、德银仓位报告、Koyfin、SentimenTrader、乐咕乐股等）：本站缺金融条件、实际利率、美元、趋势与波动水平、期权情绪等常见项；呈现上缺总览、变化、排序筛选与新鲜度标识。
3. **页面走查**（桌面 1440 与手机 390）：37 项逐行堆叠（手机约 14,000 像素高），列不对齐，百分位条的颜色方向与冷热标签相反，只展示指标的打分位显示「暂无」。

### 审计发现与处理

| 编号 | 发现 | 证据 | 处理 |
|---|---|---|---|
| A1 | 回测里的每股盈利用了事后插值 | 席勒表 1960 年以来 532 个非季末月里有 528 个是季末之间的线性插值；4 月的盈利已含三分之一的二季度变化 | 盈利与市盈率改用季末阶梯序列（季末后第 3 个月末可得）。影响 646 个月里 34 个月的档位；夏普 0.586 → 约 0.591，没有被高估 |
| A2 | 净流动性历史年数写多了 | 标「2003 年起约 23 年」，实际 677 个点里 673 个在 2014 年以后 | 隔夜逆回购工具 2013-09-23 启用前按 0 计，历史真实回到 2003 年；改正来源文档 |
| A3 | 成交量类指标的冷热没有方向 | 11 月 20 日标普跌 3.7%，20 日量比 1.34 倍却标「偏热」，同屏 VIX 期限结构标「偏冷」 | 量比、量价不给冷热（方向为「无」） |
| B1 | 月均价收益让所有策略的波动偏低 | 全程持有：波动 12.5%（月均价）对 15.3%（月末收盘），夏普 0.553 对 0.479；排序不变 | 回测另算一套月末收盘口径并排列出；宏观攻守页同样受影响，本次只记录、不改 |
| B2 | 「高于恒定七成」没有统计依据 | 夏普差 +0.03，自助抽样 95% 区间约 −0.06 至 +0.15 | 结论句按抽样区间措辞；区间由脚本算出 |
| B3 | 两项家庭配置几乎是同一票 | 月度打分相关 0.84，73.7% 的月份相同、从不相反；1998 年前它们就是整个拥挤度 | 披露；并给出「合并算一票」时的热度（今天恰在偏热边界 −0.50） |
| B4 | 过期读数仍给冷热 | NAAIM 已停更 97 天仍标「偏热」；过期阈值不分频率 | 过期与停更不给冷热；阈值按频率定 |
| B5 | 百分位样本疏密不均 | 20 日量比早年按日、中段按周：94.9（混合）对 93.4（按周） | 日频、周频序列统一按周取最后一个观测再算百分位 |
| B6 | 当前口径与回测口径不同 | 融资余额当前 0 分、回测口径 −1 分；综合分 −0.03 对 0.00 | 已披露；页面并排显示上月末回测档位 |
| C1 | 股债利差读数混用日期 | 11 月 20 日市盈率配 10 月月均收益率，标「2026 年 11 月」 | 读数句写清两个日期，并附按当日收益率的参考值；打分口径不变 |
| C2 | 个别数据异常 | 20 日量比缺 2026 年 1 月；1997-12-26、2003-12-26 读数 0.26 | 查明并修正或剔除 |
| C3 | 个别冷热标签有歧义 | 等权相对市值加权、做市商 Gamma 敞口 | 改为不给冷热；页面写明「冷热不等于加分扣分」 |

## What Changes

- **口径修正**：上表 A1–A3、B1–B6、C1–C3。九项计分规则、阈值、权重、分档一律不变（radar-v1）。
- **补全数据**：新增 18 项只展示指标（金融条件指数、OFR 信用压力、10 年期实际利率、美元指数变化、银行准备金变化；巴菲特指标、股息率；Put/Call、SKEW、杠杆基金期货净仓、对冲基金股票多空比、融资余额 ÷ GDP；VIX 水平、标普相对 200 日均线、距 52 周高点回撤、已实现波动率、VVIX；企业利润 ÷ GDP）。其中 14 项用站内已有序列，4 项新接外部来源。
- **每项指标新增字段**：数值与短读数、频率、状态（最新 / 滞后 / 停更 / 零星）、方向、近期变化、图上的规则线、小组、是否核心、全部历史。
- **回测新增**：月度综合分与维度分历史、四条净值曲线、各档位与各冷热之后 12 个月表现、月末收盘口径对照、夏普差的抽样区间。
- **页面改版**：结论区加五维雷达图、驱动项与新鲜度；新增一屏冷热总览；指标区改为对齐的表格，可按维度筛选、切换核心 / 全部、排序，行内有变化与走势，展开后有带规则线的历史图；回测区按时段切换、加净值曲线与分组表现；披露收进可展开的小节。筛选、排序与展开的指标写进网址。

## 业务规则

1. 计分规则冻结：九项指标、阈值、同维度平均、五维等权、分档刻度不变。新增指标一律「事后新增，只展示」。
2. 仓位结论只在综合策略页给出；雷达页不出现仓位百分比（沿用 2026-11-24 的定案）。
3. 冷热 = 乐观、昂贵、拥挤或景气强；冷热不等于加分扣分。没有方向含义的指标不给冷热。
4. 过期或停更的读数照常显示数值与日期，但不给冷热、不进冷热计数；计分指标即使过期仍按冻结规则计分，并在结论区提示。
5. 所有新增的回测数字由脚本生成，页面不写死数字。
6. 看过结果后的数据修正（A1、A2、B5）在披露里逐条写明日期与影响。

## 边界情况

| 情况 | 期望行为 | 对应场景 |
|---|---|---|
| 新接的外部来源首次下载失败且没有缓存 | 该指标读数暂缺，其余指标与回测照常生成，脚本给出警告 | spec「来源失败不拖累整体」 |
| 指标只有一两个读数（美银调查） | 状态为「零星」，不画走势、不给百分位与冷热，仍显示读数与日期 | spec「零星读数」 |
| 指标读数超过滞后上限 | 状态为「滞后」，行内标出天数，不给冷热 | spec「过期读数」 |
| 筛选后没有任何指标 | 显示「没有符合条件的指标」并提供清除筛选 | spec「空筛选」 |
| 网址里带了不存在的指标或维度 | 忽略该参数，按默认视图显示 | spec「无效网址参数」 |
| 手机 390 宽 | 无横向溢出；指标一行两列信息、点开看详情；表格在自身容器内滚动 | spec「窄屏」 |
| 旧版数据文件（缺新字段） | 页面给出「数据版本过旧」的错误提示，不白屏 | spec「数据结构校验」 |

## 非功能需求

| 维度 | 要求 | 如何验证 |
|---|---|---|
| 体积 | `market-radar.json` 不超过 1.5 MB（现 0.49 MB） | 生成后 `ls -l` |
| 性能 | 首屏不渲染 55 个展开图；展开时才挂载历史图 | 组件测试 + 浏览器走查 |
| 可访问 | 筛选、排序、展开可用键盘操作；图表有文字等价物；触屏点击目标不小于 44px | 组件测试 + 走查 |
| 兼容 | 综合策略页继续可用（共用月度信号） | 全量测试 |
| 可复现 | 回测抽样用固定随机种子，重复运行结果一致 | 脚本测试 |

## 明确不做

- 不改 radar-v1 的计分规则、阈值、权重、分档，也不把新增指标并入计分。
- 不改宏观攻守页与综合策略页的回测收益口径（B1 对它们同样成立，另开一次变更处理）。
- 不删除站内已有的高收益债利差数据（FRED 页面写明禁止转载，见风险），等用户决定。
- 不接入 CNN 恐惧与贪婪、MOVE 等许可不明或明确禁止转载的数据。
- 不改 GitHub Actions 工作流（新缓存文件落在已纳入提交的 `data-raw/market-radar/` 目录）。
- 不做指标告警、订阅与导出。

## 验收方式

- 用户：本地打开 `/invest/market-radar`，桌面与手机宽度各看一遍结论、总览、指标、回测四个区。
- 自动化：`npm run typecheck`、`npm run lint`、`npm run test`、`npm run test:scripts`、`npm run build`；浏览器脚本检查两种宽度无横向溢出、无控制台报错，并逐项操作筛选、排序、展开、时段切换。

## 澄清记录

用户未在线逐条答复；以下由 Orchestrator 依据用户已有的决定代答，交付时列给用户复核。

| 决策 | 备选 | 选择与依据 |
|---|---|---|
| 新指标是否计分 | 并入计分 | 只展示。同日两轮预注册检验后规则已冻结 |
| A1 是否修正回测 | 只披露 | 修正。属于取数时点错误，与同日已做的市盈率时点修正同类 |
| 默认显示多少指标 | 全部 55 项 | 默认「核心」约 25 项，可切到全部；避免列表更长 |
| 是否发布 | 直接推送上线 | 做到本地可看为止，提交与发布前等用户确认（用户当日对上一轮改版的要求：先在本地看再发布，发布前不提交） |

## Impact

- 脚本：`scripts/market-radar.mjs`、`scripts/lib/market-radar/{indicators,sources,backtest}.mjs`、`scripts/market-radar.test.mjs` 及新增测试。
- 数据：`public/data/market-radar.json`（结构新增字段）、`public/data/combined-strategy.json`（A1 使部分月份的热度与九格统计小幅变化）、`data-raw/market-radar/` 新增 4 个缓存与来源文档。
- 页面：`src/features/market-radar/**`、`src/styles/market-radar.css`、`src/pages/MarketRadar.tsx`。
- 契约：`src/features/market-radar/types.ts`（Orchestrator 维护，已先行写定）。

## 风险

- **数据许可（存量）**：高收益债利差（FRED `BAMLH0A0HYM2`）页面写明「禁止以任何形式转载」，本仓库公开且自 2023-11 起逐日累积。Cboe 指数文件的条款同样限于个人非商业使用。本次不扩大这类暴露，是否下架由用户决定。
- **流程缺项**：本仓库没有 PR 门禁与 staging；门禁以本地全量检查加线上 Pages 构建为准，发布由用户确认。
- **A1 改变历史档位**：34 个月的档位变化会传到综合策略页的九格统计，需要在两页披露。
