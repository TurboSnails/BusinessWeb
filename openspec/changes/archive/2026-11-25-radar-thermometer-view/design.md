# 设计

## 1. 数据（`scripts/lib/market-radar/backtest.mjs`）

- `RadarForwardStats` 新增 `episodes`（连续月份段数）与 `independent`（≈ min(段数, round(月数 ÷ 12))，至少 1；无样本为 0）。
- `tierStats[]`、`heatStats[]` 新增 `before2000`（信号月 < 2000-01），与 `all`、`since2000` 同结构。
- 新增 `backtest.predictive`：`{ score: Corr, heat: Corr }`，`Corr = { all, before2000, since2000 }`，每段 `{ months, r, t }`。r 为皮尔逊相关；t 为 OLS 斜率的 Newey-West t（Bartlett 核，滞后 12）。回报与 `forward12` 同源（月均价 + 股息，信号月后第 2~13 个月）。
- `timeline[]` 新增 `heatScore`（估值与拥挤度维度分等权平均）。

## 2. 结论句规则（页面侧，由数字生成，不手写数字）

- 相关性：三段（全样本、1973–1999、2000 年以后）各给相关系数与 t；|t| < 2 写「不显著」，否则按 r 的符号写方向。综合分说「越高之后越好 / 越差」；冷热分正数为偏冷，说「越偏冷之后越好 / 越差」，并在主语后注明「正数为偏冷」。
- 冷热分组：两段都有偏热与居中时，比较「偏热 − 居中」的符号；两段同号写「两段都是偏热之后低于（或高于）居中，但独立样本少」，异号写「两段方向相反，不能当择时信号」，任一段差值为 0 时不判方向。某段某组没有样本时写「2000 年以后没有出现过偏冷」。
- 折叠摘要：取 `predictive.score` 与 `sharpeGaps` 里十个月均线一项；区间含 0 写「与十个月均线的差异在抽样误差内」，否则写高于/低于。标题固定为「把五个维度平均成一个分数行不行」。摘要开头：全样本 |t| < 2 时为「没有证据显示可行」。
- 冷热描述用「估值与持股拥挤度」，不用「仓位」。

## 3. 时间线

V 原稿要求月度时间线改画冷热。TimelineView 为宏观攻守、综合策略、雷达三处共用，色带与图例写死五档。为画冷热改共用组件的风险与改动面不划算，取舍为：月度档位时间线整体移入折叠区（它本身是综合分的证据）；冷热历史由结论区「冷热分近 10 年走势」小图承担。

## 4. 实时与月末口径

结论区读数用实时快照，时间线与走势小图用月末回测口径，两者可能不同（如 −0.58 对 −0.75）。走势小图下注明「月末口径」。

## 5. 兼容

`load.ts` 的校验不要求新字段；页面在 `before2000` / `predictive` 缺失时退回只显示全样本与 2000 年起，不白屏。

## 6. 策略名称

回测里 `radar` 一行的名称由「市场雷达」改为「按综合分持仓」，verdict 与月末口径披露同步改，避免把雷达本身读成一个持仓策略。

## 7. 走势小图

冷热分走势固定 −1～+1 纵轴，画 0 线与 ±0.5 虚线，标注「往上偏冷」；先取最近 120 个月再画，缺值断开。
