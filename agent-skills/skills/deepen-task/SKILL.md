# 任务深挖

把用户的任务改写成专业人士会执行、且能由外部证据检验的请求。深度来自材料、方法和验证，保持原有目标、对象、交付物、时间及预算边界。

## 输入

从当前消息或对话中定位要改写的原始任务。仅有本技能的通用指令、没有具体任务时，先请用户提供原始提示词。若领域或关键约束仍有歧义，只询问会改变方法选择的问题；其余假设在输出中标明。

## 工作流程

在重写前，依次回答以下四项，每项都结合原任务写出具体内容：

1. **专家会补上的工作**：指出顶尖专业人士为回答同一个问题，会做而原请求没有要求的关键工作，说明它能排除哪种误判。优先选对结论影响最大的缺口，避免扩展成新的项目。
2. **最原始的材料**：指出应从哪些一手记录、原件或直接观察入手，替代现有摘要、二手解读和加工指标。说明具体材料、所需粒度、取得途径，以及加工过程中可能丢失的信息。区分已提供材料、可获取材料和待补材料。
3. **具体方法与工具**：把方法与材料和问题逐一对应，说明输入、操作和预期证据。工具写出具体名称及用途，根据任务选择。尚未确认的能力或访问权限标为待确认，并给出可行替代。
4. **独立验证标准**：说明除用户和助手的主观判断外，什么能支持或推翻结果。给出适用的外部基准、可复现实验、留出数据、原始证据交叉核对或第三方评审，以及通过、失败或证据不足的判据。区分事实核验和审美、偏好等判断；阈值有依据时写明，无依据时标为建议验收条件。

然后输出一份可直接复制使用的完整提示词：保留原始目标与约束，明确上述四项对应的材料要求、执行方法、交付内容和验收条件。对缺失材料写明补充需求与证据不足时的处理方式。

本技能到重写提示词为止；实际执行原任务需由用户另行请求。方法和验证是拟议方案，不能写成已完成的研究、已访问的资料或已通过的检查。

## 输出

使用用户的语言，按「专家会补什么 → 一手材料 → 方法与工具 → 独立验证 → 重写后的提示词」的顺序组织。前四项简明具体，最后一项完整自足，用户无需复制前文即可使用。原有范围无法支持所需深度时，明确取舍，保留边界并降低结论强度。

## 原始提示词

> I want a deeper version of this task, not a bigger one. Before rewriting it: (1) say what a top professional in this field would do here that I’m not asking for; (2) name the rawest material they would start from instead of what has already been digested for me; (3) name the specific methods and tools they would use; (4) say what, other than you or me, would show the result is right. Then rewrite my prompt to ask for exactly that.
