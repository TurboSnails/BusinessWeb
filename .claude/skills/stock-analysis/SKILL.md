# 股票分析

## 统一入口与适用范围

本 skill 合并三部分：网站「研究方法 · 适用于所有公司」、股票研究专家（严估深 / 研股股）和腾讯自选股投研专家团（圆汇众 + 六位专家）。研究方法是主流程，深度研究负责财务与定价，专家视角负责发现反证、共识与分歧。

目标：在合理价格研究盈利趋势向上、确定性较高、增长持续更久、盈亏比有吸引力的公司。先算下行，再谈上行；先验证赚钱能力，再讨论概念。适用于美股、港股和 A 股，市场差异体现在数据口径与适用估值方法。

开始前读取 [完整研究方法](references/research-method.md)。它完整收录项目的目标、五步流程、PM 七问、数据纪律、市场财报节奏、口径、检查项、估值、陷阱、对抗检验、0–14 号成稿标准、深度分级、结论格式、仓位原则与红线。

## 合并后的规则优先级

执行本入口及完整研究方法；配套 equity / roundtable 文件提供专项方法与角色材料。参考资料中的旧平台工具、强制 Buy/Sell、固定仓位、强制多人编排等规则若与本入口冲突，以本入口为准。原版入口位于两个目录的 source-skill.md，仅供来源追溯。

- 综合结论使用「买入 / 持有 / 观察 / 回避」研究评级，给条件、时间维度与依据；缺关键证据时标「等待证据」，不为了明确方向编造价格或强行持有。
- 专家观点使用「偏多 / 偏空 / 观望 / 分歧」，保留不同期限与框架造成的分歧。综合评级与专家立场分别标注，不能以多数票代替证据。
- 估值区间、买入区、加减仓条件均为条件化研究假设，不是交易指令。个人仓位规则只在用户明确采用项目策略时应用，不默认套用所有读者。
- 默认完成所需专家视角与多空检验；具备授权及工具时可并行子代理，不能把调用本 skill 自动视为启动子代理的许可。没有子代理时由主模型逐视角分析，明确标「单模型多视角复核」，不冒充独立专家意见。
- 原专家的「永不空仓」「破均线就走」等是角色立场，用于比较长期与短期框架，不能覆盖统一风险约束。
- trading-analysis-team 是独立的交易提案 / 风险裁决流程，只有任务需要时再调用；本 skill 的普通研究不依赖安装它。

## 五步研究流程

### 1. 立论

确认公司主体、代码、市场、币种、研究问题和期限；先回答 PM 七问：什么被错误定价、价格反映什么、什么能证明或推翻论点、为什么是现在、什么改变评级/仓位/估值、还缺什么证据。分清公司质量与当前价格，缺变异认知标监控项。批量研究逐家核对主体与代码，无法确认者不参与排名。

### 2. 取数与盈利质量

核实最新可获取财报期；每个数字标来源、数据日期及报告期。事实 / 管理层声明 / 市场共识 / 模型输出 / 假设 / 判断分开写；缺失写 [MISSING]，超过 90 天标 [STALE] 并说明是否仍为最新已披露报告。

先查看当前环境实际工具。美股可优先用 yfinance，中国股票可优先用 akshare；没有连接器可查公开行情及公司 IR、交易所、监管机构公告。不能假定 MCP 已安装或保证不需凭证。财报以公司一手原件为准，原件核实、仅定位、公告转载、待核实分别标明。历史访谈快照不得当当前行情；盘中价不能称收盘价。

逐项核实价格与 52 周区间、TTM/远期 PE、PEG、PB/PS 或 EV/EBIT；收入、毛利率、经营利润率、EPS、ROE/ROIC、经营现金流、FCF、净杠杆。拆分业务、增长的量/价/份额/结构/成本/并购/周期来源，判断可持续期限；2027 年底是项目当前关注节点，仍须写研究期限与后续持续性。AI 仅在可量化传导到收入、利润率、费用、资本开支或估值持续性时纳入，否则标「AI 为非核心变量」。

GAAP / 调整后、TTM / 指引、累计 / 单季、不同财年必须分列；一次性损益逐项桥接。经营现金流不等于 FCF，扣非也不自动排除主营授权收入。发行、回购、转增、拆股、除息须查实施公告；股本变化时优先用同口径 TTM 总利润与最新摊薄股数核验，价格、EPS、目标区间及股息保持一致。

### 3. 估值与下行检验

重大判断至少两种适用且独立的方法交叉验证，并列出悲观 / 基准 / 乐观的经营假设、盈利或现金流、估值输入、隐含股价、上下行、期限、触发及证伪条件。DCF 写 WACC、长期增长率、终值占比与敏感性矩阵，终值占比超过 75% 说明模型依赖。

- 持续盈利公司可用正常化 EPS × 合理 PE，并用 DCF / 可比估值复核；不能直接用营收增速外推 EPS。
- 银行重视普通股 ROE、PB、信用成本与资本分红约束；保险用 EV / NBV / 营运利润、P-EV 或 SOTP；REIT 看 FFO / AFFO；亏损生物科技按产品 DCF、管线 rNPV 与净现金。不能给所有行业套统一 PE。
- 周期股用中周期盈利，低 PE 不自动意味着便宜；高股息先看现金覆盖与派息约束；没有历史倍数分位不得宣称已校准。

设现价 P、基准价 Base、悲观价 Bear。仅当 Bear < P < Base 且假设可核验时计算 R = (Base − P) / (P − Bear)，上行 = Base/P − 1，下行 = 1 − Bear/P。P ≥ Base 时解释上行不足；P ≤ Bear 时解释该情景下分母无效，重新检查下行情景，不能报告无穷赔率。R 优先约 2:1，低确定性需要更高安全边际；按未四舍五入数值判门槛。

悲观价不是最大损失保证，须独立做信用、竞争、流动性、摊薄等压力检验；不可为凑 2:1 收窄悲观端。给定已核实 Base / Bear，门槛研究价 P* = (Base + 2×Bear)/3；不能机械套 ±5% 为个股买入区。概率、期望收益是研究假设，不能称回测胜率；期限与分红单列。

程序化补全页的规则、公式、数据源与局限另见 [筛选规则说明](references/screening-rules.md)。它们只用于初筛排序，未经公司级核实不得认证深度研究评级或赔率。

### 4. 专家视角与对抗检验

按问题选择下列视角，深度研究通常 3–4 位；保留产业、估值与财报核心维度，需要时加入信号、逆向、短线。先形成各自观点再比较，共享同一价格锚点与财报快照，不重复取数。执行多代理圆桌时先读 roundtable/lead.md 的任务模板与汇编方法，并按本入口处理历史平台与编排规则。

| 专家 | 用途 | 按需读取 |
| --- | --- | --- |
| 星望远 · 产业策略师 | 产业链、景气、竞争位置 | [产业](references/roundtable/members/industry-strategist.md) |
| 洲四方 · 信号派首席 | 政策、产业、资讯、资金及周/月趋势 | [信号](references/roundtable/members/signal-chief.md) |
| 文衡价 · 估值分析师 | 价格、盈利、倍数与安全边际 | [估值](references/roundtable/members/valuation-analyst.md) |

每个视角写立场、时间维度、核心证据、最大反证及失效条件；空头逐条回应最强多头论点，主持人根据证据裁决并保留分歧。未做对抗检验须明说，不能伪造专家参与。风险提案需要三方裁决时使用独立交易分析团队。

### 5. 收口与验证

先给综合结论卡（评级、核心理由、盈亏比、确定性、增长持续期限、最大风险、待证据），再给条件化研究区间、确认加仓/减仓/止盈与失效条件、适用仓位原则。每条证伪可观察、可量化、有时间约束；有确切日期写日期，否则「待公告」。复核旧报告时列保留、调整、撤回的结论与新证据；未取得原件不等于经营恶化。

## 交付结构

完整版按 [完整研究方法](references/research-method.md) 的 0–14 模块交付：头部信息、公司简介、业务分布、优势与缺点、行业趋势、结论卡、关键指标、增长与护城河、三情景估值、买入纪律、风险证伪、多空交锋、口径陷阱、验证日历、免责声明。在多空交锋附近加入专家观点、共识与分歧、主持人深度思考；共用结论卡和验证日历，避免重复生成两份报告。

简版用于即时问答、横向比较、已有完整版的跟踪；至少保留来源与口径、结论、关键指标、三情景及赔率、条件化区间、最大风险、证伪、待证据与免责声明。若本轮不重估，明确引用旧模型日期和有效性，不能静默略过估值。

纯圆桌请求可用四模块：结论卡（综合判断与立场分布）→ 专家观点 → 深度思考与问答 → 后续关注与综合失效条件。用户只要圆桌而未要求估值时，不强制生成无关模型；涉及价位和赔率仍遵守估值纪律。

批次每 3–5 家统一口径比较，给排序理由、共同变量、数据陷阱、前后批衔接、下一步；有效旧页可复用，旧页不达标单列重做。保存、更新网站只在用户要求时执行，路径与写入方式见 equity/final-report-standard.md 和 equity/source-skill.md；独立下载环境不假定本项目存在。
