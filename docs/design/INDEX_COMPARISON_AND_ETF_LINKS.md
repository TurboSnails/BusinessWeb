# 指数比较、ETF关系与数据质量说明

入口仍为 `/monitor?tab=valuation`。本次基于现有 React 模块实现，不引入朋友独立HTML应用或数据包。

## 可以做什么

- 搜索、收藏已有指数，勾选2–4只，按共同月份比较归一化价格；按1/3/5/10年或全部区间查看。
- 表格列出月线起止标签和每只最新行情日。部分Yahoo序列以月初timestamp作月份标签，不能视为标签当天成交价；腾讯可能以末交易日标签。缺失月份按真实日历定位，不插值。
- 展开指数，可看到价格、PE、成分估值各自日期、频率/样本范围、来源与缺失解释；参考PE明确标TTM或Forward。
- 官方材料核验的少量ETF可以预填复盘或网格工具，打开链接不创建交易或覆盖笔记。直接跟踪和相关主题使用不同关系；未知不能解释为市场无产品。

价格比较不含分红，也未把不同币种换算成统一投资回报。PE分位不输出交易指令。长期PE位置至少24个真实月份，周频或更密序列先取每月最后一个真实观测，缺月不插值；插值仅可辅助画图，不能增加真实样本。价格十年分位要求以最新行情月份为终点之前120个完整月，缺月或未完成月不凑足门槛。

## 新增行业及缺数行为

`server/indexes.mjs` 为同一月线更新管线新增全指医药卫生000991、中证银行399986、证券公司399975、主要消费000932。只采真实指数，尚未取得的显示“待采集”，可先查看已核验ETF关系；没有PE就留缺失，不拿ETF净值或近似行业代替。

本次环境直接HTTP接口不可达，未生成这些行业历史，也未覆盖既有 `public/data/index-history.json`。有网络的维护环境运行：

```sh
node scripts/index-snapshot.mjs
```

现有每周六 `.github/workflows/macro-snapshot.yml` 已调用该脚本，所以以后自动纳入。脚本更新时先验证结构、真实日期/截止日、价格有序有限、旧历史不缩水且中间观测未被静默改写，再原子写入；失败保留旧文件。人工换来源或改历史仍走明确导入流程，允许有意识修订，但同样必须通过结构与日期门禁，不自动混拼。
