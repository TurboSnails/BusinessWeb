# ETF 网格迁移：实施与审阅记录

## 使用入口

- 导航「网格交易」→计算器：`/grid-trading`。
- 记录管理：`/grid-trading/records`。
- 保存回测后进入详情：成交修正、手动补录、删除/恢复网格成交、参数历史、快照及续跑对比。
- 结束日期留空的记录继续随最新行情更新；指定结束日期的记录固定该区间。
- 记录只保存在当前站点、当前浏览器。可导入 notes 导出的 `SavedRecord[]`，或导入/导出当前版本 JSON；同步 token 不在记录导出中。
- 快照最多 20 份，达到上限会拒绝新建并提示删除旧快照。修改快照及其续跑成交不会修改主记录。

## 数据与计算

腾讯前复权日线、GBK 实时报价，无需登录。日线当日最高/最低触发固定成交价；建仓当日不触发；同日两侧触及时买入优先、每日最多一笔。网格买入可让现金流为负数，自动卖出限制在已有持仓内。成交修正、手动补录或撤销导致历史或最终负持仓时，拒绝保存。

ETF 佣金 0.015%，单笔最低 ¥5、免印花税。普通 A 股佣金 0.015% 无最低佣金，卖出印花税 0.05%。算法与费率沿用原项目。总收益率按总盈亏/最大占用本金计算；快照后收益率按新增盈亏/快照时占用本金计算。

行情不可用或不完整时显示错误，保留已保存结果。只有显式刷新/修改会更新已保存计算；打开详情会加载行情以供操作。并发刷新保存前核对记录版本，避免覆盖新编辑或复活已删除记录。

## 云端边界

未读取、连接或修改朋友的云同步服务。独立存储 key 为 `businessweb.grid-trading.*`，源码和构建产物不带朋友服务地址、数据库 ID 或 token。

云同步默认未配置。只有自行部署独立 HTTPS 服务与专用 token 后才能启用；配置和每次同步都确认域名，拒绝已知朋友服务，禁止重定向。GET 返回 `{schemaVersion:1,records:[...]}`（兼容省略版本的同形响应），PUT 接收相同结构。按更新时间合并，删除标记保留 180 天；相同时间但内容不同的记录会提示冲突，停止上传。部署独立服务不在本次范围内，未部署或写入任何云服务。

6. 独立云服务部署延后，未提供隔离部署目标。代价：自有服务部署前云同步不可用，其余功能可用。
7. 手动账本的已实现盈亏沿用原算法。代价：已实现盈亏描述网格模拟；总盈亏包含手动调整。
