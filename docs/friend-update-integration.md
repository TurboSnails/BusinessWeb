## 使用入口

- `/monitor?tab=valuation`：指数搜索、收藏，选择 2—4 只指数进行共同月份的归一价格比较。表格显示月线标签范围与最新行情日期；日期标签不是当天成交日期，跨市场比较不含分红或汇率转换。来源、实际最新日期和历史覆盖可展开查看。
- 指数展开后的「关联 ETF」：少量代表产品的官方材料核验目录，区分直接跟踪和相关主题；记录资料日期、核验日期和原文链接。可以前往复盘或网格工具。暂无映射不等于市场不存在产品。
- 医药、银行、证券、主要消费四个行业指数已加入采集注册。当前静态历史未补齐，页面明确显示待采集，可先查看已核验产品；没有用 ETF 价格或编造 PE 代替指数。
- `/grid-trading` 和网格记录详情：点击加载独立日线观察图，支持日 K、成交量、MA10/20、可选 MACD、区间及平移缩放；逐日滑块可用键盘操作。观察图不改变参数、账户模拟或成交记录。
- `/etf-review`：多分组、日/周/月 MACD 偏多/偏空以及本期金叉/死叉筛选，默认排除未完成周期。技术快照显示逐标的日期，可失败重试；缺前值不生成交叉事件。当前快照没有上一完成月时，页面明确提示未完成周期，不把通用空态冒充无信号。
- ETF 清单和指数映射的「加入复盘」仅预填代码与名称，确认后才新增。已在列表的代码保留原名称、标签及笔记。

## 数据与兼容

复盘仍使用 `businessweb.etf-review.v1` 存储 key，避免遗弃旧数据；导出格式升级为 version 2。旧单分组备份载入时迁移为多标签，兼容的 `group` 字段保留首标签。改名时当前分组筛选跟随新名，删除当前分组筛选回到全部，均不删除笔记。导入先预览，默认合并补入新内容，保留当前标的顺序、名称和同标的同日笔记；新标的追加，替换全部需要明确确认，对话框内可先导出备份。

网格行情兼容可选 `open`、`volume`：旧缓存缺开盘价时显示真实收盘线，缺成交量不补零；按钮可强制刷新旧缓存。新拉取行情记录前复权/未复权口径；不同分页口径变化时拒绝合并，保留原缓存。观察图不混入未复权实时报价，历史截止日也约束观察范围。它使用最多 3 只标的的会话内存 LRU，不读写账户回测的 localStorage，也不会把账户缓存起点永久扩到 2000 年。刷新失败保留当前图，重绘不重复联网。成交量保留来源原单位，不冒充成交额。

指数长期分位需要真实月份数量及时间跨度；周频或更密 PE 序列先取每月最后观测，缺月不插值，插值不能增加样本。十年价格位置仅用对应日历窗内的完整月份。PE 的滚动/Forward 标签明确区分。自动快照发布前检查有效值、真实日期、未来日期、历史覆盖退化和中间观测改写，再以临时文件原子替换，失败时保留原产物。人工导入允许明确修订历史，但也必须通过同一结构与日期门禁，不能写入未来或非法观测。

## 维护

```sh
# 修改并核验官方关系证据后重建目录（不会自动把核验日期改为今天）
node scripts/index-etf-catalog.mjs

# 更新真实指数行情；数据源失败不会用替代数据冒充
npm run index:update

# 针对性脚本校验
node --test scripts/index-etf-catalog.test.mjs
```

目录事实源：`data-raw/index-catalog/etf-evidence.json`，身份注册：`src/features/index-catalog/registry.json`，发布产物：`public/data/index-etf-catalog.json`。更新时核对官方指数代码及产品的实际跟踪基准，不能按名称相似度自动认定直接跟踪。上游材料不保证每天更新，核验日不等于披露日。前端共享目录请求并设 15 秒超时，非法目录与请求失败均可重试。

未引入资金流、主升浪名单、择时优选组合或未核实 EPS。ETF 择时继续沿既有研究门禁验证，不因展示箭头或历史收益而升级为买卖指令。
