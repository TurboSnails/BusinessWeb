## 怎么读

1. **C1 用国债和黄金代替现金，组合反而更冒险**：年化波动 11%–12%，比「现行规则满仓 + 现金」还高，对照组不加杠杆追不上（按预注册，记为「需加杠杆」，在不同波动下比较，这对 C1 有利，它仍不通过）。2000 年后它更好（2008 年累计 −6.6% 对 −14.6%），但这是股债负相关、债券牛市的年代；1976–1981 年和 2022 年都明显更差。
2. **C2 风险平衡很平稳，但同样波动下「少放股票、多放现金」更好**：1976–1999 年夏普 0.62 对 0.26，2000 年后大跌损失还更深。
3. **去掉一次性漂移、换到没用过的 1963–1972 年数据，两者都更差**：黄金 1970 年代的暴涨和 1981–2020 年的债券牛市是它们好看的主要来源。
4. 结论：在同等波动下，国债和黄金没有比现金更可靠地减少大跌损失。降波动继续用「美股上限 80%，其余放现金或短期国债」。

## 第二实现与审稿

独立审稿人只按预注册另写了一套实现（先冻结自己的数字，再看主实现），初次比较发现主实现一处错误：C1 把黄金上限 1/3 用在了「债 + 金」那部分，而预注册是对整个组合的黄金占比设上限（C1 的黄金占比本来不超过 0.248，上限不会触发）。另有一处取舍：去漂移检验是否按去漂移后的序列重新算权重；改为与预注册「保留波动与相关」一致的做法——权重按原始序列。两处改正后，两套实现所有比较数字的最大差异 3.3e-15（预注册要求 < 0.001）。改正前后结论相同。审稿还确认 1976–1981 压力期截到净值起点（1976-02-04）的修正正确。

## 局限

- 黄金 1999-01 至 2000-08 是月均价插值；国债是固定期限收益率换算，不是可交易指数；期内每日再平衡是简化；持有费与成本是估计值。
- 美国 1973 年以后的数据已被多轮检验使用；本检验的信息主要来自严格的尾部门槛、去漂移与锁箱。
