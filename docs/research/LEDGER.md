# 研究登记簿

建立于 2026-11-25（降低波动路线图第 1 阶段）。目的：记录在同一份历史数据上做过多少次检验，让读者知道该给历史数字打多少折；保留真正没看过的数据（锁箱）；防止不通过后在同一数据上反复换参数重试。

## 规则

1. 每份新预注册必须写明登记编号（如 `L-024`），并在提交前把条目加到下表，结论栏写「待算」。
2. 每份预注册最多 2 个**确认**候选；探索性候选可以多，但不能据此采用。
3. 不通过后 90 天内，不在同一数据上预注册该方法的参数变体（换窗口、换久期、加上限等）。
4. 锁箱数据只在预注册提交之后、为确认检验使用一次；使用后在锁箱表里记日期和用途，从此不再是锁箱。
5. 两套引擎一致只证明「代码没写错」，不证明「结论可靠」；结论可靠要靠没看过的数据。
