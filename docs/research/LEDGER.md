# 研究登记簿

建立于 2026-11-25（降低波动路线图第 1 阶段）。目的：记录在同一份历史数据上做过多少次检验，让读者知道该给历史数字打多少折；保留真正没看过的数据（锁箱）；防止不通过后在同一数据上反复换参数重试。

## 规则

1. 每份新预注册必须写明登记编号（如 `L-024`），并在提交前把条目加到下表，结论栏写「待算」。
2. 每份预注册最多 2 个**确认**候选；探索性候选可以多，但不能据此采用。
3. 不通过后 90 天内，不在同一数据上预注册该方法的参数变体（换窗口、换久期、加上限等）。
4. 锁箱数据只在预注册提交之后、为确认检验使用一次；使用后在锁箱表里记日期和用途，从此不再是锁箱。
5. 两套引擎一致只证明「代码没写错」，不证明「结论可靠」；结论可靠要靠没看过的数据。
6. **因子挖掘（2026-11-26 起，`research-py/factorlab/`）**：探索性评估由引擎自动记入 `research-py/factor-ledger/{市场}.jsonl`，不必逐条写进本表；但任何「采用 / 通过」只认锁箱数据上、按预注册门槛的确认检验，并照常在本表登记 L-xxx。锁箱固定为各市场 2023-11-01 至 2026-11-30（`factorlab/lockbox.json`），在数据层强制；每个市场终身候选预算 24 个，按季度批量解封、批内 Holm 校正，按批次计数（不是按预注册份数），预算用完即作废；之后靠截面验证、跨市场复现与 2026-12 起的前推记录。设计见 `docs/research/factorlab/DESIGN.md` 第四节。幸存者偏差等级 B 的数据（港股、美股个股）上的结论不能单独据此采用。
