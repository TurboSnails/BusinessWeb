## 要回答的问题

用户设想的主动策略：2 只成长股、2 只高波动股、1 只稳定股（如安达保险 CB），按目标权重持有；平时偏离到一定程度就调回目标；纳指 100 大跌时分步卖出稳定股、买入跌得最多的弹性股；大盘恢复后再买回稳定股。问题是：这样长期回报是否更高、风险如何？

## 主要结论

### 1. 再平衡相对买入持有：取决于行情类型

- **反复震荡、没有持续多年的超级大赢家时，再平衡普遍多赚。** 2021-08 至 2026-11 的 1,575 个组合里，相对偏离 40% 再平衡的年化高于买入持有的占 95.6%（中位数高 3.9 个百分点）；不含 RKLB 的组合也有 93.4%。
- **有持续多年的大赢家时，再平衡会少赚很多，但回撤小得多。** 2016 年以来含 NVDA、TSLA 的 70 个组合，没有一个再平衡收益更高（中位数低 6 个百分点），但全部回撤更小（中位数少跌 14 个百分点）。1986 年以来的行业组合同样如此（买入持有年化 20.9%，再平衡 17.5%）。
- **起点很重要。** 2023-12 到 2024-06 之间开始的话，再平衡有一半以上组合输给买入持有。

### 2. 规则选择：差别不大，按操作负担选

- 相对偏离 20% 到 60%、绝对偏离、每月、每季的结果跳来跳去，不随阈值平滑变化，主要由少数几次调仓的时点决定。不存在"最优阈值"。
- 换不同起点看，**每年调一次**的最差情况最温和（最差比买入持有少 2.4 个百分点，其他规则最差少 6 到 10 个），5 年只调 3 到 5 次。
- 换不同起点看，再平衡在 85% 到 90% 的起点上降低了回撤（2021 年以来的组合，中位数少跌约 18 个百分点）。
- "只调越界的那只"在按目标比例分摊时与"全部调回"数学上等价。

### 3. 稳定股：放一只和科技股走势不同步的

- 选哪只稳定股，对再平衡额外收益的影响约 1.5 个百分点，远小于选哪两只高波动股。
- CB 与 AVGO、META 的日收益相关性接近零，放进组合能明显降低回撤（用户的五只组合里，用 CB 换 MSFT 后回撤从约 −57% 降到约 −52%）；AXP 与成长股的相关性在 0.3 到 0.46，作用有限。
- 价格数据大多不含分红，KO、PG、JNJ 等高分红股被低估约每年 2.5 到 3 个百分点。

### 4. 大跌切换：收益更高，回撤更深；加卖出上限后风险接近普通再平衡

| 样本 | 方案 | 年化（中位数） | 最大回撤（中位数） |
|---|---|---:|---:|
| 用户组合，2021-08 起 | 普通再平衡 | 27.8% | −45.7% |
| | 大跌切换 | 32.0% | −47.4% |
| 70 个组合，2016 起 | 切换相对普通再平衡 | +1.9 个百分点 | 多跌 4.3 个百分点 |
| 54 个行业组合，1986 起 | 普通再平衡 | 17.5% | −63.1% |
| | 大跌切换 | 18.1% | −73.0% |
| | 大跌切换 + 卖出上限 50% | 18.2% | −64.4% |
| | 大跌切换 + 18 个月超时 | 17.4% | −74.1% |

- 本质是**大跌时加仓抄底**：继续下跌时跌得更深，赚的是之后的反弹。
- **2000–2002 年**：纳指 100 跌了约 83%，"大跌状态"从 2000-04 一直持续到 2015-03 才恢复；无上限的规则在 2000 年 11 月前就把稳定资产卖光，2000-03 至 2002-10 组合跌了 62.7%（普通再平衡 51.7%），最差三年年化 −26.8%（普通再平衡 −22.3%）。
- **卖出上限 50%** 让最大回撤和最差三年都回到接近普通再平衡的水平，年化仍略高（+0.7 个百分点），从高点到重新创新高的时间还缩短了约 558 个交易日。在这几个样本里，它是风险和收益最平衡的一种。
- **18 个月超时**反而更差：在熊市还没结束时就把稳定资产买回来，随后再次触发，收益更低、回撤更深，不建议使用。

改用标普 500 后，54 个行业组合各阈值的年化差中位数仍为 +0.38 至 +0.67 个百分点；无上限版本回撤更深，50% 上限把回撤差中位数收窄到 −2.09 至 −0.32 个百分点。2016 年以来的 70 个组合年化差为 +0.33 至 +1.93 个百分点；浅回调的轮内差值较小，较大的正差值集中在深跌后的反弹轮次，同时仍有中途落后。详见 [spx-signal.md](spx-signal.md)。

## 对用户策略的条件化看法

在这些样本里，下面这种做法的风险与收益较为平衡；它不是"最优"，只是在测过的几种里没有明显短板：

- 组合里放一只与科技股走势不同步的稳定股，高波动股降低目标权重（如各 12.5%）。
- 平时用宽一些的偏离阈值或每年调一次，以少交易为准。
- 大跌切换加**累计卖出上限 50%**，不加超时恢复。
- 每只股票事先写好退出条件；大跌时规则会去买"跌得最多的那只"，基本面坏了的股票不该补。

## 局限

- 事后选股与事后指定规则；样本里独立的大跌只有几次（1986 年以来 8 次进入 −20%）。
- 个股数据大多不含分红；行业组合比个股分散，个股的最坏情况会更糟；等权行业组合含大量小盘股，成本被低估。
- 只计 0.10% 交易成本，不计税；税负取决于账户。
- 70 个、54 个组合彼此高度相关，分位数不是独立实验的置信区间。
