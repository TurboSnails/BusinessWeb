## 规则（逐字照 L-004 代码，计算前写死）

代码版本：`scripts/research/etf-strategy-oos/strategies.mjs` 在提交 **b8e45ae6**（2026-11-15，L-004 当天）创建后未再改动，SHA-256 `9570a34bd55439245012b9b8bfb2a2143b8d92acb346a301704501bb9edbbb82`；L-004 调用方式见 `bt-index.mjs`（b8e45ae6；之后 74242c00 只加了「取数失败不覆盖」的保护）。冻结基于 origin/main **ffb038c4**；冻结提交本身的哈希以 LEDGER L-056 行为准。计算脚本 `run.mjs` 必须 `import { ratioTiming, timingGold, windowStats, macdOnly } from strategies.mjs`，不复制、不改写，运行时校验上述 SHA-256，不符即停止。

- **择时**：`ratioTiming(000300, 000922)`：比值 = 000300 收盘 ÷ 000922 收盘；最近 20 个比值（含当天）用 `q.reduce` 从旧到新求和后除以 20 为均线；当天比值**严格大于**均线为牛，否则为熊；不足 20 个比值时没有定义。
- **MACD**（`macdCross`，对被交易指数自己的收盘）：EMA12 与 EMA26 都以第一根收盘为初值，系数 2/13、2/27；DIF = EMA12 − EMA26；DEA 初值 0，DEA += 0.2 ×（DIF − DEA）。金叉：前一日 DIF ≤ DEA 且当日 DIF > DEA；死叉：前一日 DIF ≥ DEA 且当日 DIF < DEA。
- **交易**（`timingGold(bars, bull, { fill: 'close' })`，预热 120）：
  - 第 i 根（i ≥ 120）：空仓、当日金叉、当日为牛 → **次日收盘买入**（全部资金，扣 0.1%）。熊市不开新仓。
  - 持仓、当日死叉 → **当日收盘卖出**（扣 0.1%）；若当日就是买入成交日，则次日收盘卖出。
  - 挂单次日执行时不再检查牛熊；卖出成交当天若又是牛市金叉，可以挂新的买单。
  - 空仓现金收益为 0；持仓按收盘计值；窗口末不强制平仓，窗口末的挂单不执行。
- **一直持有**：被交易指数收盘本身，不计买入成本（与 L-004 相同）。
- **统计**（`windowStats`）：区间 [from, to] 内第一个与最后一个交易日；年数 = 日历天数 ÷ 365.25；年数 ≥ 1 时给年化，否则只给区间收益（C 段 1.05 年，给年化，区间收益另报）；最大回撤从区间首日净值起算，不继承区间以前的高点。输出为百分数。

## 对照、暴露与安慰剂（计算前写死）

- **暴露**：e_i(t) = pos_i(t−1)，W 首日 e = 0（规则在 W 起点空仓）。pos 取 `timingGold` 的 `pos`。
- **k_i** = W 内 t = 2..1338 的 e_i(t) 均值，即实际承担当日收益的暴露（买入成交日的收盘才建仓，不赚当日收益）。这与 count.mjs 的「持仓天数占比」分母不同，不能混用。
- **同平均仓位静态对照 M_i**：净值 = Π(1 + k_i·r_hold,i(t))，t = 2..1338，每日再平衡、现金 0、不计成本。
- **年化波动**：W 内日简单收益的样本标准差（ddof = 1）× √252，规则 / 持有 / M_i 同一口径。
- **时机安慰剂（循环平移）**：平移量 s ∈ {63, 64, …, 1275}（全部 1,213 个，确定性枚举，不用随机数）。L = 1338，W 内第 u 天（u = 0..L−1）的平移暴露 e_i^s(u) = e_i((u + s) mod L)。占位净值：E(−1) = 1；E(u) = E(u−1)·(1 + e_i^s(u)·r_hold,i(u))（u ≥ 1）；若 u < L−1 且 e_i^s(u+1) ≠ e_i^s(u)，视为当日收盘成交，再乘 (1 − 0.001)；窗口末日不计成交。按此定义 s = 0 的占位净值与 `timingGold` 净值逐日相同（窗口末日恰有成交时除外；2011–2026 已用数据上核对，最大相对差 4.6e-15）。**15 个指数用同一个 s**，保留指数之间的相关。
  - 统计量：C 段最大回撤的 15 指数均值 D̄、W 年化的 15 指数均值 Ā、#X（安慰剂对 M_i）。规则的 D̄_rule、Ā_rule 取自 `timingGold` 净值的 `windowStats`。
  - **p_C** = (1 + #{s : D̄^s ≥ D̄_rule}) / (1 + 1213)（回撤为负数，≥ 表示安慰剂不比规则深）；p_A、p_X 同理（p_X 用 #X^s ≥ #X_rule）。p_C 用于判定，p_A、p_X 只报告。
  - 只报告：每个指数单独的 C 段回撤在 1,213 个平移中的分位（指数级 p）。
  - 只报告：**择时滤网安慰剂**——把 000300÷000922 的牛熊序列相对价格循环平移（同一组 s，在 2005-01-28 至 2010-12-31 的 1,439 个有定义日期上平移：bull_s(第 k 天) = bull(第 (k + s) mod 1439 天)，k 从 0 起），MACD 不动，重跑 `timingGold`，报告 #D、#X、D̄、Ā 的分布及规则所处分位。
  - 只报告：`macdOnly(bars, { fill: 'close' })`（不择时、只认金叉死叉，L-004 当时也算过）。

## 判定

### 逐个指数

- **D_i（回撤）**：C 段内规则最大回撤不超过一直持有的 70%（代码：`rule.dd ≥ 0.7 × hold.dd`，dd 为负数）。
- **A_i（收益）**：W 内规则扣费后年化 ≥ 一直持有年化 − 1 个百分点。
- **P_i** = D_i 且 A_i。
- **X_i（同仓位择时增量）**：W 内规则扣费后年化 ≥ M_i 年化，**且** C 段规则最大回撤不深于 M_i。X_i 对现金口径中性（M_i 的平均现金比例与规则相同，两边现金都记 0）。

### 等级（计算前写死）

| 等级 | 条件 |
|---|---|
| **确认** | #P ≥ 9 且 #D ≥ 12 且 #X ≥ 8 且 p_C ≤ 0.10 |
| **部分确认（同仓位下回撤改善成立）** | 不满足「确认」，但 #D ≥ 12 且 #X ≥ 8 |
| **回撤门槛通过、择时增量未证实** | #D ≥ 12 且 #X < 8。按「未确认」处理。子标签：p_C ≤ 0.10 时写「大跌段时机优于随机（p_C = …）」，否则写「大跌段时机与随机无异（p_C = …）」 |
| **未确认** | #D < 12 |

等级顺序：确认 > 部分确认 > 回撤门槛通过、择时增量未证实 > 未确认。「部分确认」若 p_C > 0.10，须加注「与同样仓位结构的随机时机相比不显著」。

理由：#P ≥ 9 对应 L-004 的「15 个中 9 个两项都过」，确认同一结论需要同样的广度；#D ≥ 12（80%）允许一段大跌里最多 3 个不过；#X ≥ 8（过半）与 p_C 回答「同样三到四成的平均仓位，规则把仓位放在了对的时候吗」，正对用户目标（同等仓位下降低波动与回撤），并防止把「低仓位」误读为「择时有效」。只看个数、不看平均，与 L-004 口径一致；15 个指数高度相关（N_eff ≈ 1.3），这不是 15 次独立检验。门槛未因功效结果改动。

### 降级规则（计算前写死，按顺序执行）

1. **择时信号回填降级**：在 W′（2008-05-26 至 2010-12-31）对全部 15 个指数计算 X_i′：k_i′ = W′ 内 t = 2..637 的 e_i(t) 均值（e 沿用主口径的持仓，不重启规则），M_i′ 按 k_i′ 在 W′ 内重算，比较 W′ 年化与 W′ 内最大回撤（「不深于」）。若主口径 #X ≥ 8 而 #X′ < 8，等级最高「部分确认」，并注明「择时增量只出现在择时信号回填段」。
2. **L-004 布局敏感性**：直接用 `docs/research/etf-volume-2026-11-25/inputs.json`（SHA-256 `3f1836349d6a1566e58c85f9d5c987514db71c9ea2f83d7b909bbbf83294e8e5`；2026-11-25 取数，与 L-004 同一分段布局，含 2004-01-01、2008-01-01 假行，以及 H00016、000300 的 2004 年数据），截到 2010-12-31，调用方式与 `bt-index.mjs` 完全相同：`timingGold(bars, ratioTiming(000300, 000922), { fill: 'close' })`，从各序列第一根起跑。窗口 W、C、W′ 不变；k_i、M_i、安慰剂、降级规则 1 都在该口径下重算（安慰剂 W 首日 e 取该口径的 pos(W 首日前一天)，实测为 0）。**最终等级取主口径与本口径中较低的一个**；两者不同时注明「对单个数据日敏感」。（计数实测：两口径在 W 内择时状态 0 天不同，只有 H00905、H00991 各一个卖出日差一天。）
3. **E1 依赖声明**：E1（÷000015）按同一套判定与降级算出的等级若与主口径不同，结论写「主结论依赖回填的分母 000922」。不能据此采用 E1，也不能用来挽救结论。

## 功效（2011–2026 已用数据，`power.mjs` → `power-results.json`，计算前写入）

只用 L-018 `inputs.json` 2011-01-01 以后的部分；1,338 个交易日滚动窗口，逐月起点 2011-08 至 2021-05，共 118 个（独立约 2.9 个）；每个窗口前 120 根全新预热，窗口首日必然空仓；C′ = 窗口内 H00300 最大回撤段；H1 = 原规则，H0 = 上述循环平移安慰剂（同样仓位结构、随机时机）。有效样本：15 个指数日收益两两相关均值 ρ̄ = 0.729，N_eff = 1.34。

**大跌段构成**：118 个窗口的 C′ 只落在 3 次大跌上：2015 股灾 48 个窗口、2018 熊市 15 个、2021–24 慢熊 55 个。p_C ≤ 0.10 只在 2021–24 的窗口出现（55/55），2015、2018 的窗口一次也没有。所以 P(p_C ≤ 0.10 | H1) 等于「C′ 是慢熊型窗口」的比例，似然比 6.6 不是稳定估计，只说明规则的大跌时机在已用的三次大跌中有一次优于随机。

**读法（写进结论）**：起草人给 2005–2010 的 p_C 事前概率约 45%，依据是「2008 年更像 2021–24 慢熊」这一判断，不是统计结果。P(「部分确认」及以上 | H0) = 0.061 < 0.3，不触发「该等级不能区分择时与低仓位」的强制声明；但 P(同 | H1) 也只有 0.067，所以这两个等级本身几乎不提供证据，结论必须报告似然比。有区分力的是「未确认」（H1 下从未出现）和「择时增量未证实」档里的 p_C ≤ 0.10（似然比约 6.6）。注意：窗口高度重叠；2011–2026 没有 2006–07 式单边牛市，P(A | H1) 偏乐观；H1 只代表「规则表现得像 2011–2026 年」，不代表「规则有真实择时能力」。

## 结论分级与处理

- **确认**：可以作为把「择时 + 只认金叉」升级为「通过检验」的依据之一，必须写明「其中 11/15 为回填指数、择时分母一半为回填」；升级本身仍等影子运行 2027-05 中期复核与 2027-11 决定，**不改用户仓位规则**、不进 `/invest/start`、`/invest/my-plan`，不输出买卖指令。
- **部分确认**：影子运行照常；实验页写「2005–2010：同仓位下回撤改善成立，收益代价未确认」，并写出 #P / #D / #X 与 p_C。
- **回撤门槛通过、择时增量未证实**：与「未确认」同样处理；实验页写「2005–2010：回撤改善可由平均仓位较低解释，择时增量未证实」（附子标签）。
- **未确认**：影子运行照常；实验页写「2005–2010 未确认」。
- 后三档都适用 LEDGER 规则 3：90 天内不在 2005–2010 数据上预注册该规则的参数变体（换比值、换均线、换 MACD 参数、加过滤等）；E1 与各敏感性不能据此采用。
- 不论等级：计算后把「15 个中证全收益指数与 000300 / 000922 / 000015 的 2005–2010 年」加进 LEDGER「已用掉」清单；页面改动由 manager 另行安排，本研究不改 src / public。

## 事前预期（起草人，计算前；已看过计数与 2011–2026 功效结果）

- **D**：13–15/15（规则 C 段持仓 15–36%）。
- **A**：3–8/15。2006–07 年大牛市里规则持仓天数只占 20–59%，又频繁被死叉洗出，预计大幅跑输；能否靠 2008 年少亏追回，取决于 2009 年反弹抓到多少。#P：3–8。
- **#X**：2–7（功效 H1 中位 4）；P(#X ≥ 8) 约 15%。2008 年是一年期的持续下跌、中间多次反弹，形态比 2015 股灾更接近 2021–24 慢熊，所以 p_C ≤ 0.10 的概率约 45%。
- **W 年化波动低于 M_i 的指数**：0–2 个。理由：0/1 持仓在同样平均仓位下，波动约为 √k·σ_持仓期，静态 k 仓位约为 k·σ；k ≈ 0.37 时前者约是后者的 1.6 倍，除非持仓期本身明显更平静；2011–2026 功效窗口里这一项全部为 0。**这一项直接回答用户目标，结论首段必须写。**
- **等级概率**：确认约 5%；部分确认约 10%；回撤门槛通过、择时增量未证实约 80%（其中子标签 p_C ≤ 0.10 约 40%）；未确认约 5%。
- 分组：大盘蓝筹 / 红利组 P 比例低于中小盘 / 周期组的概率约 55%。
- 现金计息版：预计让 #A 增加 2–5 个，有约 30% 的可能跨过 #P ≥ 9 的边界。

## 实现与复核

- **主实现** `run.mjs`（本目录，Node，直接调用 `strategies.mjs`），依次断言：① raw 文件 SHA-256 与 SOURCES.md 一致；② 由 raw 清洗得到的数据与 `inputs-clean.json` 逐值相同、其 SHA-256 与本文一致；③ 交易日历 1,458 根、W 1,338 根、C 259 根、W′ 637 根；④ `strategies.mjs` SHA-256；⑤ L-018 `inputs.json` SHA-256。输出 `results.json` 与 `RESULTS.md`。
- **独立第二实现** `replication/run.py`（不同执行器、独立代码，不读主实现的任何中间产物，不 import `strategies.mjs`）：从 raw 独立清洗，再与 `inputs-clean.json` 逐值对比；raw 不在时以 `inputs-clean.json` 为输入并注明。逐项独立实现并核对：
  - 假行剔除、重叠日断言、共同起点 2004-12-31；
  - 比值均线（与 `q.reduce` 相同的从旧到新求和顺序）、严格大于、不足 20 个比值无定义、从未有状态视为牛；
  - MACD 初值与金叉 / 死叉定义；预热 120；挂单次日执行不复查牛熊；卖出成交当天又是牛市金叉可挂新买单；买入成交当天死叉 → 次日卖；窗口末挂单不执行；两边各 0.1% 成本；现金 0；
  - `windowStats`：年数 ÷ 365.25、年数 ≥ 1 才给年化、回撤从区间首日净值起算；
  - k_i 分母、M_i、年化波动（ddof = 1、√252）、X_i、X_i′；
  - 安慰剂（确定性枚举，p 值应逐位一致）、择时滤网安慰剂、`macdOnly`；
  - **L-004 布局口径**，含 H00016 在 2004 年的交易与 000300 / 000922 的 2008-01-01 假行；
  - 现金计息版、死叉次日卖版、E1、C′ 上证综指日期。
- **近似并列**：两边都输出 |比值 − 均线| / 均线 < 1e-12 的日子和 |DIF − DEA| < 1e-12 的日子；若其中有决定成交的日子，单独列出并说明两边是否一致。
- **容差**：`windowStats` 的输出是百分数，年化、回撤、区间收益、波动的绝对差 ≤ 1e-8 个百分点；k_i 的绝对差 ≤ 1e-10；布尔判定、个数、等级、p 值与成交日必须完全相同。另与 `count-results.json` 的买卖次数核对（注意其持仓占比分母是 2005–2010 全年 1,457 天，与 k_i 不同）。
- 两套实现一致只证明代码没写错，不证明结论可靠（LEDGER 规则 5）。
