- 脚本：`replication/run.py`（Python 3.12 + numpy）。运行：`uv run --python 3.12 --with numpy python -I replication/run.py`，约 15 秒。
- 输出：`replication/results.json`（`headline` 是摘要，其余字段按 PREREG 用词）。

## 三、对 PREREG 的解释（每一处）

1. **安慰剂 E(0) 与成本**：PREREG 写 E(−1) = 1，递推只对 u ≥ 1 定义。我取 E(0) = 1；若 e^s(1) ≠ e^s(0)，第 0 天收盘成交，E(0) 再乘 0.999。W 年化用 `windowStats` 的口径，即 E(L−1)/E(0)，所以第 0 天的这笔成本**不进入**区间收益。这样 s = 0 时才与 `timingGold` 的 `windowStats` 一致。另一种读法（从 E(−1) 起算）会让一半左右的平移在 Ā^s 上多扣 0.1%。这只影响 p_A，不影响 p_C（C 段在 W 内部）。
2. **安慰剂 #X^s 用规则的 M_i**：PREREG 写「#X（安慰剂对 M_i）」。我用规则自身的 k_i 算出的 M_i（年化与 C 段回撤），**没有**按平移后的暴露重算 k。平移后的 k 只差一个元素：u = 1..L−1 覆盖了除 e(s) 以外的全部 e。
3. **安慰剂回撤**：C 段回撤与 `windowStats` 相同，从 C 首日的 E 起算，按日更新峰值；15 个指数用同一个 s；p = (1 + #{统计量^s ≥ 规则}) / 1214。
4. **L-004 布局的窗口长度**：L-018 数据带 2008-01-01 假行，所以该口径下 W 有 **1,339 根**（C 有 260 根），不是 1,338。PREREG 写「窗口 W、C、W′ 不变」，我理解为日期不变，假行照常作为一根参与（与 `bt-index.mjs` 相同）。k_i 取 t = 2..1339，安慰剂 L = 1339。**平移量仍按 PREREG 字面取 63..1275（1,213 个）**，没有改成 63..1276。W 首日前一天的 pos 实测 15 个指数都是 0，与 PREREG 相同。
5. **L-004 布局的比值**：按分母 000922 的行迭代，只在分子有非零收盘的日子计算（与 PREREG「比值只在两个价格指数都有收盘的日子计算」相同）。所以 000922 的 2004-01-01 假行与 000300 的 2004-01-01 行相除，进入了比值队列；000300 的 2004 年其他行不进入。择时状态在 W 内与主口径 0 天不同。
6. **W′（降级规则 1）**：k_i′ = W′ 内 t = 2..637 的 pos(t−1) 均值；M_i′ 从 W′ 首日 = 1 起重算；规则用全程同一条净值，按 `windowStats` 在 W′ 上取年化与最大回撤；X_i′ = 年化 ≥ 且回撤不深于。
7. **E1 的降级**：L-018 `inputs.json` 没有 000015，L-004 布局（规则 2）对 E1 无法计算，所以 E1 只用主口径加规则 1。E1 等级与主口径等级、最终等级都比较过，相同。
8. **C′（上证综指日期）**：用 C′ 同时替换 D 的区间、X 的回撤腿和 p_C 的区间。#D、#X、p_C 都不变。规则 D̄ 与主口径完全相同（各指数规则在 C 段的最低点都在 2008-10-28 之前）。
9. **现金计息（歧义）**：PREREG 写「空仓日按当日有效的利率计息，两交易日之间按日历天数 × 年利率 ÷ 365 累计」。我用的主读法 `rateOnDay_t`：持现金度过 (t−1, t] 时，现金乘以 1 + 天数 × 利率(t 日有效) / 100 / 365，单利、逐交易日复利。另报两种读法：`perCalendarDay`（每个日历日用当天有效利率）、`rateOnDay_t-1`（用 t−1 日有效利率）。三者 H00300 W 年化相差约 0.002 个百分点，#A、#P、#X 完全相同。利息在挂买单成交当天先计（现金持有到当日收盘），卖出成交当天不计。一直持有不计息。「M_i 也计息」：M_i 每日收益 = k·r_hold + (1−k)·r_cash。现金计息版的 P 用主口径的 D（另报计息规则自身的 D，结果相同）。
10. **死叉次日卖版本**：持仓遇死叉一律挂次日收盘卖，其余不变（包括卖出成交当天若又是牛市金叉可以挂买单）。X 用该版本自己的 k、M。
11. **择时滤网安慰剂的 #X**：PREREG 只写「报告 #X」。我报两种：`X_ownK`（每次重跑用自己的 k 重算 M，与判定里 X 的定义相同）和 `X_ruleM`（用规则的 M_i）。#D 用一直持有的 C 段回撤（与平移无关）。
12. **指数级 p**：报告 (1 + #{dd^s ≥ dd_rule}) / 1214，以及低于规则的份额与分布分位。
13. **按自然年**：年度收益以上一年最后一个交易日收盘为基准（2005 年以 W 首日 2005-07-06 为基准），M_i 用 W 全程的 M 曲线。买卖次数按成交日（pos 变化日）计；持仓占比是年内（W 内）收盘持仓天数占比。
14. **分段贡献**：对数收益差 = ln(规则末/首) − ln(持有末/首)，以及对 M_i 的差。区间首末日按 `windowStats` 取。另给 W 全程的值作对照。
15. **发布后 / 回填**：(a) W′ 段 15 个指数的 X′、k′ 直接取降级规则 1 的值。(b) n = 4 的发布后子集：H00300、H00016 用 W，H00905 用 2007-01-15 至 2010-12-31，H00922 用 W′。每个窗口内重算 k 与 M，报告窗口年化、窗口最大回撤（X 按 X′ 的结构）；C 段完整在窗口内时（H00300、H00016、H00905）另报按主口径定义（C 段回撤腿）的 X。(c) 回填段 2005-07-06 至 2008-05-23 全部 15 个，结构同 (b)：X 10 个（年化腿 12，窗口回撤腿 10）。(d) C 段拆两段：规则、持有、M_i（W 全程 M）的区间收益与区间最大回撤。
16. **「区间回撤」**：PREREG 第 4、5 条的「区间回撤」，我同时给区间收益 `total` 与区间内最大回撤 `dd`，由 manager 选用。
17. **四次大跌并列**：2015、2018、2021–24 取 `power-results.json` 中 `H1.byEpisode` 的中位数。「优于随机」：2008 年看 p_C ≤ 0.10，其他三次看 p_C 中位 ≤ 0.10。
18. **近似并列**：比值 |ratio − ma| / ma < 1e-12 的日子没有。|DIF − DEA| < 1e-12 只有每个指数的第 0 根（2004-12-31，DIF = DEA = 0，这是初值决定的）。它只影响第 0、1 根的交叉判断，两根都在预热期内，不可能决定成交。
19. **W 年化波动**：日简单收益 t = 2..1338（1,337 个），样本标准差（ddof = 1）× √252，输出为百分数。
20. **「W 年化波动比静态持有低」**：PREREG 第一句的「静态持有」我理解为同平均仓位静态对照 M_i（`volLowerThanM`），结果是 0 个；另报对一直持有的个数（`volLowerThanHold`），是 15 个。

## 四、发现的 PREREG 与代码不一致或需留意之处

- **以下各处 PREREG 与 `strategies.mjs` 没有实质不一致**：MACD 初值、交叉条件、`ratioTiming` 的 `if (!av) continue`（分子收盘为 0 或缺失都跳过）、`q.reduce` 求和顺序、`timingGold` 的先执行挂单后判信号、「买入成交当天死叉 → 次日卖」（`buyIdx === i`）、`windowStats` 的 i0 / i1 取法（`findIndex(date > to) − 1`）、年数 ÷ 365.25。我独立实现的结果在 s = 0 自检、`count-results.json` 买卖次数、DATA.md 的 L-004 布局成交差异上都对上了。
- PREREG 的「卖出成交当天若又是牛市金叉，可以挂新的买单」在代码里只对**挂单卖出**（买入当天死叉的次日卖，以及死叉次日卖版本）成立。当日收盘卖出走的是 `else if` 分支，同一天不可能再挂买单。不过同一天既死叉又金叉本来就不可能，所以实际没有差别。
- PREREG「容差」节要求布尔、个数、等级、p 值、成交日完全相同。在 L-004 布局下，k_i 的分母是 1,338（不是 1,337），这是 PREREG 没有明说的地方（第 4 条），两边实现可能不同。我的 L-004 p_X = 0.00906，与主口径的 0.00824 不同，原因就在 L 不同。
- `macdOnly` 默认预热 60，从第 0 根起跑，所以 W 首日可能已经持仓；`windowStats` 会归一化。我照此实现，没有另做 W 起点空仓处理。
