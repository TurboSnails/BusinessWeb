# BTC 单币择时研究（L-039）

**旧史不通过**（趋势策略绝对年化波动率 82.62%，最大回撤 72.62%）。趋势策略的最大回撤比同波动参考浅 8.94 个百分点，但相对直接持有的波动降幅为 7.79%，低于预注册的 15% 门槛。

即使通过，波动仍远高于美股；本研究不评估把 BTC 加入组合的影响，不构成配置或杠杆建议。

## 偏离与澄清

1. 冻结后补录 FRED 的 3 个月期国债利率原始 CSV 并登记 SHA-256，仅用于现金利率敏感性。
2. 永续手续费和滑点各为每边 10 个基点。半权益代理逐腿分配初始资金和隔离保证金。触线时该腿保证金归零，待出现新的入场信号后，用该腿剩余权益开仓。开仓按目标仓位分配初始保证金并扣除手续费，按成交价计的名义头寸等于初始保证金乘以杠杆倍数。
3. 历史自助法保留抽中原日的成交条件、成本、月调回标识及趋势策略收益，每次从美元现金重建月调回参考，分位数用线性插值。
4. 晚一天口径首日尚无到期信号时持现金，等待首次已到期的信号。

主判定沿用冻结预注册。以上口径由协调者在看绩效前确认。 [预注册](PREREG.md) · [口径澄清](CLARIFY-1.md) · [冻结来源清单](../../../data-raw/crypto-trend/SOURCES.md)

## 局限

旧史的早期交易稀薄，开盘成交是连续交易市场的理想化近似。均线规则和早年周期早已为人所知，样本由少数周期主导。链上读数是当前历史版本，缺少逐日的历史首印。永续日低与资金费结算的先后只能通过情景近似。既定前推尚未揭盲。
