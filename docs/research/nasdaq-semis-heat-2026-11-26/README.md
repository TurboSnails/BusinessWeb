## 一句话

**四种「超配」口径都没有预测力：纳指、半导体过热或拥挤的时候，之后一年并没有更差，回撤也没有更深。** 科技股、电子设备的市值占比处于高位之后，收益反而略好，只是统计上不显著。美银基金经理调查只有当期读数，无法检验。

## 主判定（目标为各自资产的未来 12 个月）

| 指标 | 区间 | 斜率 β | 循环平移 p（下尾 / 上尾） | 高位五分之一：收益差 / 最差点差 | 两半 β | 结论 |
|---|---|---:|---|---|---|---|
| N1 纳指相对 200 日均线 | 1976–2025 | −0.029 | 0.42 / 0.58 | +0.2 / +1.2 个百分点 | −0.08 / +0.02 | 没有预测力 |
| S1 费城半导体相对 200 日均线 | 2000–2025 | −0.083 | 0.33 / 0.67 | +2.3 / +4.3 | −0.19 / −0.22 | 没有预测力 |
| N2 科技股占美股市值 | 1978–2025 | +0.139 | 0.89 / 0.11 | +9.4 / +1.5 | +0.12 / +0.18 | 没有预测力 |
| S2 电子设备占美股市值 | 1978–2025 | +0.138 | 0.91 / 0.09 | +11.9 / +2.6 | +0.10 / +0.19 | 没有预测力 |

- 「最差点差」为正，意思是高位之后一年里的最大跌幅反而**更浅**。
- N2、S2 的斜率为正（高位之后更好），上尾 p 经 Holm 校正后 0.36，不显著，所以不写「反而更好」。
- S1 两半的斜率都为负，但幅度和显著性都远不够；而且 S1 的检验从 2000 年开始，第一段高位正是泡沫顶。
- 回撤斜率（只报告）四个都为正，下尾 p 0.58–0.95：高位不预示更深的回撤。

**N3 资管机构纳指期货净多**（探索，2013–2025，只有 150 个月）：β +0.06，下尾 p 0.69，同样没有预测力。

## 以标普为目标（只报告，雷达计分变体 2027-02-24 前不能在标普数据上检验）

四个指标对标普未来 12 个月的斜率分别为 −0.001、+0.075、+0.098、+0.037，高位之后标普的收益与回撤都不更差。

## 结论与落地（按预注册）

1. 四个都「没有预测力」，**作为只展示指标加进市场雷达**（「科技与半导体」一组），说明里写明本研究结论；不进计分。
2. 美银基金经理调查的科技净超配照常展示当期读数，无法回测。
3. 读法：科技与半导体的集中度和过热，是值得知道的背景（集中度高意味着大盘更依赖少数行业），但不能用来择时。

## 局限

- S2 是 Ken French 的 Chips 行业，口径比半导体宽（含通信设备、防务电子）。
- SOX 只有 Yahoo 一个完整来源；KF 每年 7 月重新归类；5 个百分点的门槛没有按各资产波动缩放。
- 文献（Greenwood、Shleifer、You 2019）说行业大涨后崩盘概率上升；本研究的回撤指标没有看到这一点，但样本里真正的行业崩盘只有 2000 年一次左右。
