## 2. 逐日定位（任务第 1 项）

**方法**：以主实现 `daily/validate_*.csv` 为准，第二实现三种执行顺序各跑一遍，找出每个组合第一次出现 >1e-10 差异的日期，再在那一天从相同的成交前状态出发，单步比较各顺序。

**第一次差异日（验证段，> 1e-10）**：

| 组合 | 严格留现金（主口径） | 转给其他目标（allocate） | 主实现顺序（capfirst） |
|---|---|---|---|
| B0 | 2015-01-05 | 2015-04-01 | 无 |
| B1 | 2015-01-05 | 2015-04-01 | 无 |
| C1a | 2015-01-05 | 2015-01-05 | 无 |
| C1b | 2015-01-05 | 2015-08-03 | 无 |
| B2p | 2015-01-05 | 2015-01-05 | 无 |
| B2b | 2015-01-05 | 2019-04-01 | 无 |
| B4 | 2015-01-05 | 2015-06-01 | 无 |

（留现金口径从验证段第一天就不同，因为 2015 年前累积的持仓状态已经不同。）每个第一次差异日都是调仓成交日，当天的换手、成本、毛收益同时出现差异；非调仓日的差异只是延续前一调仓日的持仓差异。现金收益两边都是 0（第 5 条），在三种口径下都不是差异来源。

**代表性日子（从相同的成交前状态出发）**：

| 日期 / 组合 | 当天情形 | 主实现顺序（先截断后缩放） | 严格留现金（先缩放后截断） |
|---|---|---|---|
| 2015-01-05 / B0（信号 2014-12-31） | 601766 目标 0.232%、002346 目标 0.003%，都是一字涨停（开 = 高 = 低 = 收、limit_up）；210 只锁定股（停牌）合计权重 3.37%，其目标权重只有 0.18% → 剩余目标超预算 | 缩放系数 0.97030，成交后**满仓 100.000%**，买不进的 0.235% 被摊回其他目标；换手 0.017973 | 缩放系数 0.96804，成交后 99.775%，0.225% 留现金；换手 0.018201 |
| 2015-01-05 / C1a | 同上两只买不进（C1a 当月是 B0 槽位）；锁定 210 只，权重 3.06% | 满仓 100%；换手 0.018562 | 99.775%；换手 0.019038 |
| 2019-04-01 / B2b | 600155 目标 0.194% 一字涨停；**无锁定** → 不超预算 | 99.806%（买不进的部分留现金） | 99.806%，两种顺序相同；这一天主实现与「留现金」一致、与 allocate 不一致，正是 allocate 版 B2b 的第一次差异日 |

**归纳**：
- 只有「超预算」的调仓日两种顺序才会不同。超预算 = 锁定持仓（停牌 / 一字跌停）的现权重 > 其目标权重 + 买不进目标的权重。
- 2015 年停牌潮期间这种情况几乎每月都有，所以留现金口径与主实现差得最多：B2p 的 2015-12-22→2016-01-28 急跌段收益差 1.7e-2；B2′ 验证段最大回撤 −0.5369 vs −0.5483。
- 这不是主实现代码缺陷，而是规则表述留下的顺序歧义。

**manager 已裁定（CLARIFY-2 第 11a 条）为 (a) 严格留现金**；当时的待裁定表述：超预算的调仓日里，一字涨停 / 执行日停牌买不进的目标权重，应当
- (a) **严格留现金**：第二实现主口径。符合第 11 条「不转给其他目标」的字面；但锁定持仓超出的部分要靠缩小其余目标来腾出预算，同时又有现金闲置。
- (b) **先截断再缩放**：主实现现行顺序。超预算时买不进的权重被缩放吸收、组合满仓；效果上等于在那些日子把这部分权重转给了其他目标。

裁定只影响执行层数字和 C1a 判定 4 的读数（a 不过 / b 过），不影响分级。裁定后：选 (a) → 主实现改顺序；选 (b) → 第二实现把 `results-capfirst.json` 改作主口径（当时已与主实现逐位一致）。最终选 (a)，主实现已改。
