# 预注册：A 股「6 月相对强 + 成交额集中 + 行业 PE 自身分位」（L-052）

登记号：**L-052**（LEDGER 已预留）。日期：2026-11-28。版本：**v3**（独立审稿 REVIEW-1 全量必改）。状态：**草案 / 冻结后才允许计算任何持仓收益**。

## 问题

用户原话：市场总有一段时间的主要题材与主要矛盾，结合 PE 高度制定策略。总目标：只做多、同等暴露下降低波动、可靠优先。

确认候选：**C1a**（持续主线 + PE 过滤）、**C1b**（每月主线 + PE 过滤）。Holm 族 = {C1a, C1b}。

**先讲结论口径（给用户的第一句必须是这个）**：本研究检验的是申万一级行业的「6 个月相对强 + 成交额集中 + 行业 PE 自身分位过滤」，不是题材或概念本身（AI、机器人这类主线跨越多个一级行业）；C1a / C1b 结构上集中持有 1–2 个行业，不是降波动写法；验证段不是样本外；已退市股票不在行业篮子里；整行业篮子普通账户难以执行，行业 ETF 多跟踪中证指数且大多 2013 年后才有。第一句之后再报：相对覆盖池 B1 的年化波动与最大回撤、急跌段 L、夏普、同波动对照 B1\*、以及对 B2′ / B4 的增量拆分。

## 数据与口径

- **预热**：价格/行业/成交额/财报从 **2000-01** 加载；计数与判定窗口仍 2005-01…2023-10。
- **覆盖池**：当日有有效价格且有点时行业归属的股票。全部组合（含 B0）只用覆盖池；另报「全市场 B0 − 覆盖池 B0」作幸存者偏差。成交额占比分母 = 覆盖池合计。结论注明行业收益偏乐观（已退市股多无行业）。
- **申万映射**（`sw_canon.py`）：1:1 见文件；**建筑建材不映射**；采掘/信息服务/信息设备/交运设备/金融服务不映射。2014-02-21 前启用名称出现视为回填。
- **收益权重**：行业日收益用 **t−1 收盘 `mcap_float`** 加权；个股收益以前一有效收盘为基准（停牌涨跌计入复牌日）。月内持仓按信号日收盘 mcap_float 定权后漂移，月内新上市不加入。
- **PE**：分子只用 **`mcap_total`**，只对同时有 mcap_total 与 `fin_ni_ttm` 的股票求和，**不回退 float**；分母 TTM = `fundamentals_cn` 的 `fin_ni_ttm`（最近一期累计 + 上年年报 − 上年同期；缺任一项则无）。行业合计 NI≤0 → 无正 PE。历史分位：用 **t 时成分**回溯过去最多 60 个有 PE 月末（≥36）；跳过三类分别计数：分位>0.90 / 历史不足 / NI≤0。A/H 溢价为已知局限。
- **样本**：探索 2005–2014（行业非点时，**不设通过门槛**）；验证 2015–2023-10（主判定）。
- **锁箱**：`unseal('cn', batch_id, [冻结提交哈希], ['L052-C1a','L052-C1b'])`；脚本 sha256 + 参数哈希；经带凭证 `load_market`，禁止 `raw=True`；每候选只跑一次，两实现同凭证各一次，记 `data_access`。校正族 = **同一解封批次全部候选**。L-052 **不进 2026Q4**，最早 **2027Q1**。记录 prices / fin_pit / industry_pit 的 MANIFEST sha256（本机 fin_pit 与 L-038 冻结版若 MISMATCH 须写明）。锁箱门槛：σ ≤ σ(B1) 且回撤不比 B1 深 1 个百分点以上且 ΔS ≥ ½ × 验证段收缩估计（验证段 ΔS≤0 时 ≥ −0.02）；显著性只报告。

## 规则

### C1a 状态机（伪代码）

```
prev_topk ← ∅; active ← ∅   # active=主线集合；held=PE 过滤后持仓；二者不同
每月末 t：
  在「资金集中且成员≥5」的行业中按 rel6 降序排名（并列：average 秩 + sha256("tie:"+名)）
  topk ← 名次 ≤ K 的集合
  enter ← topk ∩ prev_topk          # 连续两月进前 K 才进入 active
  still ← {i ∈ active : 名次(i) ≤ 4 且仍在排名表}
      # 资金集中失败 → 不在排名表 → 立即退出（无缓冲）
  active ← still ∪ enter
  pool ← active 按当月名次排序（缓冲不保护「超过 K 的名次优先」；取持仓时按名次）
  held ← 按 pool 顺序，跳过（分位>0.90 | 历史不足 | NI≤0），最多 K 个
  # 被 PE 跳过但仍在 active 的行业：下月若仍在 still/enter，可不再重新满足「新进入」而直接参与 PE 检查买回
  # 持有中分位升到 >0.90：本月不进入 held，权重归顺延或 B0
  每个持仓槽权重 = 1/K；若 |held|=1 → 50% 该行业 + 50% B0；|held|=0 → 100% B0
  prev_topk ← topk
首月：prev_topk=∅（无进入）
K=1/3 敏感性：退出名次 = max(4, K+2)
```

- `rel6`：过去 126 日行业累计 − 覆盖池等权累计。  
- 资金集中：`share60` > 自身 250 日均值（≥120 有效日）；金额均在覆盖池内。

### C1b

- `rel3`+`rel6` 综合分；资金集中用 20/250。  
- 顺延只在综合排名前 **2K=4** 内，不足归 B0（v3 相对 v2 收紧，**算收益前修订，已写入已知信息**）。

## 度量与执行

- 回测：按**个股目标权重**（行业权重 × 行业内 float 权重）；本金 **100 万元**；计最低佣金与整手；`open_adj` 次月首日开盘成交；一字涨停买不进的权重持现金到下个调仓日，跌停卖不出继续持有；持有期停牌冻结。B1 每月调回等权并计成本；B0 买入持有并处理覆盖池成分变动，同样计成本。无风险利率：中国一年期定存月度折算（冻结时钉死序列）。  
- 同波动对照 B1\* = k·B1+(1−k)·现金，k=σ(候选)/σ(B1)。  
- 急跌段：覆盖池 B0 日度总收益指数，折线法（低点反弹≥20% 后再跌算新段），取跌幅≥20% 的段并逐段列出；L 改善超过 50% 来自单一段 → 最高「部分成立」。

## 判定（验证段；探索段只描述）

### 「通过」（C1a/C1b 各须全部）

1. 验证段年化波动 ≤ B1 **且** 最大回撤不比 B1 深超过 1 个百分点；同波动对照下夏普 ≥ 夏普(B1\*) − 0.02。  
2. L(候选, B1) ≤ 0.95。  
3. 验证段夏普 ≥ 夏普(B1) − 0.02。  
4. PE 增量（对 B2′）：回撤浅 ≥ 2 个百分点 **且** 夏普 ≥ 夏普(B2′) − 0.01。  
5. 主检验：随机行业安慰剂的 **L 单边 p**，Holm（族 {C1a,C1b}）后 **≤ 0.10**；否则最高「部分成立」。  
6. 扣成本后仍成立。

### 统计与功效

- 随机行业安慰剂：保持 C1a 每段起止月、持有个数、空缺月不变，每段开始从当月可排名行业无放回随机抽同样个数持有到段结束，1000 次，种子 20261128；p=(1+#{优于实际})/(1+N)；波动、回撤、L、夏普分报。  
- 另报选择序列整体循环平移安慰剂；bootstrap 块长 6/12/24。  
- **功效（冻结前）**：验证段约 106 月、C1a 有持仓约 75 月。若真 L 改善 0.05、月收益相关 0.3，块 bootstrap 双侧 10% 功效粗估约 25–40%（待实现时用模拟精确写进 results）；**真实有效时「通过」概率事前预期约 15–25%（C1a）、10–20%（C1b）**。锁箱 36 个月功效更低，故锁箱以幅度门槛为主、显著性只报告。
