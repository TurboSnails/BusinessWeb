## 1. 问题与事前预期

- **A. 预测力（主问题）**：哪些估值指标对标普 500 未来 1 / 3 / 5 / 10 年超额收益有**样本外**预测力？
- **B. 可交易性（次问题）**：把证据最强的估值思路做成**小幅连续**仓位倾斜，扣成本后是否优于同平均仓位恒定组合？

事前预期（依据 Goyal–Welch–Zafirov 2024、Campbell–Thompson 2008、Boudoukh–Richardson–Whitelaw 2008）：1 年期 OOS R² ≈ 0；5–10 年期为正，但因不重叠样本极少，显著性脆弱；B 部分大概率"未证实"。

## 3. 预测目标

月度采样。第 t 月目标：未来 h 个月标普 500 **对数超额累计收益**
`Y_t(h) = Σ_{k=2..h+1} [ln(1+r_{t+k}) − ln(1+rf_{t+k})]`，h ∈ {12, 36, 60, 120}。
r 为 v1 定义的月总回报（Shiller 月均价）。目标窗口从 t+2 月开始（与 v1 跳月一致，规避月均价自相关）。Y_s(h) 在第 t 月"已实现"当且仅当 **s ≤ t − h − 1**；训练样本、历史均值基准、预测区间残差一律只用已实现标签。

## 4. 主预测变量（4 个）

| 代号 | 名称 | 第 t 月取值 |
|---|---|---|
| P1 | CAPE 收益率 | 1 / CAPE_t（CAPE 按 v1 自算口径） |
| P2 | ECY | 1/CAPE_t − real10_t；real10_t = GS10_t/100 − π̄_t，π̄_t = 截至 t−1 月的过去 120 个月 CPI 年化通胀 |
| P3（探索性） | AIAE 代理 | (NCBEILQ027S + FBCELLQ027S) / (NCBEILQ027S + FBCELLQ027S + FGSDODNS + CMDEBT + BCNSDODNS + DODFFSWCMI + SLGSDODNS)，单位统一后计算，按第 2 节规则前向填充到月 |
| P4 | 分项求和 SOP（Ferreira–Santa-Clara 2011，固定系数） | 年化对数预期超额收益 SOP_t = ln(1 + D12_t/P_t) + g_t − ln(1 + TB3MS_t/100)。D12_t = Shiller 的 D（已是年化股息，**不再累加**），取滞后 3 月的值 D_{t−3}；P_t 为当月价格；g_t = [ln(E_{t−3}) − ln(E_{t−3−240})]/20（过去 20 年名义 E 年化对数增长） |

**组合基准 PC**（Rapach–Strauss–Zhou 2010）：P1、P2、P4 预测值的等权平均（P3 为探索性，不纳入；另报含 P3 的版本）。

## 5. 预测方法

- P1–P3：扩张窗口 OLS，`Y_s(h) = α + β·X_s + ε`，只用已实现样本（s ≤ t − h − 1）。至少 240 个已实现样本才开始预测。
- P4：不回归，预测 = h/12 × SOP_t（对数近似）。
- Campbell–Thompson 约束（P1–P3）：β 符号与理论不符（P1、P2 应 β>0；P3 应 β<0）时用历史均值；预测值 < 0 时截为 0。
- 历史均值基准：截至 t 已实现的 Y(h) 的扩张均值。

## 6. 评估

- **共同 OOS 窗口**（主）：预测月 1985-01 起，至 Y(h) 可实现的最后一个月。所有变量同窗口比较（受 AIAE 起点与训练期约束）。
- **长窗口**（次）：P1、P2、P4。起点按规则锁定：对每个 h，取"已实现标签 ≥ 240 个且标签所需 TB3MS 全部可得（标签窗口不早于 1934-01）"的第一个月；不回填、不缩短训练期。实际起点由脚本算出并写入报告。
- 指标：OOS R² = 1 − Σ(Y−Ŷ)² / Σ(Y−Ȳ_hist)²；同时报告不重叠窗口数。
- **显著性（主）：循环平移零分布**。把预测变量序列相对收益序列做循环平移（偏移量取 [120, N−120] 内全部整数，N 为变量有效长度），保留两者各自的自相关、打断对应关系；对每个偏移**完整重跑**标签对齐、扩张回归、CT 约束与 OOS R² 计算（P4 同样平移后直接作为预测）。单侧 p = (#{平移 OOS R² ≥ 实际值} + 1)/(偏移个数 + 1)。
- 参考（不用于判定）：Clark–West (2007) 统计量（仅 P1、P2，嵌套模型）与 Newey–West（滞后 h+1）t 值；P4 报告原始损失差的 Diebold–Mariano 型统计量。
- **多重检验**：主族 = {P1, P2, P4} × 4 周期 = 12 个检验，Holm 校正，族错误率 5%。PC、P3 与第 8 节变量另报，**不得升级为确认性结论**。
- **判定**："有预测力"须同时满足 (a) Holm 后 p < 0.05；(b) OOS R² > 0；(c) 共同窗口拆成 1985–2004 与 2005–末两段，两段 OOS R² 均 > 0。其余为"未证实"；OOS R² ≤ 0 为"无"。
- **预测区间**：用扩张窗口残差的经验分位给出 80% 区间，报告实际覆盖率（应接近 80%）。

## 7. 可交易性（B 部分，2 条规则）

执行与 v1 完全相同：月度、信号 t → 收益 t+1→t+2、成本单边 0.10%、W = 60%、无杠杆、同平均仓位恒定组合 CM 对照、平稳块自助法（块长 12、B = 10000、种子 20261115）、ΔCER（γ = 3）。评估区间：1960-01 至末月（z 分数需要足够历史）。

| 代号 | 规则 | 目标股票仓位 |
|---|---|---|
| T1 | 估值 + 动量小幅倾斜（Asness–Ilmanen–Maloney 2017） | clip(0.60 + 0.10 × (0.5·z(ECY_t) + 0.5·z(MOM_t)), 0.40, 0.80)；MOM_t = 截至 t 的过去 12 个月累计对数超额收益；z(x_t) = (x_t − 均值) / 总体标准差（/n），均值与标准差用截至 t（含）的全部有效历史，至少 240 个月 |
| T2 | SOP 预期收益倾斜 | clip(0.60 + 0.10 × z(SOP_t), 0.40, 0.80) |

倾斜幅度 0.10、上下限 0.40/0.80 事先约定，不调。若 1960-01 时某规则的 z 分数尚不可算，评估起点改为两条规则都可算的第一个月（按规则锁定，不手动选）。判定沿用 v1 第 6 节四条件，Holm 族 = {T1, T2}，子区间改为 1960–1984、1985–2004、2005–末。

## 8. 稳健性（报告，不改判定）

- 次要变量（同第 5–6 节方法，不进主族）：股息率 D12/P、市值/GDP（NCBCEL/(GDP×1000)）、Tobin Q（NCBCEL/BOGZ1FL105015005Q）、市值/GVA（NCBCEL/(A455RC1Q027SBEA×1000)）。
- 不加 CT 约束；Z.1 再多滞后 3 个月；OOS 起点 1975；T1/T2 成本 0.30%；T1 只用估值（去掉动量）与只用动量。
- P4 口径敏感性：算术版 D12/P + g_arith − rf（g_arith = (E_{t−3}/E_{t−243})^{1/20} − 1）。
- 参考检验：Clark–West + NW 的 Holm 结果，与主检验并列展示，判定以主检验为准。
