## 一句话

**期权保护确实能在急跌里少亏，但不比直接调低仓位便宜。**
- 每月买 5% 价外看跌（PPUT），17 次急跌里合并少亏 23%，判「部分成立」：少亏集中在 1987、2008 年秋、2020 年这类一两个月内的暴跌，阴跌里反而更差（逐个只赢 10/17）；同等波动下每年少赚约 1.1 个百分点。
- 换一个角度看：想在急跌里亏得和 PPUT 一样少，直接把股票调到约 46%，每年的代价和买看跌几乎相同（只差 0.08 个百分点）。
- 零成本领口（CLLZ）判「不起作用」：急跌里和同波动对照亏得一样多（L = 1.01）。

所以「急跌只能靠事先定低上限」这句话仍然成立，期权是另一种付费方式，不是更便宜的办法。

## PPUT 在哪里赢、在哪里输

逐事件（窗口内累计收益：PPUT 组合 / 同波动对照）：

- **大幅少亏**：1987（−8.7% / −20.1%）、2008 年秋（−14.1% / −26.3%）、2020（−9.5% / −21.0%）、2001 年 9 月（−8.1% / −13.1%）、2002 年夏（−12.6% / −17.2%）、2010、2011、2025。
- **反而多亏**：1990、2001 年初、2002 年秋、2007–08 年初、2009 年初（−18.5% / −16.8%）、2022 年两次。这些是一路阴跌：每月换仓时行权价跟着下移，看跌一直在价外，保费照付，保护落不到实处。
- 谷底后 60 个交易日，PPUT 几乎每次都比对照少涨（1987 年 −11.5 个百分点、2008 年 −6.9）：反弹时看跌的保费又成了拖累。

## 结论与落地（按预注册）

1. **C1 PPUT「部分成立」、C2 CLLZ「不起作用」**：只记录，不进说明书推荐。仓位规则不变。
2. 说明书第十四章（试过但没采用的办法）补一条：期权保护能在急跌里少亏，但同等少亏下与直接调低仓位一样贵；零成本领口不起作用。
3. 对用户的实际含义：
   - 想在急跌里少亏，最简单的办法仍是事先把上限定低（例如 80% 再往下调）；
   - 买看跌期权不是更便宜的办法，只是把代价从「平时少持股」换成「平时付保费」，而且在阴跌里保护不到；
   - 零成本领口在深跌里几乎不起作用，不推荐；
   - VIX 尾部对冲在 2008、2020 年表现突出，但证据只有两次，不能采用。

## 局限

- PPUT、CLLZ 1986–2015 年是 CBOE 按现行方法论做的回测；1986 年至 1990 年代初的期权成交价来源未说明（1990 年起的敏感性方向不变）。
- 股票腿股息按交易日平均分摊，指数按除息日计入，逐日层面有错位，对 60 天窗口影响可忽略。
- 标普 1986–2026 年是用过很多次的数据；事件只有 17 次，结论以方向和幅度为主，没有显著性检验。
- 我下载数据时看到过两个指数的首尾值（已在预注册披露），所以 G3 的方向事先大致知道；急跌指标没有任何先验数字。
