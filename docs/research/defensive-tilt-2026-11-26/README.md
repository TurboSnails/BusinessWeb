## 一句话

按预注册，P1（防守九行业）和 P2（低波十行业）都**通过**，按规则取合并跌幅比较小的 P2（1.002 对 1.006，实际上打平）。但要看清楚好处在哪：**在同等波动下，大跌时并没有少跌**；好处是效率，波动低约 5%、年化略高、夏普高约 0.05。它更像「更聪明地把上限调低一点」，不是一个专门躲后期急跌的工具。2012 年以后这点优势也基本没了。
