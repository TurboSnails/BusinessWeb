## 一句话

**五个新读数都没有预测力，全部 49 个行业放在一起也没有。** 罗素 2000、恒生指数、上证综指远高于 200 日均线时，之后一年并不更差；能源、金融占美股市值处在高位时，也不预示自身更差。49 个行业平均下来斜率略为负，但远不显著（p 0.47）。唯一的影子是「崩盘概率」：行业占比处在高位时，之后一年中途跌三成以上的频率从 6.3% 升到 7.6%，略高，但幅度很小。

## 主判定（目标为各自资产的未来 12 个月）

| 指标 | 区间 | 斜率 β | 循环平移 p（下尾） | 高位五分之一：收益差 / 最差点差 | 两半 β | 结论 |
|---|---|---:|---|---|---|---|
| R1 罗素 2000 相对 200 日均线 | 1993–2025 | −0.109 | 0.12（Holm 0.61） | −4.4 / +0.5 个百分点 | −0.12 / −0.11 | 没有预测力 |
| H1 恒生指数相对 200 日均线 | 1992–2025 | −0.068 | 0.31 | −8.6 / −0.7 | −0.09 / −0.04 | 没有预测力 |
| A1 上证综指相对 200 日均线 | 2003–2025 | +0.189 | 0.82 | +23.8 / +1.7 | +0.45 / −0.08 | 没有预测力 |
| E1 能源占美股市值 | 1978–2025 | −0.012 | 0.50 | −4.0 / −4.1 | +0.01 / −0.01 | 没有预测力 |
| F1 金融占美股市值 | 1978–2025 | +0.008 | 0.55 | +3.7 / +2.1 | −0.08 / −0.05 | 没有预测力 |

- **R1、H1** 方向偏负，两半也都为负，但统计上远不显著。最差点差接近 0，也就是高位之后中途并没有跌得更深。
- **A1** 高位之后一年反而平均多涨 24 个百分点，几乎全部来自 2006-01 至 2007-10 这一段（22 个高位月，之后一年平均 +79%）。其余 6 段里 4 段之后是跌的（2004、2009、2015、2019 年），所以前一半斜率 +0.45、后一半 −0.08，很不稳定。
- **E1、F1** 是因为著名的行业泡沫（1980 年能源、2007 年金融）挑出来的，挑选本身偏向负斜率，结果仍然几乎为零。去掉著名泡沫期后（只报告）：E1 去掉 1979–1982 年 β −0.036、ΔR −6.1；F1 去掉 2006–2008 年 β −0.058、ΔR +0.2，都不显著。
- 回撤斜率（只报告）：五个的下尾 p 为 0.28–0.85，高位不预示更深的回撤。

## 49 个行业的面板（P49）

1978-06 至 2025-09，568 个月，49 个行业的有效月份相同。

| 统计量 | 数值 |
|---|---|
| 平均斜率 β̄ | −0.018 |
| 共同平移安慰剂下尾 p | 0.47 |
| 斜率为负的行业 | 27 / 49（门槛 30） |
| 斜率中位数 | −0.011 |
| 按行业波动缩放后的 β̄ | −0.068 |
| 去掉科技三行业的 β̄ | −0.027（26 / 46 为负） |
| 高位时之后一年中途跌三成以上的频率 | 7.6%（其余月份 6.3%） |
| 高位对其余的收益差（汇总） | −0.2 个百分点 |

结论：**行业层面方向偏负、不显著**。斜率最负的是 Other、Steel、Toys、Fin、Fun，最正的是 Softw、Coal、Beer、Books、Chips，看不出规律。崩盘频率略高，与 Greenwood、Shleifer、You（2019）「大涨后崩盘概率上升，但平均收益不一定更低」的说法方向一致，但只多 1.3 个百分点。

## 结论与落地（按预注册）

1. 五个都「没有预测力」，P49「行业层面方向偏负、不显著」，没有任何一项登记为待确认候选。
2. 五个读数**作为只展示指标加进市场雷达**，说明里写明本研究结论，不进计分。占比同时显示绝对值和近十年百分位；200 日乖离写成「高于 / 低于均线 X%」，不标「过热」。
3. 新设锁箱 B-6：KF 49 行业 1926–1973 年的市值占比读数，本研究没有计算，留给将来确认。
4. 读法：和 L-032 一样，某个市场、某个行业「热」，是值得知道的背景，但不能用来择时。

## 局限

- 三个指数都是价格指数（不含息），对同一资产内的斜率影响很小。
- 上证综指在 Yahoo 只有 1997 年以后的数据，检验从 2003 年开始，只有 272 个月。
- 5 个百分点的门槛没有按波动缩放（A 股、港股波动远高于美股）。
- 审稿用合成数据核对过，P49 的共同平移检验会多报显著（名义 5% 实际约 9%）。本次 p 0.47，不受影响。
