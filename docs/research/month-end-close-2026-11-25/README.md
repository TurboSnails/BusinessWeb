## 结论

**按预注册措辞：月末收盘口径下结论不变。** 主口径 E1（次月第 3 个交易日收盘成交）下，本策略夏普比恒定七成高 0.13，最大回撤浅 14.8 个百分点。

1. **换成能成交的价格，所有方案的夏普都下降约 0.1，排序不变。** 本策略 0.71 → 0.59，恒定七成和全程持有 0.55 → 0.46，十个月均线 0.64 → 0.53。月均价把波动压低了约两成，页面上的夏普偏高，但对各方案的影响差不多。
2. **按月净值算，最大回撤从 −20.0% 变为 −24.4%。** 恒定七成从 −36.6% 变为 −39.1%，全程持有从 −49.0% 变为 −52.0%。
3. **按日净值算，本策略最大回撤约 −33%，发生在 2020 年 2–3 月。** 月度规则来不及反应一个月内的暴跌：2020-02-19 到 03-23 这 23 个交易日里，策略基本还在原来的仓位上。同期十个月均线也是约 −34%。恒定七成按日最大回撤约 −41%（2007–2009），全程持有约 −55%。**按日算，本策略比恒定七成只浅约 8 个百分点，而不是页面上的 17 个百分点。** 说明书里的「最大回撤 −20%」要理解为月均价口径下的数字，真实持有时可能经历三成左右的账面回撤。
4. **执行时点不敏感。** 月末当天成交（E0，做不到的上限）、次月第 3 个交易日（E1）、晚一个月（E2），本策略年化 10.2%–10.3%，夏普 0.59–0.60，回撤 −19.7% 到 −24.4%。
5. **统计显著性和原来一样处在边缘。** E1 下相对恒定七成，夏普差 +0.13，分块自助法 95% 区间 −0.012 至 +0.262，p = 0.07；相对十个月均线，夏普差 +0.06，区间 −0.015 至 +0.132，p = 0.11。都不显著。

## 数据核对中发现的问题

用日收盘算出的月均价与回测用的月均价逐月比较：除一个月外，1950 年以来每个月的偏差都不超过 0.4%，1980 年以后不超过 0.31%；例外是 **1974-07，偏差 4.42%**。原因是 `data-raw/sp500-backtest/shiller.csv` 这一行的价格 79.31 是 1974-07-31 当天的收盘价，不是当月均价（日收盘均价 82.82）。

- 影响：按本目录的输入重算，页面四个方案的年化、回撤不变，夏普最多变化 0.0006（假定档位不变；82.82 仍远低于当时的十个月均线，均线判断不会翻转）。
- 后续核对：席勒官网当前版本的 ie_data.xls 这一行同样是 79.31，Multpl 转载的也是这份数据，所以错误在源头。
- 处理：`data-raw/sp500-backtest/shiller.csv` 保持与源文件一致（它也是此前研究的输入），改正写在 `scripts/macro-posture.mjs` 的 `PRICE_CORRECTIONS`，不论数据取自 Multpl 还是席勒快照都统一生效，同月股息率按同一价格换算；来源自己改正后自动不再生效。本目录的结果仍用改正前的快照（`inputs.json`），以便与页面和此前研究逐项对照。

## 局限

- 档位规则是看着这段历史定的，换收益口径只检验「计算方式有没有美化结果」，不能回答规则在未来是否有效。
- 日收盘来自 Yahoo Finance ^GSPC，不含分红；股息按月度股息率分摊。1973 年以来的日收盘未与第二个来源逐日核对，只用月均价做了间接核对。
- 没有计入交易成本和税费。
