# 预注册：多资产「趋势 + 动量」轮动（美股、海外股、国债、黄金）

登记编号：**L-036**（2 个确认候选，另有探索项）。写于 2026-11-26，在计算任何候选或基准的表现之前提交。

## 问题

用户：「趋势 + 动量做趋势呢？帮我做下，如果靠谱做个新页签。」

**先划清哪些不能再测**：只在美股一个资产上「趋势 + 动量」择时，本项目已经测过——L-011 的「动量且趋势」加码（不采用）、L-027 / L-031 的十个月均线防下跌（部分成立 / 不通过）。L-031 在 2026-11-26 不通过，按登记簿规则 3，2027-02-24 前不在同一数据上测它的变体（换信号、加动量确认都算）。

**本检验判断的是四类资产的整体配置**。无论结果如何，不据此对「只在股票上用均线择时」或「美股 / 海外轮动」下任何结论（那是 L-031、L-034 的问题），也不报告只限股票腿的拆分。为看增益是不是来自新的部分（国债、黄金），另加探索项 T2′（股票两条腿固定不择时，只对国债、黄金做均线过滤）；如果增益主要来自股票腿，结论必须注明「与 L-031 是同一证据」。国债、黄金在美国这份数据上从没做过趋势择时（L-030 用的是 14 国本币 10 年期国债，不含美国）；L-021 是波动倒数配权，本检验不是它的参数变体。

**还没测过的**是趋势跟踪最经典的用法：**在几类资产之间用趋势和动量轮动**（Faber 2007 的全球战术配置、Hurst–Ooi–Pedersen 的时间序列动量，常被称为「危机时的保护」）。股票走坏时不只是换成现金，还可以换到正在上涨的国债或黄金。

> 每月月末，在美股、海外股、美国国债、黄金四类资产里，只持有「近期涨得最好、并且在长期均线之上」的，能不能比四类固定各持 25% 更好——尤其是大跌时少亏？

## 候选

| 编号 | 名称 | 规则（月末 t 计算，t+1 月持有） |
|---|---|---|
| T1 | 趋势 + 动量 | 先在四类里按动量选出前 2 名，各配 50%；再逐个用均线过滤：入选的一类若破位，这 50% 改放现金，**不递补第 3 名**；两类都破位就 100% 现金 |
| T2 | 只看趋势 | 四类各配 25%；某一类破位，这 25% 改放现金（Faber 2007 的写法） |

- **动量**：mom_t = [(I_t/I_{t−3} − 1) + (I_t/I_{t−6} − 1) + (I_t/I_{t−12} − 1)] / 3，I 为扣费前的总收益指数，不跳过最近一个月；现金不参加排名。
- **破位**：I_t < MA10_t（严格小于；相等时继续持有），MA10_t = 最近 10 个月末 I 值的平均（含 t）。
- **并列**：动量差的绝对值 < 1e-12 视为并列，按代码字母序 BOND < EXUS < GOLD < US 取前者。
- 选中的资产不变时，每月也再平衡回目标权重并计成本。

T2 回答「只用趋势够不够」，T1 回答「在趋势之上加动量排序有没有增益」。参数（3/6/12 个月平均、前 N 名、10 个月均线）来自 Faber 2007 与《The Ivy Portfolio》（2009）及其后续版本，不在本数据上选择。

**基准 B**：四类各 25%，每月再平衡，不择时。

## 已知信息（如实写明）

- 美股、5 年期国债、黄金 1976–2026 年用于 L-021（按波动倒数配置，不通过），美股与 13 国用于 L-034（跨国轮动，不通过 / 不稳定）。四类资产「趋势 + 动量」轮动的组合结果没有算过。
- 我知道的大致事实：1981–2020 年国债长期牛市，2022 年股债同跌；黄金 1980 年见顶后长期低迷、2000 年代和 2020 年代大涨；2008 年国债和黄金上涨、股票大跌。所以 2008 年前后这类策略大概率表现好，这一点事先就知道。
- 文献：Faber（2007）的样本 1973–2005 与本检验约六成重叠，Moskowitz–Ooi–Pedersen（2012）也重叠，所以通过只是弱证据，不通过才是强证据。Faber 报告的全球战术配置在发表前表现很好；网上普遍认为 2010 年代以后它跑不赢股债组合。时间序列动量在 2008 年后整体变弱（Hurst–Ooi–Pedersen 2017 有讨论）。
- 没有商品、房地产信托的长期免费数据，所以只有四类，比 Faber 的五类少商品。
- 数据口径：黄金 1999-01 至 2000-08 是世界银行月均价插值（月末收益偏平滑），2000-08 至 2004-11 是 COMEX 近月期货价格（换月会跳空，不是现货收益），之后是 GLD 加回费率；1999-01、2000-09 两个月跨数据来源。国债是 5 年期固定期限收益率换算的，不是可交易指数。海外等权 13 国内部每月再平衡的成本没有计（L-034 计了）。均线用总收益指数，Faber 用价格指数，前者略偏多头。
- 1981–2020 年国债的高回报来自利率从高位一路下行，以后不会复制。

## 方法

- **执行**：月末 t 信号，t+1 月持有（ETF 次日交易，近似为月末价）。
- **权重与成本**：权重在 5 列（US、EXUS、BOND、GOLD、CASH）上跟踪；漂移后权重 w̃_{t,i} = w_{t,i}(1 + r_{t,i}) / (1 + g_t)；持有月 t+1 的净收益 = Σ w_{t+1,i} r_{t+1,i} − Σ_i c_i |w_{t+1,i} − w̃_{t,i}| − Σ_i w_{t+1,i} f_i / 12。
  - 单边交易成本 c：股票（US、EXUS）0.10%，国债 0.05%，黄金 0.15%，现金 0（与 L-021 相同）；
  - 持有费 f（年）：US 0.03%，EXUS 0.07%，国债 0.15%，黄金 0.40%，现金 0；
  - 第一个持有月不计交易成本；候选、基准、每个平移版本同样处理。
- g_t = Σ_i w_{t,i} r_{t,i}（含现金列，扣成本与持有费之前）；c、f 用小数（例如 0.0003）。
- **夏普**：月超额收益（净收益 − 同月 RF）均值 ÷ 标准差（ddof = 1）× √12。ΔS = 候选 − 基准。年化 = Π(1+r)^(12/N) − 1；最大回撤按月末净值，净值从 1977-12 月末的 1 开始，起点计入峰值。两半与发表后从同一次全样本运行的月度净收益里截取（回撤在截取段上从 1 起算）。
- **循环平移安慰剂**：把候选的目标权重矩阵（576 × 5）相对收益序列整体循环平移 k = 24 … 552（全部枚举），每个 k 用实际收益重算漂移、换手与成本，得到 ΔS_k。上尾 p = (ΔS_k ≥ ΔS 的个数 + 1)/(k 个数 + 1)。Holm 族：T1、T2（两个 p 的标准逐步写法，取单调版本）。平移保留各资产的平均持有比例，所以 p 只检验「时机」，长期偏重哪类资产的效果体现在 ΔS 里。相邻 k 高度相关，p 只当门槛用。

## 门槛（T1、T2 各自判定）

| 编号 | 条件 |
|---|---|
| G1 | 全样本 ΔS > 0，且平移上尾 p 经 Holm 校正 ≤ 0.05 |
| G2 | 两半的 ΔS 都 > 0 |
| G3 | 发表后（2010–2025）ΔS > 0 |
| G4 | MDD_候选 − MDD_基准 ≥ 0.05（MDD 为负数，即回撤浅 5 个百分点以上），且年化_候选 ≥ 年化_基准 − 0.01 |
| G5 | 晚一个月执行（t 月末信号，t+2 月持有）：候选从 1978-02 起单独跑（首月不计成本，575 个月），基准从主运行里截取 1978-02 至 2025-12，不重跑；ΔS > 0 |

## 结论规则

按顺序取第一条成立的：
1. G1–G5 全部满足：「通过」。
2. G1、G2、G3、G5 满足，G4 不满足：「风险调整更好，但收益或回撤不达标」。
3. G2–G5 满足、G1 不满足：「方向一致，统计上不显著」。
4. 全样本 ΔS > 0 的其余情况：「不稳定」。
5. 其余：「不通过」。

- **「通过」**：研究页新开「趋势动量」页签，展示规则、历史表现与当月读数；**不直接改仓位**。按月写入影子记录（锁箱 B-3）12 个月，2027-12 与其他影子记录一起复盘，由用户决定是否作为方案的一部分。「用它替代防守部分的现金」是另一种用法，没有检验过（L-030 的趋势过滤国债替代现金刚判「不通过」），需要另行预注册。

- **「不稳定」「不通过」**：结果放进「轮动」页签，不新开页签；方案不变。
