## 一句话

**十个月均线在 14 个国家里时机确实有信息，但作用太小，而且怕慢，两种写法按预注册都「不通过」。**
- 时机信息很显著：14 国全部 L < 1，随机平移安慰剂 p = 0.005（411 种随机平移里没有一种比实际更好）。
- 但幅度小：117 次熊市里，现行写法（破位降到 70%）比同等波动的固定仓位合计只少跌约 3.5%，破位封顶 50% 少跌约 11%，都达不到「下跌亏损里至少 65% 处于防守」的标准。
- 全周期（谷底后再看 12 个月）只有约一半的熊市算下来是赚的；2000 年以前的熊市整体是亏的。
- 执行晚一个月，全周期就变成亏钱：省下的跌幅在反弹里还回去了。

## 主判定（117 次熊市，Lunde–Timmermann 20/20 定义）

| | C1 现行（破位 70%） | C2 破位封顶 50% |
|---|---:|---:|
| 合并跌幅比 L（门槛 L*） | 0.966（0.955）✗ | 0.888（0.867）✗ |
| 逐段胜出 | 69% | 74% |
| 逐个去掉一个单元后的 L | 0.964–0.966（都 < 1） | 0.885–0.890 |

| 前段（高点 ≤ 2000）L / ΔE | 0.981 / **−0.13** ✗ | 0.929 / **−0.08** ✗ |

- 不通过的条件：G1（L 没到门槛）、G2（全周期为正的不到 62.5%）、G4（前段全周期为负）、G7（切换略多于 1.5 次/年，0.30% 成本下 G1、G2 也不满足）、G9（晚一个月执行全周期为负）。
- 满足的条件：时机显著（G5）、平时不更贵（G3）、整体效用不降（G6）、各单元方向一致（G8）。
- 平均仓位：C1 81%，C2 75%；对恒定 85% 的非目标期代价 C1 −0.48、C2 −1.12 个百分点/年（只报告，和 L-027 在美国的数字几乎一样）。

两段完全不重叠的历史给出几乎相同的 L。这说明十个月均线的效果是真实、稳定的，只是**很小**：L-027 的门槛按美国校准时 L* 更宽（0.995），在多国按各国同波动对照加权后 L* 收紧到 0.955，C1 没过；再加上全周期为正的比例只有一半，按同一套标准它不够格。

## 结论与落地（按预注册）

1. **C1、C2 都「不通过」**。仓位规则不变：十个月均线修正仍是现行规则的一部分，L-027 与本研究都显示它在两段历史上方向一致、作用稳定但很小。
2. 按预注册落地：说明书写明「十个月均线在多国不通过：时机有信息但作用小、对执行速度敏感」；**最终方案的放弃条件里，「上限 + 十个月均线」的简化版改为「只保留上限」**。也就是说，如果以后宏观攻守失效，退回固定上限即可，不必再保留均线。
3. 破位封顶 50%（C2）继续只在影子记录里观察，不采用。
4. 对用户的实际含义：
   - 最可靠的仍是「上限定在多少」；
   - 均线和宏观规则都是锦上添花，作用不大；
   - 规则执行要及时，晚一个月，好处就基本没了。

## 局限

- 信号用含息总收益指数月末值、次月执行，比现行规则（标普价格月均价）偏乐观；G9 的 t+2 是偏悲观的另一端，现行规则的 E1 执行（次月第 3 个交易日）介于两者之间。
- 数据在 L-030 里作为组合股票腿用过；新增样本只有 9 段熊市。
- 欧元区 1999 年后不独立；安慰剂用共同平移保留了国家间同步。
