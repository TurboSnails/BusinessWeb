# L-051 口径澄清（manager 裁定，2026-11-28，冻结后、计算前；两实现一致执行）

## 第一批（开工前，三点）
1. 探索变体只报告主推断（日历时间组合）均值、NW t、事件数、信号月数，不跑完整 S1–S5 与安慰剂。
2. 价值因子经 `load_fin_pit` 点时现算 TTM EP，优先调用已注册 `cn_ep_ttm`（compute_strict，不调用 evaluate_factor）；缺财报则该股该日缺失、不进回归；报告覆盖率。
3. 低波安慰剂按事件逐个配对：每个被回避事件在 s 日同板块 × 流通市值三档 × vol_60d 三档、当时不在任何回避窗中的股票里随机抽 1 只，在同一窗口剔除；1000 次，种子 20261128。

## 第二批（主实现提出，全部同意）
1. **S3 组合路径**：流通市值按前一日收盘加权（停牌日市值前推）；成员 = 最近一个严格早于当日的月末底池；回避股 s+1 开盘卖出（保留 s+1 隔夜收益）、s+61 开盘买回，其余股票按权重比例重新归一（隔夜 / 日内两步）。S3 的波动比、最大回撤、夏普、安慰剂用这条路径的毛收益；成本只进 S5（回避净收益），另报扣比例成本的净路径。底池路径不做整手；整手 + 5 元最低佣金只用于 S5 单事件成本（仓位 = 该股 s 日底池市值权重 × 1 亿元）。夏普 rf = 0（factorlab perf_stats 口径）。
2. **「暴跌未反弹」诊断对照**按 PREREG 字面：同日、同板块、同市值三档、s 日 dd_60 与 rev_1m 同五分位（分位在 s 日全底池上算），剔除 [s−60, s] 内有反弹信号的股票；不另加「10 日跌 ≥ 25%」要求。
3. **分档**用 `factorlab.backtest.quantile_labels`（并列按 sha256 代码哈希），在 s 日全底池（不分板块）上切三档 / 五档，再与同板块求交；vol_60d 用注册因子定义。
4. **S2(a)(b) 与集中度**都在日历时间组合序列上算：S2 按信号年剔除事件后重算日均差 × 60；集中度按交易日所在日历年汇总日差。
5. **C2 合并分级**：上下界都「支持」→ 支持；都「不支持」→ 不支持；其余 → 部分成立。C1 \ C2 在上下界两种标注下都须 ≤ 0。
6. **块自助 p**：对去均值序列循环块重抽，p = (1 + #{boot 均值 ≤ 观测均值}) / (N + 1)。
7. **第 9 条「停牌 ≥ 60 日后复牌首日」**只从首个有效行情日起计（上市前空白不算停牌），事件计数会与 count_h2_filtered 略有不同，报告差异。st_pit 中没有「终止上市」事件，该子条款为空操作——**须另报诊断**：信号日 s 之后 60 个交易日内退市的事件数、占比，以及剔除这些事件后的主推断均值（只报告，不改判定）。

主实现把以上口径写进 `results.schema.json` 的 conventions 段；第二实现以本文件为准。
