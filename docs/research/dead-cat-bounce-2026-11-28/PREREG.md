## 事件定义（以 `count_h2.py` 逻辑为准）

实现锚点：仓库内 `docs/research/dead-cat-bounce-2026-11-28/count_h2.py` **第 79–141 行**（冻结提交时写死该文件 blob SHA）。伪代码：

```
last_signal ← −∞
for each stock, for i from 10 … n−1:          # i = 候选暴跌锚点日（crash_end）
    if i − last_signal < 120: continue        # 冷却：暴跌日距上次信号 ≥ 120
    if 当日或 i−10 无有效收盘: continue       # 停牌 = 当日无行情行（非仅 is_suspended 字段）
    if close[i]/close[i−10] − 1 > −0.25: continue
    crash_start, crash_end ← i−10, i
    roll_min ← close[crash_end]; trough ← crash_end; signal ← None
    for k in crash_end+1 … crash_end+20:
        if 无行情: continue
        更新 roll_min / trough
        if close[k] ≥ roll_min × 1.10:
            if 一字跌停: break                 # 不记信号、不更新 last_signal
            signal ← k; break
    if signal is None: i ← i+1; continue
    # —— 以下为 v2 相对 count_h2 的增量过滤 ——
    if 第9条排除: i ← i+1; continue           # 不占冷却
    last_signal ← signal
    if 信号日 s 不在底池: i ← signal+1; continue
    记录事件；i ← signal+1
```

要点写死：

1. 暴跌锚点可在冷却允许下逐日重扫；找到信号后 `i` 跳到 `signal+1`。
2. 滚动最低从 **crash_end 收盘**起，在随后 ≤20 日内搜索；信号日须有行情且非一字跌停。
3. **先全市场检测 + 冷却 + 第 9 条，再按 s 日底池成员资格过滤。**

### 第 9 条排除（不计入、不占冷却）

`[crash_start, s]` 内若出现任一：

- `no_limit_inferred` 为真的交易日；或
- **停牌 ≥ 60 个交易日**后的复牌首日；或
- s 日已处于 `st_pit` 中 `flag=delisting` 区间，或已发生「终止上市」事件（`p_stock2117` → `st_pit`，点时 `start_date`）

则该次检测作废。

### 剔除窗与执行

- 回避窗：市场日历上 **s+1 开盘** 卖出（或不再买入），至 **第 s+60 个交易日收盘** 结束；下一开盘买回。
- 窗口终点固定为日历第 s+60 日收盘；事件股停牌则用复牌后首个收盘计入路径，**对照同一终止日**。
- 对照组**不**施加可成交（涨跌停）过滤。
- 流通市值分档、vol_60d 分档、底池市值阶梯**只用 s 及以前数据**。

## 对照与主推断

### 主对照（事件超额）

同信号日、**同板块（涨跌幅制度 / board）**、同流通市值三档（s 日底池内）、同 **vol_60d** 三档；并剔除过去 30 日内出现过 10 日跌幅 ≤ −25% 的股票。档内 < 10 只时**只放宽 vol_60d**。申万行业匹配仅在当前上市股子样本报告，注明幸存者偏差。

### 必报诊断对照

「暴跌未反弹」：同日、同板块、同市值档、s 日 `dd_60` 与 `rev_1m` 同五分位但未触发反弹信号。若事件股相对该对照超额 **≥ 0** → 结论最高「部分成立」。

### 主推断（日历时间组合法）

每日：回避窗内事件股等权收益 − 各自对照收益，得日差序列；  
**S1 均值 = 日均差 × 60**；t / p 用 **Newey–West 滞后 60**。  
辅助：63 日一块循环块自助 10000 次单边 p（种子 **20261128**）。  
按信号月聚类的事件层 t **只报告**。Holm 用主推断 p。

### S5 成本（方向）

回避净收益 = **−(事件超额) − 来回成本**，成本 = s+1 开盘卖出 + s+61 开盘买回（逐笔佣金+税+滑点）。  
**S5：回避净收益均值 ≥ +1.0%。**

### S3（低波安慰剂）

主口径对满仓底池：波动比或 MDD 改善，且夏普不差于满仓 −0.02。  
另须：候选波动比 < 安慰剂分布 **5% 分位**——每日在同板块 × 市值三档 × vol_60d 三档内随机剔除同数量股票、同窗口长度，**1000** 次，种子 **20261128**。

### Spanning

- **判定用（探索/验证 S4 改为只报告；锁箱 S4 只报告）**：组合层市值加权日超额对因子日收益回归，因子 = 月末调仓、前 20% 对底池、按日持有：`rev_1m`、`max_ret_21d`、`dd_60`、`peak_fall`、`vol_60d`、`size`、`turnover_20d`、价值（`cn_ep_ttm` 或 bp）、`mom_12_1`、市场超额；报告 **α > 0 且 NW t ≥ 2、滞后 60**。
- **事件层（报告）**：每周 Fama–MacBeth  
  `r(i,s+1→s+60) = a + γ·Event + b'X`，X 含上述反转/回撤指示与幅度、vol_60d、log 规模、turnover_20d、板块虚拟变量；检验 **γ < 0**（NW 滞后 12）。

## 判定门槛

对 C1、C2 **分别**判定。晋级锁箱 = 探索与验证各自「支持」。

### 优先级

1. 事件超额均值（主推断）**≥ 0** → **不支持**  
2. S1 或 S2 失败 → **不支持**  
3. S1、S2 满足且 S3–S5 有失败 → **部分成立**（不晋级）  
4. 全部满足 → **支持**  
5. 集中度：>50% 累计超额来自单一日历年 → 最高**部分成立**  
6. 诊断对照超额 ≥ 0 → 最高**部分成立**  
7. C2 上下界仅一边满足 → 最高**部分成立**  
8. C1「支持」另须 **C1∖C2** 超额均值 ≤ 0  

### 探索 / 验证层

| # | 条件 |
|---|---|
| **S1** | 主推断超额均值 ≤ **−1.5%**，且 NW（滞后 60）单边 p 对应 **t ≤ −2**（或等价） |
| **S2** | (a) 去掉事件数最多的一个日历年后均值仍 ≤ **−0.75%**；(b) 事件数 ≥ 50 的年份中 ≥ **60%** 均值为负 |
| **S3** | 对满仓：波动比 ≤ 0.98 **或** MDD 浅 ≥ 1pct，且夏普 ≥ 满仓 − 0.02；**且**波动比 < 安慰剂 5% 分位 |
| **S4** | spanning α 与事件层 γ：**只报告**，不作通过必要条件 |
| **S5** | 回避净收益均值 ≥ **+1.0%** |

### 锁箱层（与 L-038 对齐）

- m\* = （探索层主推断均值 + 验证层主推断均值）/ 2  
- **通过** = 锁箱超额 ≤ **½·m\*** **且** 本族 Holm 后单边 p < 0.05 **且** S3（安慰剂版）与 S5 成立  
- **方向一致、证据不足** = 仅过 ½·m\*  
- **不通过** = 未过 ½·m\*  
- 锁箱 **S2** 只判 (a)，且改为去掉事件数最多的一个**日历季度**  
- **信号月数 < 12** → 最高「方向一致、证据不足」  
- S4 只报告  

## 功效（显式）

设月度主推断超额的 σ_月 **事先取 8%**（保守；算收益后不回改此假设）。  
MDE（单边 5%、功效 50%）≈ `(z_{0.95} + z_{0.50}) · σ_月 / √n_月 = (1.645 + 0) · 0.08 / √n_月`。  
功效 80% 时用 `z_{0.80}=0.842`。n_月 = 该层信号月数（见过滤计数表）。锁箱若 n_月≈12，MDE≈3.8%/月量级（再 × 路径相关会更大）——**通过概率先验低**。
