## 一、结论

1. **H1（指数首次反弹）事件够粗估、不够硬确认。** 美国 1928–1949（Ken French 日度含息）**8** 个；去掉 1929–32 路径后剩 **6**。海外 9 指数合计 **99**，但日历月重叠 ≥2 市场的有 **20** 个月，有效独立日历月约 **78**（把同步月算 1 次）。与文中粗估（美约 10、国际 30–60）同量级；同步危机（2000–02 / 2008 / 2020）吃掉独立性。适合探索或合并样本的弱确认，**单靠美 8 个撑不起「跌破比例 vs 零分布」的硬门槛**。
2. **H2（A 股暴跌后反弹）个数极多、高度扎堆。** 2005–2023-10：**14 644** 次、**4 283** 只股票、**1 804** 个不同信号日；窗口内有 `fin_pit.announce_date` 的 **3 865（26.4%）**。四年（2015/2008/2016/2022）占 **51.8%**。原始次数远超检验需求，但有效独立日远少于 1804；仍**够做探索区检验力**，确认必须进锁箱且要 spanning 反转族。
3. **H3（机械化 SC→…→LPS）完整形态极少，不够预注册。** 主口径漏斗：SC **971** → AR **492** → ST **264** → Spring **201** → SOS **66** → LPS **7**（7 只股票；年分布 2013:1 / 2017:1 / 2022:3 / 2023:2）。敏感性 LPS 在 0–11 之间晃（`m_sp=0.5` 时 **0**）。远低于文中「约 200 独立 / 约 50 有效日」门槛；**组合层面几乎攒不出同时持仓**。不建议为 H3 预注册确认。
4. **Manager 已拍板（2026-11-28）**：H3 结案不预注册；H2 写预注册 L-051（C1 笼统 / C2 利空公告两候选）；H1 只作探索（`EXPLORE-H1.md`，R1=60 日不破低）。见文末「H3 结案说明」与 `PREREG.md`。
