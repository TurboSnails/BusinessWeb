# L-051 预注册草案独立审稿（2026-11-28）——必改清单

总评：暂不能冻结。以下 18 条必改须全部处理；建议项尽量采纳，不采纳的写明理由。审阅只读文件，未计算任何收益。

## 必改

1. **S2 无法在单层内判定、结论分级重叠**：S2 改为层内稳健性——(a) 去掉事件数最多的一个日历年后超额均值仍 ≤ −0.75%；(b) 事件数 ≥ 50 的年份中至少 60% 均值为负；锁箱层只判 (a)，改为「去掉事件数最多的一个日历季度」。判定优先级：超额 ≥ 0 → 不支持；S1、S2 满足而 S3–S5 有失败 → 部分成立；S1 或 S2 失败 → 不支持；全满足 → 支持。
2. **S5 成本方向写反**：回避净收益 = −(事件超额) − 来回成本（s+1 开盘卖出 + s+61 开盘买回，逐笔计算）≥ +1.0%。
3. **同平均仓位对照与重新归一矛盾**：主口径 = 剔除后重新归一、直接对底池；报告项 = 剔除权重放现金对 Bc，并注明这在危机后等于市场择时（与 L-047 同类），不能作为回避有效的证据。
4. **未控制低波 / 低 beta 倾斜**：spanning 加入 vol_60d、size、turnover_20d、价值（cn_ep_ttm 或 bp）、mom_12_1、市场超额；S3 另须满足：候选波动比低于安慰剂分布 5% 分位（每日在同板块 × 市值三档 × vol_60d 三档内随机剔除同数量股票、同窗口长度，1000 次，种子 20261128）。
5. **按信号日聚类低估标准误**：主推断改为日历时间组合法（每日回避窗内事件股等权减各自对照的日收益；S1 均值 = 日均差 × 60；Newey–West 滞后 60）；辅助：63 日一块循环块自助 10000 次单边 p；按信号月聚类的事件层 t 只报告；Holm 用主推断 p。
6. **行业匹配有前视**（prices.industry 只覆盖当前上市股，退市股为空）：主对照改为同信号日、同板块（涨跌幅制度）、同流通市值三档（s 日底池内分档）、同 vol_60d 三档，剔除过去 30 日内出现过 10 日跌幅 ≤ −25% 的股票；档内 < 10 只时只放宽 vol_60d。申万行业匹配仅在当前上市股子样本报告并注明幸存者偏差。
7. **对照组成不匹配问题**：主对照排除近期暴跌股（见 6）；「暴跌未反弹」对照升级为必报诊断（同日、同板块、同市值档、s 日 dd_60 与 rev_1m 同五分位但未触发反弹信号）；若事件股相对该对照超额 ≥ 0，结论最高「部分成立」。
8. **退市收益 −100% 对本假设不保守**：主口径 = 退市股按最后可成交收盘结束，不另补；报告项补 −100% 并注明「对回避有利的上界」。
9. **须排除退市整理期与长期停牌复牌**：[crash_start, s] 内含 no_limit_inferred 日、停牌 ≥ 60 交易日后复牌首日，或 s 日已处于退市整理期 / 已公告终止上市（点时状态取自 p_stock2117），该事件不计入、不占冷却期。
10. **文字与 count_h2.py 实现不一致**：事件定义以 count_h2.py 在某提交中第 79–141 行逻辑为准（附伪代码），写明：暴跌锚点与重扫规则、滚动最低价起点与搜索窗、冷却期判断的是暴跌日距上次信号 ≥ 120、停牌 = 当日无行情行；先全股票检测与冷却，再按 s 日底池成员资格过滤。
11. **fin_pit 没有业绩预告**：二选一——改名「C2 定期报告暴跌回避」并写死 doc_type ∈ {periodic}、announce_rule ∈ {declared, declared_same_report}、排除 statutory_deadline；或冻结前补齐点时业绩预告 / 快报数据源并记快照哈希。
12. **退市股公告日大多缺失（C2 幸存者偏差）**：C2 主判定在两种标注下同时满足——下界（新浪来源退市股事件一律非 C2）、上界（一律 C2）；只有一边满足最高「部分成立」。

14. **层边界窗口截断**：事件按信号日归层；验证层只纳入 s+60 ≤ 2023-10-31（约 s ≤ 2023-08-02）；锁箱层纳入 s ≥ 2023-11-01 且 s+60 ≤ 2026-11-30；探索层 2014Q4 跨入 2015 的窗口照常计算并单列。
