# A 股流动性踩踏防守（L-047）

**C1 跌停潮「部分成立」，C2 冲击成本飙升「不稳定」。不改仓位规则。**

C1 的规则：当天 5% 以上的股票跌停，就把 A 股仓位降到 50%，持续 20 个交易日。2006–2023 年：

- 夏普从 0.485 升到 0.549；
- 最大回撤从 −71.6% 收窄到 −58.9%，比同平均仓位（88%）的 −66.4% 浅 7.5 个百分点；
- 大跌段合并损失比 0.86，前后两段都有效。

但时机检验 Holm p = 0.14，没到 0.10，按预注册判「部分成立」。

## 怎么理解

- **跌停潮常出现在恐慌顶点。** 每段第一次触发后（共 19 次，间隔 > 60 天才算新的一次），大盘 20 个交易日平均**上涨** 3.4%，60 日平均上涨 6.6%，只有约四成为负。2020-02-03 当天几乎就是底部。
- **它仍然有用**，是因为 2008、2015 年这类连续多波的流动性危机里，一次跌停潮之后往往还有下一波。减仓一个月躲过了后面几波，少亏的部分超过了在底部卖出的代价。
- **统计上不显著**：18 年里真正的流动性危机只有两三次（2008、2015–2016），时机检验的原始 p = 0.071，校正两次检验后 0.141。这类规则和美股的十个月均线一样，只能当「大熊市保险」，等不到统计确认。
- **C2 冲击成本**（Amihud）2015 年以后失效：冲击成本飙升常发生在成交萎缩的阴跌末期，之后 20 日大盘平均略跌（−0.5%），减仓的时机不稳定。
