## 2026-11-26 美股动量 vs Ken French UMD

- 数据：美股个股全量（Yahoo，5,262 只，1995-01 至 2026-11，幸存者偏差等级 B），探索区（70% 证券、2023-10 以前）。
- 命令：`uv run python -m factorlab.cli eval --market us --factor mom_12_1 --motivation "literature: engine validation vs KF UMD"`（登记簿 `factor-ledger/us.jsonl` 第一条）。
- 校验：引擎的「前 20% − 后 20%」等权月收益与 Ken French 动量因子 UMD 同月相关 **0.91**（1996-02 至 2023-09，332 个月）；错开 ±1 个月相关 −0.01、+0.02。说明收益期对齐正确、没有错月或前视。只做多口径（前 20% 对股票池，市值 / 成交额加权）与 UMD 相关 0.71–0.75。
- 用途只是验证引擎；这里的收益数字是幸存者偏差数据上的探索结果，不据此做任何判断。
- 顺带修复：容量比例在成交额为 0 时除以零。

## 2026-11-27 A 股全量数据与经典因子校验

- 数据：A 股全量（腾讯日线 + 新浪乘法复权因子），5,897 只、1,621 万行，2005-01 至 2026-11；2005 年以后退市的 311/313 只有日线（等级 A）；无重复、无空值、无超出涨跌停幅度的价格；流通市值对照腾讯当前值中位误差 0.7%。
- 外部基准：Liu、Stambaugh、Yuan 的 CH-4 月度因子（`inputs/CH_4_fac_update_20211231.csv`，sha256 `b12853ce…061d14f`，2000-01 至 2021-12，作者主页下载）。
- 结果（探索区，2005-02 至 2021-12 与 CH-4 重叠 203 个月）：
  - 规模因子多空（小减大，等权）与 SMB 同月相关 **0.93**，主口径（市值加权前 20% 对股票池）0.94；错开 ±1 个月 0.12 / 0.09。
  - 20 日换手多空（低减高）与 PMO 相关 0.57（PMO 用异常换手，口径不同）；60 日波动多空与 PMO 0.30。
- A 股公认规律都复现：短期反转 RankIC +0.060（NW t 6.8）、12−1 月动量约为 0（−0.010）、低波（−0.071，t −7.3）与低换手（−0.084，t −9.2）更好、小盘更好。RankIC 按因子原值计算，事先方向为「越小越好」的因子 IC 为负即方向正确；报告已标明。
- 这些是探索区（70% 证券、2023-10 以前）的引擎校验，登记在 `factor-ledger/cn.jsonl`，不据此采用任何规则。
