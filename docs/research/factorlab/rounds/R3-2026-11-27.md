# 第三轮因子挖掘（R3）：组合因子——计划与晋级规则

写于 2026-11-27，在跑任何组合因子之前提交。

## 为什么做这一轮

R1、R2 的共同结果：A 股价值、低波动、反转的截面排序都显著（RankIC t 4–11），但剔除最小 30%、市值加权只做多的主口径超额都不到门槛（t < 2）。文献与实务的常见做法是把互相独立的信号合成一个分数，降低单一因子的噪声。

## 晋级规则

与 R1 完全相同（探索 → 截面验证 → 增量性 → 预注册 + 锁箱确认，门槛数字不变）。增量性的基准：A 股用规模、1 月反转、60 日波动、20 日换手；美股用 Ken French 五因子 + 动量。组合因子的成分本身已在基准里时（如 C2 含反转、波动、换手），增量性检验照做，意思是「组合后是否有超出各成分线性组合的部分」。

不符合的照实记录，不调权重、不换成分重试；改写法须升版本号并另计试验。
