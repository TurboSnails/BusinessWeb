# 加入大师长期持仓后的再平衡重算 · 事先方案（2026-11-22）

> 本文件在新股票价格采集之前写定并提交。之后的任何改动追加到文末「变更记录」。这是探索性研究，选股和规则都受事后偏差影响，结论只作参考。

## 1. 新增股票怎么选

来源：SEC EDGAR 的 13F-HR 原始信息表（不是汇总网站）。六位投资人：巴菲特（伯克希尔）、段永平（H&H International）、李录（喜马拉雅资本）、阿克曼（潘兴广场）、阿克雷（Akre Capital）、特里·史密斯（Fundsmith）。

**长期持有**的口径：
- 在最新一期 13F 里占申报市值 5% 以上（期权行不计）；
- 而且五年前同一季度的 13F 已经持有（按 CUSIP 发行人前 6 位比对，同一公司的不同股票类别合并）。

最新一期是 2026-09-30；潘兴广场最新只到 2026-03-31，对照 2021-03-31。"五年前已持有"只比对两个时点，不保证中间一直没有卖过。

结果新增 14 只：AAPL、MA、V、MCO、ROP、CSGP、WAT、SYK、BAC（成长组），PDD、KKR（高波动组），BRK-B、CVX、QSR（稳定组）。已有的 AXP、KO、GOOGL 也符合口径，补上持有人标记。分组按业务性质事先指定，拿到数据后用第 4 节的检查复核。

## 2. 统一回测约定（与网站页面一致）

- 价格：Yahoo 复权收盘价（含拆股和分红），由 GitHub Actions 采集，腾讯不复权日线交叉核对。
- t 日收盘判断，t+1 日收盘成交；成本 = 单边换手 × 0.10%；全部调回目标权重；不计税。
- 再平衡规则主设定：相对偏离 40%（目标 × (1 ± 40%) 之外触发）；对照：每年最后一个交易日调一次。
- 大跌切换主设定：纳指 100 ETF（QQQ）从高点回撤 20% 进入，每再跌 5 个百分点一步，每步卖出进入时稳定资产市值的 25%，买入当前权重 ÷ 目标权重最低的那只；回撤收窄到 5% 以内恢复并全部调回目标；累计卖出上限 50%；不设超时。
- 指标：期末倍数、年化收益（自然日 ÷ 365.25）、最大回撤、交易次数。

## 3. 要算的三件事

**A. 用户现在的组合换成大师股会怎样**（2021-08-25 起，RKLB 上市首日）
基准：AVGO、META、CB 各 25%，SOFI、RKLB 各 12.5%。
- A1 换稳定股：CB 依次换成 BRK-B、QSR、CVX、KO、AXP。
- A2 换成长股：AVGO、META 分别换成 AAPL、GOOGL、MA、V、MCO、ROP、CSGP、WAT、SYK、BAC 中的一只（共 20 个组合）。
- 每个组合报告不动、相对 40% 再平衡、再平衡加大跌切换三种结果。

**B. 扩大后的组合网格**（2021-08-25 起）
"2 成长 + 2 高波动 + 1 稳定"，权重 25%、25%、12.5%、12.5%、25%，覆盖扩充后各组的全部组合。
- 再平衡年化高于不动的组合占比、差值中位数、最大回撤差值中位数；
- 按"含几只大师股"（0 到 5）分组比较上面三项；
- 按稳定股分组，比较大跌切换相对普通再平衡的差值。
只报告分布，不挑"最好的组合"当结论。

**C. 只用大师股的长期组合**（2018-07-26 起，PDD 上市首日；全部 17 只大师股都有数据）
- C1 从 17 只大师股里任选 5 只等权（6,188 个组合），比较不动、相对 40%、每年一次三种做法的年化和最大回撤分布，并与同期 QQQ 对照。
- C2 一个事先指定的例子：每位投资人最大的一只长期持仓，AAPL（段永平、巴菲特）、GOOGL（李录）、QSR（阿克曼）、MA（阿克雷）、WAT（特里·史密斯），加 BRK-B 作稳定股，六只等权；报告三种做法与大跌切换（稳定资产 BRK-B）。

## 4. 数据检查

- 新增 14 只全部通过腾讯交叉核对，或者在报告里写明哪只没核对。
- 分组复核：计算每只的年化波动和对 QQQ 的贝塔（2021-08-25 起）。若事先指定为"稳定"的股票贝塔高于 0.8，或"高波动"的年化波动低于 35%，在报告中指出并说明是否调整分组；分组调整不改变 A、C 的组合定义，只影响 B 的网格。
- 用两个独立实现复算：网站引擎（TypeScript）与 manager 的 Python 程序，A 组与 C2 全部、B 与 C1 各抽 20 个组合，期末倍数四位小数一致。

## 5. 局限（事先写下）

- 选股本身就是事后的：能在 13F 里五年都还在的股票，大多是这几年涨得好的（幸存者偏差）。C 组的绝对收益偏高，不能当作"抄大师作业"的预期收益。
- 13F 有约 45 天延迟，只含美国上市股票多头，不含现金、债券、空头和非美股票。
- 2018 年以来只经历了 2020、2022 两次大跌，大跌切换的样本很少。
