## 2. 草稿结论

### 2.1 "逐一剔除"表怎么读

去掉一只后，其权重按比例分给其余几只。"年化差"为负，表示这只在**拉高**组合（它涨得比其余平均快，或它的波动被再平衡利用得好）；为正，表示它的回报不如其余平均，**不等于亏钱，也不等于该删**——稳定股去掉后年化往往更高，但回撤更深。

所以用户的理解反了：去掉后收益**降低**的，是**涨得快**的（博通 2021-08 以来年化 44.7%、Rocket Lab 32.4%）。去掉后收益**升高**的，才是涨得慢的（苹果 17.9%、安达保险 15.6%、拼多多 −2.9%）。这里的"增速"指股价年化收益，不是营收或利润增速；股价收益 ≈ 盈利增长 + 估值变化。

### 2.2 驱动因素（35,280 个组合，"2 成长 + 2 高波动 + 1 稳定"）

把"再平衡年化 − 不动年化"（再平衡超额）按各因素分五档：

| 因素 | 最低档 → 最高档：再平衡超额中位数（胜过不动的占比） |
|---|---|
| 成员股价年化的离散度（增速差距） | +4.4 点（100%） → +0.5 点（58%） |
| 成员加权平均波动 | +3.0 点（96%） → +4.2 点（90%） |
| 成员两两平均相关 | +3.7 点 → +3.0 点；回撤改善 +2.3 点 → −0.5 点 |
| 成员加权平均年化（整体增速） | +3.6 点 → +2.8 点 |

线性回归（四个因素，R² = 0.73），每变化一个标准差，对应的再平衡超额：离散度 −2.6 点，波动 +1.6 点，相关性 −0.5 点，整体增速 +0.5 点。

草稿解读：
- **最关键的是"增速差距"，不是"增速高低"。**成员长期涨幅接近、但短期轮流涨跌时，再平衡几乎总能多赚（离散度最低的两档胜率 100%）；一旦有一只长期远远跑赢其他（离散度最高档），再平衡就是在不断卖掉赢家，胜率只剩 58%、超额只剩 0.5 点。这与 Perold & Sharpe（1988）"恒定比例策略在震荡市占优、在趋势市落后"一致。
- **波动越大，再平衡可利用的"高卖低买"越多。**SoFi（年化 −3.3%、波动 66%）、拼多多（−2.9%、65%）本身没赚钱，但放进组合里，靠大幅波动给再平衡提供了买卖机会。
- **相关性低主要带来的是回撤改善**，而不是收益提升。
- **稳定股的作用是降回撤**：安达保险与博通、SoFi、Rocket Lab 的相关性接近 0，去掉它组合年化 +3.4 点，但最大回撤加深约 8 点。

### 2.3 市场上的类似方案与结论

| 方案/研究 | 结论 |
|---|---|
| Vanguard《Best practices for portfolio rebalancing》（2010/2015）、《Rational rebalancing》（2022） | 没有最优频率或阈值，不同再平衡方法的风险调整收益差别不大；目的主要是控制风险，而不是提高收益；不宜太频繁（月度、季度），也不宜两年以上才调一次 |
| Bouchey、Nemtchinov、Paulsen、Stein（2012），"波动收割" | 资产波动大于 0、相关性小于 1 时，分散加再平衡能带来额外复合增长；但资产泡沫持续期间会很痛苦 |
| Willenbrock（2011） | "分散收益"的来源是再平衡，强制卖出相对上涨的、买入相对下跌的资产 |
| Perold & Sharpe（1988） | 恒定比例（定期调回目标）在无趋势、波动大的市场占优；在单边趋势市场落后于买入持有 |
| 2018 年《Review of Quantitative Finance and Accounting》个股组合研究 | 个股组合再平衡降低波动，但买入持有的期望收益更高，检验多数偏向买入持有 |
| Daryanani（2008）"机会型再平衡" | 经常检查、只在偏离超出区间时才调，比固定每年调一次多出的收益可以翻倍（作者来自券商，有利益相关） |
| 等权 ETF（标普 500 等权 RSP，按季调回等权） vs 市值加权 SPY | 过去十年 RSP 年化约 11.9%，SPY 约 15.5%：大科技股持续领涨时，"定期卖赢家"吃亏；2026 年以来 RSP 暂时领先 |
| 纳指 100 等权 ETF（QQEW） | 本页同期对照：QQEW 年化 3.0%，QQQ 10.3% |

草稿归纳：我们的回测和这些研究方向一致——**再平衡在"轮流涨跌"的组合里稳定加分，在"一只独大"的趋势里吃亏；它首先是风险控制工具。**本页样本中再平衡多数时候多赚，是因为这 5 年科技股经历了 2022 年大跌和之后的轮动，股票之间波动大、轮流领先；不代表未来也一样。

## 3. 页面结论文案（准备实现）

### 3.1 自动结论（按当前所选组合和结果计算，放在四格对比上方）

最多 4 句：
1. **收益**："动态平衡比不动多/少 X%（年化 A% 对 B%），最大回撤 C% 对 D%。"
2. **靠谁**：逐一剔除中年化差最负的一只："收益最依赖 某某：去掉它年化少 N 个点。"若最负的两只合计超过 8 点，补一句"收益集中在少数几只，未来它们不再领涨时结果会明显变差。"
3. **稳定股的作用**：组合里有稳定组股票时，取其剔除结果："去掉 某某 年化会多 N 个点，但最大回撤加深 M 个点——它的作用是降风险。"（只在回撤确实加深时说）
4. **适不适合再平衡**：按成员股价年化的离散度判定（阈值取网格分档：≤0.10 / 0.10–0.16 / >0.16）——
   - 低："成员长期涨幅接近、走势轮动，这类组合在回测中再平衡几乎总是多赚。"
   - 中："成员涨幅有差距，再平衡多数时候仍然多赚，但优势变小。"
   - 高："有一只长期远超其他，再平衡等于不断卖掉赢家，这类组合在回测中只有约六成跑赢不动。"
末尾固定一句："以上是历史回测的描述，不是买卖建议。"

### 3.2 研究结论（静态，放在"研究参考组合"区内，可折叠）

三条：
- 再平衡在成员轮流涨跌时稳定加分，一只独大时吃亏；首先是风险控制工具（与 Vanguard、Perold & Sharpe 等研究一致）。
- 组合里放一只与科技股不同步的稳定股（如安达保险），回撤能少约 8 到 10 个点；两只高波动股之间也最好不同步。
- 每年调一次就够；大跌切换只是小幅加成。
