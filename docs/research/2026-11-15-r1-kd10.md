# R1（创业板÷红利低波）与择时+KD10 补充检验

2026-11-15。标准事先写定并先推送（`2b37ba2c`，见 [TODO](../TODO-投资工具优化.md)「补充检验」），跑数后未改。脚本 `scripts/research/etf-strategy-oos/{fetch-r1,bt-r1}.mjs`，数据来自中证指数官网和新浪。历史统计，不构成投资建议，也不是买卖指令。

## 结论

| 问题 | 判定 | 一句话 |
|---|---|---|
| A. R1 能否替代 R2 做短线择时 | **无实质差别** | R1 与 R2 有 93% 的交易日给出相同的牛/熊判断，「两项都过」只多 1 个（8 对 7），全期年化反而略低（中位差 −0.7～−1.2 个百分点/年）。换掉 R2 没有好处。 |
| B. R1 周线分位能否提示周期位置 | **创业板指÷红利低波：通过（弱证据）；创业板50÷红利低波：未通过（2019 年前没有数据，无法判定）** | 高分位（≥80%）之后一年，创业板平均跑输红利低波；低分位（≤20%）之后平均跑赢，两者相差 43 个百分点，2019 年前、2019 年后两段方向一致。2015-06 顶部分位 99%、2021-07 顶部 99.6%，2018-10 底部 12%、2024-02 底部 0.7%。 |
| C. KD10 是否优于「只认金叉」 | **无实质差别** | 「两项都过」8 对 7，年化中位差 +0.1。阈值从 0 到 8 结果几乎不变，说明 5.3 不是关键参数，但加了 KD10 也没有改善。单个指数差别很大（中证1000 +3.7，消费 −4.4），更像噪声。 |

**怎么用**

- **短线择时**：继续用 R2，不必换成 R1，也不必加 KD10。朋友当天删掉 R1，和这次结果一致：R1 只是 R2 的近似替身。
- **R1 的价值在周期层面**。「创业板指÷红利低波」周线比值的历史分位，可以当作风格/估值温度计：分位很高时成长风格已经很拥挤，分位很低时红利已经很拥挤。适合放进牛熊周期面板，作为一条观察证据。它不能当择时信号：独立的顶底只有大约 2 轮（2015、2021 两个顶，2018、2024 两个底），52 周窗口又互相重叠，统计力很弱。而且分位桶也不单调：60～80% 那一段比 40～60% 好。
- **当前读数**：2026-11-13 的分位是 44%（创业板50 口径 41%），处于中间位置，没有给出方向。
- 创业板50 口径的走势与创业板指基本一致，但只能从 2014 年算起，而且分位要先积累 3 年历史，实际从 2017 年才有读数，所以不选它。同事如果用的是创业板50，结论也相同。

**口径说明**

- A、C 中 R2 的「两项都过」是 7/15。① 报告里的 9/15 是沪深300 比值择时的结果，两者口径不同。
- 超额收益里的创业板指是价格指数，不含分红，所以绝对水平偏低约 3～4 个百分点/年，但不影响高低分位之间的比较。
