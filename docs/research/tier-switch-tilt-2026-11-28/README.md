## 判定

全组合口径：档位 × 80% 上限，其余放现金，含成本。

| | C1 固定篮子 | C2 按 β |
|---|---:|---:|
| 主窗口 1959–1972 夏普：切换 / 全买宽基 / 一直防守 | 0.312 / 0.302 / 0.359 | 0.231 / 0.302 / 0.390 |
| G1 对全买宽基（须 ≥ +0.03） | +0.010 ✗ | −0.071 ✗ |
| G2 对一直防守（须 ≥ 0） | −0.047 ✗ | −0.159 ✗ |
| G3 时机检验 Holm p（须 ≤ 0.10） | 0.81 ✗ | 0.81 ✗ |
| G4 1950–1972（须 > 0） | +0.008 ✓ | −0.048 ✗ |
| G5 1973–2026（须 ≥ −0.02） | −0.012 ✓ | −0.054 ✗ |
| 结论 | 不稳定 | 不通过 |
| 主窗口最大回撤：切换 / 全买宽基 | −17.1% / −15.6% | −17.7% / −15.6% |

C1 在 1973 年后逐段变差：1973–1999 年 −0.001，2000–2026 年 −0.024，2012–2026 年 −0.087。成本提到 0.3% 后，三个窗口都转负。晚一个月执行：主窗口 +0.007，1973–2026 年 −0.025。

## 为什么：两侧拆开看

只在防守侧切换（进攻侧照旧买宽基）和只在进攻侧切换，各自对全买宽基的夏普差：

| | 1959–1972 | 1950–1972 | 1973–2026 |
|---|---:|---:|---:|
| C1 只切防守 | +0.034 | +0.020 | +0.010 |
| C1 只切进攻 | −0.023 | −0.011 | −0.022 |
| C2 只切防守 | +0.025 | +0.020 | +0.015 |
| C2 只切进攻 | −0.095 | −0.066 | −0.067 |

C1 篮子（等权）相对宽基的月均超额：

| 档位（月数：主窗口 / 1973–2026） | 防守行业 1959–72 | 进攻行业 1959–72 | 防守行业 1973–2026 | 进攻行业 1973–2026 |
|---|---:|---:|---:|---:|
| 进攻侧（56 / 253） | −0.03% | −0.09% | −0.04% | +0.01% |
| 中性（41 / 192） | +0.32% | +0.15% | −0.08% | +0.25% |
| 防守侧（63 / 199） | +0.53% | +0.12% | +0.22% | +0.15% |

- **防守行业**在防守侧跑赢最多，方向符合直觉。但在 1959–1972 年的中性月里也跑赢，所以「一直放」比「只在防守侧放」更好（G2 不过）。
- **进攻行业**在进攻侧并没有跑赢宽基。它们的超额出现在中性和防守侧，也就是宏观转差、市场见底前后。档位是跟着数据走的，等它转回进攻，周期股最强的那段已经过去了。进攻侧本来仓位就最高，再加周期行业，只是加风险，回撤因此变深。
- C2 的高 β 篮子更极端，进攻侧月均落后宽基 0.58%（1959–1972）。

「只切防守」的小幅正值是看过结果后的拆分，不能据此采用。它也不如一直放防守行业，后者已在「通过检验」页做 ETF 影子记录（L-026）。按登记簿规则 3，2027-02-26 前不在同一数据上试切换比例、篮子名单、档位分组的变体。

## 局限

- 1934–1972 年的防守组合已被 L-026 用过（锁箱 B-4），这段数据对防守篮子不是全新的；切换组合本身从未计算过。
- 留出档位用的是修订后数据，不是当时的实时数据；1973 年后的档位就是在那段历史上调出来的，所以只作否决。
- 月度近似：忽略 t+1 月前 2 个交易日。

## 核对

独立第二实现 `research-py/replications/tier_switch_tilt_2026_11_28.py` 由子 agent 只读预注册和输入写成，没看 `run.py`。36 个确认项（三种组合的夏普与回撤、各窗口夏普差、时机检验 p、门槛与结论）全部一致，最大差 7.8e-16。
