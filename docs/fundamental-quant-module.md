# 基本面量化模块

## 目标与首版范围

用户希望在既有彼得林奇式公司研究之外，持续积累基本面量化方法；以《投资策略实战分析》为首本指导书，并在与 Claude 讨论后由 Codex 实施。

入口：投资 → 工具与参考 → 基本面量化，路径 `/invest/fundamental-quant`。与公司研究、综合估值、候选池互相衔接。首版为可使用的方法库：方法总览、书籍指南、可搜索与分类的因子手册、两张策略研究卡与一张单因子实验卡、A 股验证清单与后续路线。

不接未经核验的历史财务数据，不输出真实选股排名、回测收益或交易指令。所有策略状态为“研究草案 · A 股未验证”。后续取得当时可得数据后，再独立增加筛选与验证引擎。

## 内容契约

- 来源分层：出版社书目/简介、作者机构公开研究、项目改编。书籍正文未逐章核对，不能宣称全书精读、精确复现，不能编造章节、页码、绩效与原书参数。
- 每本书：作者、原文标题、用途、核心方向、项目采用方式、可核来源和核实范围。
- 每个因子：类别、含义、公式、排序方向、数据时间口径、行业适用范围、失效情形、来源依据。
- 每张策略卡：目的、股票池、筛选排序、组合与调仓假设、退出、交易可行性、基准、证伪条件、来源和验证状态。
- 不把缺失值补零；不把亏损公司的负 PE 识别成便宜；银行保险使用单独行业模型；动量为价格辅助信号，不归为财务指标。
- 净股东回报须识别增发与股权激励稀释。现金口径与股数口径不能直接相加，回购公告不视为已实施。
- 量化规则组合与人工复核组合分开记录；不能把人工择时后的结果算成原策略绩效。

## 设计与交互

沿用网站已有纸色、墨绿和宋体标题：背景 #FAF6EE、内容 #FFFDF8、正文 #3A3A34、次文 #6B675C、强调 #3F5A49。以研究手册为布局，左侧内容、右侧简明研究路径；窄屏单列。避免额外统计数字与收益装饰。

页内导航直达各段，因子搜索与类别过滤可组合并写入 URL 的 q/category 参数，刷新可保留；空结果解释并提供重置。书籍与策略以原生 details 展开，键盘可操作。交互不请求外部数据，无加载/鉴权状态。验证清单只保留本次页面内状态。

## 验收

- 投资首页和站内搜索可进入独立模块，深链可打开，顶部投资导航高亮。
- 指导书保留可核来源与内容边界，三张策略卡均明确未完成 A 股验证。
- 因子可按关键词及类别筛选，清空恢复全部；展开显示具体公式与陷阱。
- 页内导航、书目、公司研究、估值和候选池链接有效。
- 390px 窄屏与 1440px 宽屏无页面横向溢出；焦点可见，不依赖颜色表达验证状态。
- 不新增依赖、无生产部署、无自动交易，原有工作区修改保留。

## 验证所需的数据纪律

按财报实际公告时间建立历史快照，保留退市及历史成分。记录板块、流动性、停牌、价格限制、成交延迟与交易成本，按历史当期规则处理。先锁定规则，再做滚动样本外及参数扰动验证，同时报告失败与失效期间；分离行业/规模暴露。收益和最大回撤均从可复现代码计算。

后续按“正文核对 → 数据覆盖与口径审计 → 单因子分组 → 多因子与成本 → 样本外 → 模拟跟踪”的顺序增加能力，不以填满页面替代证据。

## 与 Claude 讨论后的裁决

采纳：来源类型化；因子补齐字段与 A 股口径；规则卡含对照组；股东回报为单因子实验卡，卡 1 不重复计入；动量只作辅助及后续对照；林奇六类适用性提示；规则/人工组合分账；方法库先放工具组；URL 保留筛选；验证清单可勾选。

未采纳：将所有书籍内容写成“模型记忆转述”（已有出版社公开简介、目录和机构研究可核，应按实际证据分层）；全站禁止出现“买入/卖出”等字符串的测试（这些词可用于解释成交约束，不等于交易建议）；18 个因子全部引入（首版保留 11 项，不引入未经核实的 Z 分等复杂公式）；因子统一可用于金融股（金融公司改用专门口径，首版策略统一非金融池）。Claude 报告的具体公式和交易规则仅为评议输入，未直接当作已核事实搬入产品。

来源分层最终采用“方法导读 / 仅书目 / 项目改编 / 待验证假设”，独立记录 source ID 与核实范围；没有正文核对的项目不显示章节/页码。数据结构不提供虚构收益字段。

Claude 实际交付复核后进一步修订：质量价值沿用全池价值阈值、不在过滤后重排；现金股东回报保留负值参与五分组，再按非现金稀释有无分层；补齐共同事件退出、申万一级历史归属、小样本处理与统一税率 ROIC 代理。因子税率代理只作待验证研究假设，非公司实际税负。来源短名与可访问名称区分，《Expected Returns》降为仅书目。纯空白搜索不写入 URL。
