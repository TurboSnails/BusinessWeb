# A 股 / 港股长周期牛熊判断体系与战略仓位面板

日期：2026-10-17。来源：用户本轮提供的完整六维方案。

状态：**观察版已实现，完整策略验证待完成**。用户在需求归档后明确要求开始实现并安排入口；实际交付与限制见文末。本文件保留研究要求，未经回测的规则不代表已验证策略。

## 目标与边界

- 聚焦 3～5 年观察尺度的大级别牛熊状态，支持“何时分批建立仓位、何时持有、何时减仓或退出”的战略判断；不假定每轮周期必然持续 3～5 年。
- 每周末 / 月底约 15 分钟完成复盘，减少日线噪音与临场情绪。
- 以公开数据、宽基指数、周月量价及宏观数据为主，不逐家公司拆财报，不开发短线选股或自动下单。
- 分别输出 A 股、港股宽基、恒生科技的结果，不把沪深300信号直接等同于所有板块信号。
- 保留六维交叉验证思路，但不预设它们统计独立；MACD、RSI、BOLL 作为同一技术维度，不能重复算三票。

## 方案完善要求

### 1. 纠正解释与市场映射

- MACD的速度 / 加速度只保留为直观类比；以快慢EMA差及信号线差的实际公式实现，明确柱体是否乘2。
- BOLL上下轨为均值加减标准差倍数，不代表真实市场价格有95.4%落在带内。创始人的规则明确提醒不要据此作正态分布假设。[John Bollinger官方规则](https://www.bollingerbands.com/bollinger-band-rules)
- 20周均线称“20周均线”，不与常见约26周或120个交易日的“半年线”直接等同。
- RSI极低、VIX极高、ERP极高只表示候选状态；不得据此断言下跌已到极限、险资一定托底或外资一定回流。
- M1 / M2不用“活钱 / 死钱”替代统计定义。人民银行自2025年1月统计起修订M1口径；历史比较须使用可比数据或标记断点，不能直接拼接。[人民银行统计说明](https://www.pbc.gov.cn/en/3688247/3688978/3709137/5838983/index.html)
- 港股单独选择估值、成交、宽度与资金指标；A股融资买入比例不能照搬。港股需研究港元资金成本、南向资金、美元利率及中国基本面的传导，不预设单一海外固定权重。
- USDCNH报价下行表示人民币升值；“升破均线”改为明确的报价方向条件。CSI300/SPX需固定指数版本、币种、交易日对齐规则；另列同币种相对收益对照。

### 2. 数据字典与低维护可行性

每项数据登记：来源链接、市场、单位、频率、观测日期、实际发布日期、可获取时间、口径版本、历史覆盖、更新方式、失败处理与许可条件。优先核验中证指数、上交所、深交所、港交所、恒生指数、人民银行、中债及美联储 / 美国财政部、Cboe等官方来源；这里只列候选，不保证免费完整历史已可获取。

| 指标 | 必须固定的口径 |
| --- | --- |
| 简化ERP | 指数PE类型与亏损处理、盈利收益率与国债利率单位一致；它是收益率差代理，并非完整前瞻风险溢价；历史窗口、最少样本、滚动均值与σ均须预先定义，只用当时已知数据 |
| 成交与融资 | 两市 / 其他交易所范围、股票与基金是否纳入、周内交易天数；融资买入额分子与成交额分母覆盖匹配；用换手率或滚动分位对照绝对金额 |
| 换手率 | 成交股数 / 可流通股数或金额 / 流通市值择一固定，不能混用单股均值与全市场加权结果 |
| ETF份额 | 份额、份额变化与资产净值分开；处理拆并份额及产品范围变化，不能把价格上涨导致的规模增加视为净流入 |
| 市场宽度 | 分母股票池、历史成分、退市、新股不足200日、停牌处理；MA200指200个交易日；固定复权与新高定义 |
| 周月技术 | 仅用已完成周/月K线；MACD(12,26,9)、RSI(14)、BOLL(20,2)先列候选标准参数；初始化与标准差口径固定 |
| 缩口与放量 | BOLL带宽=(上轨−下轨)/中轨，预定义历史分位窗口；成交比较基期排除当前周期并校正节假日 |
| 背离与破位 | 写成不依赖人工事后画线的规则；摆动点若需要后续K线确认，信号日期记在确认时；破位幅度、连续周数、收回条件需明确 |
| 宏观与海外 | M1−M2单位为百分点；按发布日期生效，记录修订；美债、VIX及汇率与本地收盘时点对齐，不能提前使用美国当日晚收盘 |

采用长期滚动分位与z-score作对照，不只依赖固定绝对阈值。免费数据不足时允许少量手动更新并显示成本；无法可靠得到的指标保留缺失，不用估计值凑齐六维。

### 3. 状态、冲突与仓位纪律

候选状态：等待证据 / 防守观察 → 底部候选 → 右侧修复 → 趋势持有 → 顶部风险 → 防守观察。允许震荡、假突破及快速跳转，不能强行给每周贴牛熊标签。

- 每维展示偏多 / 中性 / 偏空 / 缺失及原始证据；合计分数是规则输出，不是牛熊概率或胜率。先以等权作基准，再比较分市场权重，避免调参凑历史顶底。
- 缺失或过期指标不视为中性票；展示“有效维度数/总维度数”。证据不足时冻结自动提高风险的建议，保留已确认状态并显示等待证据。
- 明确定义共振窗口与过期规则，避免把数月前的底部信号同本周信号拼成共振。月内MACD临时金叉只能标“未确认”。
- 估值决定研究赔率区间，趋势与资金参与执行确认；宏观及海外作为背景和压力条件。需比较“4～5票”与分组门槛，检查相互关联的维度是否重复计权。
- 顶部减仓不能永久受“ERP与杠杆必须同时极端”限制。需验证趋势破位或风险预算触发时的独立防守路径，避免昂贵 / 便宜都只能被动等待。
- 候选破位规则如连续两周收于20周线下，与原“三周未收回”作为预先登记的对照方案；不能回测后只保留表现最好的一条。
- 入场、减仓、重新进入和冷静期必须成套定义，记录假突破后的处理。10%～15%跌幅不自动判定为洗盘。
- 原40%～50%、80%～100%均解释为**本策略获分配的可投资资金**的候选档位。备用金、长期被动仓与本策略资金分别核算；整体配置和风险预算优先，不默认推动总资产满仓或清仓。
- 后续验证前登记最大可接受回撤、单次调仓上限及复核机制；风险预算未定义时只输出状态，不生成个人仓位建议。默认无杠杆。

- 状态：不足4维等待证据；3维底部极端且无风险标底部候选；右侧至少4维支持、其中3维修复且技术向上、无风险；两周低于20周线独立防守；风险与支持并存单列分歧。此为明确登记的新观察规则，不声称等同于用户原始4～5维交易策略或已校准阈值。
- 复盘：每个市场独立预算、补录、四项检查单、理由与历史；最多保留52次本机记录，冻结输入、证据及规则版本。支持JSON导出与校验恢复；不自动下单，不输出固定个人目标仓位，不挪用备用金。
- 图表：周 / 月切换、收盘与布林带、键盘可操作历史滑块；滑块只看历史技术，不能冒充当时六维结论。
