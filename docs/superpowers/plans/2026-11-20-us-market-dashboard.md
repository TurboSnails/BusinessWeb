# 美股市场仪表盘实施计划

规格见 [设计稿](../specs/2026-11-20-us-market-dashboard-design.md)。使用现有 React 页面、TypeScript 数据模型、Node 数据采集和快照发布工作流。

- [ ] 核对公共指标、市场切片和成分宽度的独立采集契约。验证来源失败时保留原快照、不会把旧值写成今天的观测。
- [ ] 用可测模型判断同日相对强弱、有效宽度及风险证据。缺失和日期错位必须在先失败的测试中覆盖。
- [ ] 在监测页接入 URL 可分享的美股视图。覆盖细分切换、旧快照、局部失败、来源及手机布局。
- [ ] 运行采集、功能测试、类型检查、生产构建和浏览器验收，并检查更新工作流及现有页面回归。
