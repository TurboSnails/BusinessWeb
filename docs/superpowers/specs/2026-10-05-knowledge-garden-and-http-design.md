# 蒲公英网络与 AI 资料库

用户要求补齐蒲公英页面，并给第三方 AI 提供资料库访问能力；继续此前授权的实现、提交与发布。

## 本轮范围

- 个人知识中心默认进入蒲公英网络；使用真实 Markdown 的 wiki 链接和 Notion 相对 Markdown 链接。
- 分类以虚线组织，真实引用用实线连接；支持搜索、分类、缩放、分页、聚焦一层关系和打开笔记。
- 每屏最多 90 个节点，以分类轮转分配初始种子；明确展示当前显示数量。
- 增加官方 SDK Streamable HTTP MCP，无状态 POST、Bearer 认证、Host/Origin 校验；只读工具与目录范围限制。
- 保留本地 stdio MCP 的版本检查读写能力；不改变原始知识数据。
- GitHub Pages 发布静态页面与接入说明，不包含私人 Vault。

## 尚需配置

公开网站不能读取本地磁盘。远程 AI 的资料范围、持续运行的托管位置、持久数据和 HTTPS 配置尚未确定。OAuth 客户端需要后续认证适配。不得把“代码支持 HTTP MCP”描述为“公网 AI 服务已上线”。

## 验收

真实导入数据生成网络；浏览器验证搜索、聚焦、读取；使用真实 HTTP MCP 客户端验证工具发现、访问范围、认证和拒绝写入；运行类型检查、前端与知识服务测试、Pages 构建。提交前验证 `.local/` 未被 Git 跟踪且不在静态产物中。
