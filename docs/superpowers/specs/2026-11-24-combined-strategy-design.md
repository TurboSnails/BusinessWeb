# 综合策略页（宏观攻守 + 市场雷达）设计

日期：2026-11-24 · 决策人：manager（用户要求，细节授权「你自己决定」）

## 1. 为什么做

用户指出：「市场综合」的两阶段检验（第一阶段单独回测、第二阶段并入总综合）不该放在「我的市场雷达」页。雷达页只做一件事：从股市自身的指标分析和回测。应该另有一个页面，把宏观攻守和市场雷达融合起来，给出具体的仓位策略。

三个页面的分工：

| 页面 | 回答的问题 | 内容 |
|---|---|---|
| 宏观攻守 `/invest/macro-posture` | 宏观上该进攻还是防守 | 四支柱、五档仓位、时间线、回测（不变） |
| 我的市场雷达 `/invest/market-radar` | 股市自身冷还是热 | 五维指标、雷达档位、雷达自己的回测（只和持有、均线、恒定七成比） |
| 综合策略 `/invest/strategy`（新） | 两者合起来，仓位怎么定、具体怎么做 | 当前结论与动作、仓位规则、状态矩阵、融合检验、月度档位对照、市场综合 |

## 2. 融合规则：先检验，再写结论

预注册与结果见 `docs/research/market-radar-v2-2026-11-24.md` 第三轮，原文 `market-radar-v2-2026-11-24/PREREG-round3-fusion.md`。

基线是单用宏观攻守（实时数据口径）。六个候选都以宏观攻守的最终档位为起点：

| 编号 | 规则 |
|---|---|
| M1 平均仓位 | 雷达仓位与宏观仓位取平均 |
| M2 热度上限 | 偏热时档位最高到偏进攻 |
| M3 偏热且破位再降一档 | 偏热且标普月均价低于十个月均线时，再下调一档 |
| M4 偏冷加码 | 偏冷且标普月均价不低于十个月均线时，上调一档 |
| M5 全套热度修正 | M2 + M3 + M4 |
| M6 雷达否决 | 雷达综合档位为偏防守或防守时，再下调一档 |

热度 = 雷达的估值维度分与拥挤度维度分的等权平均（缺一个就用另一个，都缺为空）；≤ −0.5 偏热，≥ +0.5 偏冷，其余居中。

结果：六个候选在训练期夏普都没有超过基线（−0.063 到 −0.001），没有一个过线。之前检验过的「市场综合作为第五根支柱并入」同样未采用。

**结论：综合策略的仓位只按宏观攻守的档位定，雷达不改变仓位。** 雷达在综合策略里的作用是说明当前处在哪种状态，以及在这个状态下组合结构和节奏该怎么做。

## 3. 状态矩阵（雷达真正有用的地方）

把每个月按「宏观档位」（进攻侧 = 进攻、偏进攻；中性；防守侧 = 偏防守、防守）和「雷达热度」（偏冷、居中、偏热）分成九格，看之后 12 个月的标普回报。这是描述性统计，不是交易规则，格子里样本少的要标出来。

manager 独立算出的结果（信号月之后隔一个月开始计 12 个月；每格：月数 / 之后 12 个月均值 / 为负比例 / 期间平均最大回撤）：

全样本（1973 年起）：

| | 偏冷 | 居中 | 偏热 |
|---|---|---|---|
| 进攻侧 | 3 / 0.9% / 0% / −4.1% | 123 / 12.9% / 17% / −6.6% | 122 / 13.5% / 15% / −7.5% |
| 中性 | 25 / 7.7% / 24% / −6.1% | 104 / 16.8% / 15% / −6.4% | 57 / 8.0% / 18% / −7.5% |
| 防守侧 | 70 / 20.0% / 16% / −7.9% | 106 / 9.6% / 31% / −11.9% | 23 / −3.5% / 57% / −15.8% |

2000 年以后（没有出现过偏冷）：

| | 居中 | 偏热 |
|---|---|---|
| 进攻侧 | 74 / 13.3% / 12% / −5.1% | 72 / 7.1% / 22% / −8.9% |
| 中性 | 50 / 17.0% / 10% / −6.8% | 34 / 5.1% / 29% / −11.0% |
| 防守侧 | 62 / 11.2% / 29% / −13.0% | 17 / −10.2% / 76% / −20.1% |

两点最清楚：宏观防守且市场偏热是最差的一格；宏观防守但市场偏冷是之后回报最好的一格（底部区域）。

## 4. 每格的做法（playbook）

仓位一律按宏观档位（进攻 100%、偏进攻 85%、中性 70%、偏防守 50%、防守 30%，占自设股票上限的比例）。下面只是结构和节奏，不改变仓位；属于操作建议，没有单独回测。文字由脚本生成，其中的数字从矩阵统计里取，不写死。

| 宏观 | 热度 | 做法 |
|---|---|---|
| 进攻侧 | 偏冷 | 按档位持有。这一格历史上极少出现。 |
| 进攻侧 | 居中 | 按档位持有，按月正常再平衡。 |
| 进攻侧 | 偏热 | 按档位持有，不因为贵提前减仓。不加杠杆；新增资金分批投入；不再提高单一行业或个股的集中度。 |
| 中性 | 偏冷 | 按档位持有。需要补仓时可以在这个阶段完成。 |
| 中性 | 居中 | 按档位持有，按月正常再平衡。 |
| 中性 | 偏热 | 按档位持有。减仓时先减估值高、杠杆高的部分，留下现金流好的。 |
| 防守侧 | 偏冷 | 按档位持有，不再继续砍仓。这是历史上之后回报最好的一格；档位一旦上调（修复确认），当月就回补到位，不拖延。 |
| 防守侧 | 居中 | 按档位持有，等档位上调再回补。 |
| 防守侧 | 偏热 | 历史上最差的一格。严格减到档位对应的仓位，不抄底，不以「已经跌了不少」为由少减。 |

每格文字后面接一句由数据生成的统计：`这一格历史上有 N 个月，之后 12 个月标普平均 X%，Y% 的时候为负，期间平均最大回撤 Z%；2000 年以后 N2 个月，平均 X2%。`（2000 年以后没有样本时省略后半句；月数少于 30 时加「样本少，仅供参考」。）

## 5. 页面结构（`/invest/strategy`，从结论到证据）

1. **现在怎么做**：宏观档位（及仓位比例）、雷达档位与热度、所在格子的做法与统计；可输入自己的股票上限，换算成占总资产的仓位（与宏观攻守页共用同一个本地存储键）。数据日期。链接到宏观攻守页和雷达页看依据。
2. **仓位规则**：五档对应的比例与组合结构倾向（沿用宏观攻守页已有文字）；执行节奏：每月最后一个交易日正式定档，下个月内调整到位（回测按隔一个月生效）；月中的预估只作提醒；其余资金放现金或短债（回测按 3 个月国库券）；年均换档次数与成本拖累引用宏观攻守回测里的数字。
3. **状态矩阵**：九格表（全样本），当前所在格高亮；每格显示月数、之后 12 个月均值、为负比例、平均最大回撤，样本少的格子标注；下面附 2000 年以后的六格表。说明这是历史统计，不是规则。
4. **融合检验**：基线与六个候选的训练期、验证期、全样本对照表（年化、最大回撤、夏普、平均仓位）和一句结论；披露。
5. **月度档位对照**：标普走势加两条色带，上带宏观档位（即仓位），下带雷达档位（从雷达页搬过来的那张图）。
6. **市场综合**：原样搬过来的两阶段面板（第一阶段单独回测、第二阶段并入总综合），标题下加一句说明它是早先的一次融合检验。
7. 披露与免责声明。

顶部锚点导航（吸顶），移动端单列、表格横向滚动容器，颜色走 CSS 变量。
