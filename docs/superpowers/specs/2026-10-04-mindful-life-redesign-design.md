日期：2026-10-04　状态：待用户审阅

## 1. 目标与成功标准

把站点从“Hassan投资 交易工作台”改成个人品牌阵地「正念生活 · Mindful Life」，以《正念投资》为中心；现有全部内容先归入「正念投资」栏目；视觉改为轻松的生活感。

成功标准：

1. 顶部导航不超过 5 项，任何旧页面 3 次点击内可达。
2. 所有旧路由路径保持可访问，旧链接和书里的页面引用不失效。
3. 打开首页，第一屏能看出这是一本书和一个人的长期实验，而不是行情面板。
4. 老页面不重写逻辑，换肤后无白底白字、对比度不足或错位。
5. `npm test`、`npm run typecheck`、`npm run build` 通过。
6. 手机端（宽 360 / 390px）与桌面（1280px）都可正常使用：页面无横向滚动，点击目标不小于 44px，抽屉导航可开关，书稿阅读页舒适可读（详见 3.1）。

不在范围内：新功能、正念投资 AI 产品、改动任何数据接口和估值/网格逻辑、改书稿内容。

## 3. 视觉系统：纸书茶室

### 色板（CSS 变量，写入 `index.css`）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg-primary` | `#FAF6EE` | 页面底 |
| `--bg-card` | `#FFFDF8` | 卡片底 |
| `--text-primary` | `#3A3A34` | 正文 |
| `--text-secondary` | `#7A766B` | 次要文字（对比度对 `#FAF6EE` ≥ 4.5） |
| `--accent` | `#5B7B65` | 主色，暗绿 |
| `--accent-warm` | `#C9794F` | 点缀，陶土 |
| `--border-subtle` | `#E6DFD0` | 细线 |
| `--up` / `--down` | `#C4503F` / `#3F9A62` | A 股红涨绿跌，仅用于涨跌，不用于品牌 |

### 字体与形态

- 标题、书名：Noto Serif SC（Google Fonts 加载，失败回退系统宋体）。
- 正文：系统无衬线；书稿阅读页正文用宋体，17–18px，行距 1.9，行宽 ≤ 38 个汉字。
- 卡片：纯色底、1px 细线、圆角 14px、无玻璃拟态、无悬浮上移；只保留 0.2s 颜色/边框过渡和淡入。
- 导航：纯文字，无图标；当前项用下划线加主色。手机端为简单抽屉，不再是 16 宫格。
- 点缀：首页和栏目页头部放一枚简单的线条叶片 SVG，不用插画和图片。

### 3.1 移动端要求（硬性）

- 断点：`< 768px` 为手机布局，`≥ 768px` 为桌面布局。设计先按 390px 做，再向上扩展。
- 页面无横向滚动。栅格一律 `repeat(auto-fit, minmax(min(100%, Npx), 1fr))`，不写固定像素宽度。宽表格、长代码块放在自己的 `overflow-x: auto` 容器里，不撑开页面。
- 点击目标（链接、按钮、抽屉项、切换条）高度不小于 44px，相邻目标间距不小于 8px。
- 顶部栏手机端：左侧品牌名，右侧菜单按钮；点开为全屏抽屉，纵向 5 项大字排列，切换页面或按 Esc 自动关闭，打开时锁定背景滚动。
- 栏目内页的同组切换条在手机端横向滚动，当前项自动滚入可视区，不换行。
- 正文字号不小于 16px（避免 iOS 输入框聚焦时自动缩放），书稿阅读页正文 17px，行宽自然贴合屏幕，左右留 16px。
- 适配刘海屏与底部横条：`viewport-fit=cover`，顶部栏和页脚使用 `env(safe-area-inset-*)`。
- 首页首屏在 390×844 视口内能看到书名、副标题和“开始阅读”按钮，无需滚动。

## 4. 实现方式

### 第一阶段：外壳与换肤（本次必做）

1. 重写 `index.css` 变量。把 `--system-blue` 等旧变量映射到新色板（`--system-blue` → 暗绿，`--system-green` → 涨跌绿等），老页面引用旧变量即自动换肤。
2. 重写 `Header`（5 项 + 抽屉）、`Footer`（品牌名，Build Time 缩成小字）。
3. 新增 `Breadcrumb` / `SectionTabs` 组件、`InvestHub`、`AiStudio`、`LifeLab`；重写 `Home`。
4. 修改 `App.tsx` 增加三条路由；`index.html` 标题改为“正念生活”。
5. `FirstBook` 阅读样式微调（字体、行宽、目录配色）。

### 第二阶段：老页面硬编码颜色清理（第一阶段验收后做）

硬编码颜色集中在 `TradingPhilosophy`(562)、`Pulse`(108)、`SectorRotation`(98)、`ResearchNotes`(54)、`InvestmentStrategy`(52)、`LimitUpAnalysis`(51)。逐页把写死的蓝、紫、灰背景改成变量，不动逻辑。每页改完截图核对。

### 约束

- `App.tsx`、`Header.tsx`、`public/changelog.json`、`IndustryLandscape.tsx`、`public/industry/` 当前有用户未提交的改动。我在其基础上修改，保留产业格局路由；提交时只提交本次重设计相关文件，用户原有改动不单独提交。
- 书稿相关发布规则不变：改 `FirstBook.tsx` 的只限样式，不动 `PARTS`。
- `build:pages` 的子路径（`/BusinessWeb/`）要保持可用，所有站内链接走 router，不写绝对路径。

## 6. 风险

| 风险 | 对策 |
|---|---|
| 老页面内联样式写死颜色，换肤不彻底 | 第一阶段变量映射，第二阶段逐页清理 |
| 旧变量映射造成语义错乱（如蓝色按钮变绿但涨跌也用绿） | 涨跌色单独定义 `--up/--down`，第二阶段改涨跌相关引用 |
| Google Fonts 在国内加载慢 | 设 `font-display: swap`，回退系统宋体 |
| 与用户未提交改动冲突 | 改前读当前文件，只做增量编辑 |
