# 公司估值工作台设计

日期：2026-10-04。状态：聊天设计已确认，本文待用户审阅；尚未进入产品实现。

## 目标与成功标准

在 BusinessWeb 中输入公司名称或股票代码，选择本机 CLI 及其模型，自动整理财务资料、生成可修改的估值假设，并展示多种方法的三情景估值。用户明确要求参考 earendil-works/pi，直接调用本地 CLI。这里的“本地”指调用进程运行在用户电脑，模型推理可以由该 CLI 的云端服务提供。

默认覆盖 A 股、港股、美股上市公司。只需公司输入和模型选择即可启动；公司身份存在歧义时要求选择上市证券。数据不足时提供已有分析与缺失清单，不能把“自动化”理解为必须生成完整价格。

## 现有项目依据

- React/Vite/TypeScript；已有公司研究路由、公司目录、行情封装及 AKTools 接口封装。
- 本机已找到 pi、codex、claude、gemini、opencode 可执行文件。已确认 Codex、Claude、OpenCode 的非交互接口；Gemini 的 help 探测未及时返回，不应先承诺支持。
- 行情接口不等于完整财务数据源。README 中列出的 MCP 配置文件在本次实际文件检查中未找到，不能当作已接通服务。
- 现有研究文本是历史研究资料，不能解析成已核实的最新财务数据。
- 仓库已有行情和热力图未提交修改，本功能不覆盖这些改动。

## 方案选择

选择“网页 + 本地 Node 服务 + CLI 适配器 + 独立计算引擎”。相比仅调用 pi 的单一方案，能复用不同 CLI 各自的配置和登录状态；相比直接生成一篇 AI 报告，参数可编辑、结果可复算，错误和取消状态也能明确展示。

Pi 作为独立执行后端，通过 RPC 调用；不假设 pi 会自动调用 Codex CLI 或 Claude CLI。首版支持 Pi、Codex、Claude、OpenCode；Gemini 显示未支持，待验证后增加适配器。没有安装或登录失败的后端不可冒充可用。

## 用户流程与页面

新增 `/valuation`，从导航及公司研究详情进入，详情入口预填市场和代码。

1. 输入名称或代码，展示匹配证券的名称、市场、代码、报价币种。港股、美股的同一发行人及 ADR 不混用股本。
2. 选择 CLI，再选择本地可用的具体模型版本。Pi/OpenCode 通过可用列表选择模型；Codex/Claude 优先读取其公开发现接口或本地模型目录/配置。无法枚举时标注“使用 CLI 默认模型”，允许填写模型 ID，调用失败给出原因，不伪造完整模型列表。增加刷新列表操作。
3. 开始后依次展示识别公司、采集资料、分析假设、计算估值、完成。显示实际进度事件和取消按钮，不显示虚构百分比。
4. 结果包含公司概况、数据完整度、方法适用性、估值区间、财务质量、同业比较、关键风险和假设来源。
5. 悲观/基准/乐观列分别列出参数、每股估值及相对现价幅度。输入不足的方法展示不可计算原因，其余方法仍可完成。
6. 参数可编辑并立即复算，修改后的输出标注“用户调整”。保留原始模型假设，便于恢复。
7. 浏览器保存带版本号的报告，支持 JSON 和 Markdown 导出；不保存完整 CLI 原始日志或凭据。首版一次运行一个模型，同一资料快照可换模型重跑，保留两次报告供比较。

## 模块与职责

- `src/features/valuation/`：领域类型、纯函数公式、输入校验、情景和敏感性计算、报告存储。仅从模块入口导出公共能力。
- `src/pages/Valuation.tsx`：流程交互与结果页面；独立服务负责本地连接与事件消费。
- `server/valuation/`：本地 HTTP 服务、任务生命周期、CLI 适配器、财务数据适配器、结构化结果校验。与现有行情代理分开。
- 本地服务监听 `127.0.0.1`，默认端口 8788，可由环境变量设置。提供独立启动命令；Vite 开发时代理 `/api/valuation/*`。
- 首版的完整 CLI 流程在本地网页运行。部署到 Vercel/Pages 后能查看已有报告，但不能假设服务器可运行用户电脑的 CLI；页面说明需要本地启动，不自动从 HTTPS 页面连接 HTTP 本地服务。

## 数据获取与口径

优先从结构化数据源获取证券身份、现价、三张财务报表和股本。A/H 股优先复用 AKTools/AkShare 财务接口；美股通过 Yahoo 结构化数据与 SEC 公司财报补充，公告和投资者关系页面用于核对。具体接口必须在实施时用真实响应验证，不依赖臆测字段。

每个财务字段包含 value、unit、currency、periodStart、periodEnd、basis（年报/季度/TTM/预测）、sourceUrl、retrievedAt 和 status（已获取/缺失/冲突）。每份快照包含证券身份和 asOf 时间。金额标准化到基础货币单位；百分比内部使用小数，PEG 计算时显式转为百分数值。

- 归母净利润、普通股股东净资产、稀释股本与每股指标保持匹配；少数股东权益不直接计入普通股 P/B 分母。
- TTM 使用四个独立季度，或最新年报加本期累计减去年同期累计，不把累计报表相加。
- 报价、报表、预测注明各自时间。外币报表需要可追溯汇率，未取得汇率时阻止跨币种每股估值。
- 区分报告事实、管理层指引、AI 假设、用户输入；缺失值为 null，不用 0 代替。
- 自动数据源失败允许用户补充结构化数据，所有输入标注用户提供。手工补充是降级路径，不能拿来代替自动采集验收。
- 同业比较显示可比公司、财务口径、时间及选择理由。无有效同业数据时展示缺失，不生成虚假的行业中位数。

## 估值方法

六种方法全部有独立卡片和可计算状态，不强迫所有公司同时获得六个价格。

| 方法 | 当前指标 | 情景估值 | 校验与适用性 |
| --- | --- | --- | --- |
| P/E | 现价 / 同口径 EPS | 预测 EPS × 目标 P/E | EPS ≤ 0 不适用；周期企业提示正常化盈利；目标倍数注明假设或同业依据 |
| PEG | P/E / 盈利增长率百分数值 | 预测 EPS × 目标 PEG × 增长率百分数值 | 40倍/40%=1；增长率 ≤ 0 或负盈利不适用；显示增长预测区间；PEG<1不能自动判定低估 |
| P/S | 普通股市值 / 营收 | 预测营收 × 目标 P/S / 对应预测股本 | 股权乘数不混用 EV/Sales；加入利润率、稀释与融资需求分析 |
| P/B | 普通股市值 / 普通股股东净资产 | 预测每股净资产 × 目标 P/B | 净资产 ≤ 0 不适用；结合 ROE、资产质量；账面净资产不等于清算价值 |
| DCF | 逐年现金流现值与终值 | 股权价值 / 对应稀释股本 | 明确 FCFF/WACC 或 FCFE/股权成本，禁止错配 |
| 多阶段 DCF | 多阶段逐年现金流 | 同 DCF | 收入、利润率、再投资、融资及稀释路径显式建模，不能仅对负 FCF 乘增长率 |

相对估值的预测时点所有情景一致，清楚显示“某年预测价格”，不直接称为今日内在价值。需要今日可比值时用显式要求回报率折现，并并列展示原预测价格。DCF 本身输出估值基准日价值。

DCF 默认采用 FCFF：EBIT×(1−税率)+折旧摊销−资本开支−营运资本增加；经营现金流减资本开支不能直接假定为 FCFF。企业经营价值加现金与非经营资产，减有息债务、优先股及相关少数股东权益，得到普通股股权价值，避免重复扣除净债务。FCFE 模式使用股权成本且不再次扣债。

终值为末期 FCF×(1+g)/(r−g)，要求 r>g，终值和逐年现金流均正确折现。缺少必要股权价值桥接字段时不输出每股价格。多阶段默认10年，可选5–15年，显式建模早期投资、增长过渡和稳态；早期亏损不假设自动产生税收抵扣，融资缺口须注明解决方式和稀释假设。

DCF 展示折现率×永续增长率敏感性表与终值占比。不合法组合显示不可计算，不使用极端值填表。各方法分别输出区间，不把相关方法的简单平均包装为统一合理价格。

## AI 输出合同

CLI 接收同一份冻结财务快照、估值口径、报告要求及 JSON schema。输出为方法适用性、三个情景的假设、同业选择理由、财务质量和风险分析，引用快照中已有来源 ID。AI 不负责最终价格计算，不得把未经验证的外部文本新增为财务事实。

基本分析维度：盈利与增长、现金流质量、ROE/ROIC（有数据时）、负债与偿付、周期与行业、竞争壁垒、资本开支、股份稀释。每项支持结论、事实依据和证伪条件；资料不足标注无法判断。现有投研 skill 的研究纪律可复用，首版不启动专家圆桌或多个 CLI 并发。

输出必须通过结构、有限数值、证券身份、币种、年份和引用 ID 校验。失败允许一次格式修复，仍失败则任务报错；不得用正则随意抓取文本中的价格作为结果。

## 模型版本选择

用户补充明确要求：能够选择本地可用的模型版本，不能只选择 CLI 名称。

- 模型项包含 backend、provider、modelId、displayName、version（来源确实提供时）、isDefault、discoverySource、discoveredAt、availability 与能力信息。版本是原始模型ID/版本字段，不自行猜测。
- 区分 CLI 版本和模型版本。若模型运行在云端，本地目录列出的模型显示“CLI可访问”；Ollama/LM Studio 等实际本机模型显示“本机推理”，只有存在对应数据源时才列出。
- 发现来源包括 CLI 官方列举接口、本地目录/配置、用户手动填写；只返回模型元数据，不把凭据或原始配置传到网页。安装了 CLI 不代表已登录，本地目录存在模型也不代表当前账号有权限。
- availability 区分已发现、已验证可调用、不可用、未知。刷新列表不自动发起收费推理；实际任务调用成功后更新验证状态，失败后保留明确原因。
- 模型ID按参数原样传给所选CLI，禁止把版本字段拼成命令。报告保存用户选择的ID、实际返回的模型ID（若CLI提供）、CLI版本及时间；服务静默改用默认模型时视为错误。
- 稳定别名如默认模型/sonnet等若不能确定对应快照版本，明确标注别名，不能伪装为固定版本。模型切换后重新执行AI分析；原报告和冻结财务数据仍可保留。

## 本地调用与任务接口

- `GET /api/valuation/health`：服务状态与版本。
- `GET /api/valuation/backends`：CLI 安装状态、模型发现能力；安装不代表已登录。
- `GET /api/valuation/models?backend=…`：可枚举的模型与默认模型信息，不返回密钥。
- `GET /api/valuation/companies?q=…`：候选证券及明确身份。
- `POST /api/valuation/jobs`：传入证券身份、backend、model、估值日期，返回 jobId。
- `GET /api/valuation/jobs/:id/events`：SSE 事件包含序号、阶段、已完成数据及终态；断线可恢复已缓冲事件。
- `GET /api/valuation/jobs/:id`：查询当前状态或最终规范化报告。
- `POST /api/valuation/jobs/:id/cancel`：幂等取消。

任务状态为 queued → collecting → analyzing → calculating → completed，也可进入 failed/cancelled。默认同时只运行一个任务，额外提交返回忙碌状态。任务总时限10分钟，单个数据请求15秒、CLI启动30秒；数据阶段部分失败进入缺失状态，CLI超时进入失败状态。终态后不再接收迟到回调覆盖结果。取消停止相关子进程及数据请求，服务退出清理任务；完成报告可导出，未导出运行状态不承诺跨服务重启恢复。

所有子进程通过固定 executable 和参数数组启动，shell=false，提示内容走 stdin，股票输入不能拼入 shell。采用独立任务目录，模型只读取整理后的研究数据；禁用与估值无关的写入工具，不采用跳过全部权限的开关。不同 CLI 的允许工具能力需按实际版本验证。服务只接受允许的本地开发 origin；写入/启动接口要求启动时生成的会话 token，token仅保存在页面会话，不导出。

Pi 按安装版本验证 RPC 事件合同；新版本文档中的 agent_settled 不能直接假设旧版也支持。JSONL 只按 LF 拆分，正确处理跨 chunk UTF-8、stderr、异常退出及 prompt 接受与任务完成的区别。

## 验收与验证

1. 输入腾讯/00700、贵州茅台/600519、Apple/AAPL 能识别正确证券；歧义候选可选择，未找到时不替换为相似公司。
2. 至少一个已登录 CLI 完成真实端到端估值。其余支持后端分别验证启动、模型版本发现/刷新、显式模型ID传递、事件解析、取消、错误；没有可用登录时记录未验证，不能标记全通过。验证选中的版本确实传入调用，别名正确标注，不可用版本不会静默回退。
3. 自动采集三个市场各一家公司真实数据，核对来源、财报期间、金额单位、币种和股本。外部服务不可用时报告明确失败及恢复步骤，不用演示数据代替。
4. 稳定盈利、亏损成长、金融公司分别验证方法适用性；检查负 EPS、零增长、负净资产、股本为零、缺少净债务桥接、折现率≤永续增长率等边界。
5. 用可手工核算的样本验证 P/E、PEG、P/S、P/B、逐年DCF、终值折现及股权价值桥接；验证改参数会改变结果且不会修改原始事实。
6. 覆盖拆分JSONL、畸形结果、CLI非零退出、超时、取消与终态迟到事件。UI覆盖模型不可用、数据缺失、取消、报告保存和导出。
7. 新模块和服务端纳入类型检查；运行相关测试、现有必需检查与构建。验证根路径及Pages路径入口正常，静态构建不包含CLI凭据。

## 首版范围

包含单公司、多种方法、单模型运行与换模型重跑、三情景、敏感性、报告保存导出。后续可增加批量公司、专家圆桌、历史估值追踪、反向DCF、EV/EBITDA、DDM与剩余收益模型；首版不创建云端账号或部署服务。
