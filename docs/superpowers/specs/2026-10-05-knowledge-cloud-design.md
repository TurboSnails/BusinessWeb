# 私人资料库云端接入

本地 `.local/SecondBrain` Markdown 仍是唯一真实数据。复用既有 Supabase 项目和 Vercel，把笔记正文、元数据、关联做成可重建的私人云端副本。正文不进入 Git、静态构建或匿名接口。

网站输入资料库访问码后，显示真实蒲公英、目录、搜索、正文和关联。云端首版只读，编辑仍在本地 Obsidian。第三方 MCP 使用独立只读 token；同步使用独立写入 token。至少 32 字符，全部由 Vercel 服务端校验。前端只保存当前会话的输入，不嵌入预置凭据。

同步创建新 generation，批量上传笔记，最后用乐观版本提交 head 和图谱；失败的批次不得影响上一版可读数据。数据库关闭 anon/authenticated 权限，仅服务端 secret key 可读写。同步请求和单次响应控制在 3 MB 以内，列表分页取得完整结果。

第一版同步 Markdown，不上传图片/PDF。云端引用附件时明确提示在本地查看。备份与重建靠本地源文件；云端不提供反向写入。

验收：未经认证拿不到标题/正文/图谱；错误凭据不能同步；只读 AI token 不能上传；真实数量与本地快照一致；网页阅读和 MCP tools/call 可追溯到原始路径。要求 OAuth 的客户端暂不声称兼容。
