# 宏观攻守综合指标 v2（美股）设计

日期：2026-11-23 · 决策人：manager（用户授权「过程完全你来控制，我只要最完美的结果」）

## 1. 为什么做

站内现在有三套各自为政的攻守判断：`/invest/macro-posture`（四个子指数 + 规则档位）、`/monitor?tab=us` 的 PlainSummary（按问题家族投票）、`/invest/macro-masters` 的 cycleView（200 日线 × 基本面的阶段 + 短线攻守）。结论会互相打架，而且都「未经回测」。

用户要的是：**一个**融合九位宏观大师方法、适合我们自己的指标，直接给出「投资还是防守」；拿不准的指标放外圈并写清楚为什么拿不准、分级；然后能持续回测、迭代。

## 2. 目标 / 非目标 / 反目标

- 目标
  - 一个最终档位（五档）+ 建议股票仓位比例 + 置信度 + 一句话原因 + 距离改判还差什么。
  - 核心指标全部有长历史（≥1971 年，覆盖 ≥7 次衰退），按发布滞后做「当时可得」的月度回测，结果在页面上公开。
  - 外圈指标分 B/C/D 三级，每项写不确定原因（分类 + 说明）和晋级条件。
  - 监测美股页签、宏观大师页都引用同一个结论，不再各下各的结论（它们原有的维度解读保留）。
- 非目标
  - A 股、港股的综合指标（本版继续沿用旧页的「仅作观察」视图）。
  - 个股/行业轮动；日内或周度交易信号。
  - 参数优化。阈值全部先验给定（来自文献与大师公开规则），回测只用来检验，不用来调参。
- 反目标（技术上能跑但算失败）
  - 用短历史序列（HY OAS 只有 3 年）参与计票，导致回测与实盘口径不一致。
  - 回测偷看未来（用观测月当作可得月、用修订后数据却不披露、用当月均价算当月信号的收益）。
  - 结论写成「清仓/满仓」指令；或只有分数没有大白话。

## 3. 方案取舍（Approaches）

| 方案 | 做法 | 取舍 |
|---|---|---|
| A. 前端实时算 | 沿用旧页：浏览器读多个 JSON 现场打分 | 回测必须另写一套，两套口径必然漂移；被否 |
| **B. 脚本统一算（选定）** | Node 脚本拉长历史 → 同一个纯函数模型算「今天」与「历史每个月末」→ 写一个 JSON；前端只渲染 | 单一事实来源，回测与当前读数同口径；CI 每个工作日刷新 |
| C. 服务端 API | Vercel Function 实时算 | 数据源慢且限流，没必要 |

## 4. 模型（规则版本 `v2.1`（v2.0 + 4.5.1 修复确认））

### 4.1 结构

```
四根支柱（周期底层，3–12 个月）            外圈（不计票）
  增长与就业 G  权重 0.35                   B 预警：触发时只降低置信度并提示
  信用       C  权重 0.30                   C 背景：长期风险预算，不择时
  货币与流动性 M 权重 0.20                   D 待接入
  通胀       I  权重 0.15
        │
  R = Σ w·pillar（缺支柱按可用权重重新归一；G 或 C 缺失 → 证据不足）
        │  → 周期档位（阈值 4.3）→ 熔断规则（4.4）
        │
  战术修正：标普月均价低于 10 个月均线 → 下调一档（只降不升，最低到防守）
        │
  最终档位 → 建议股票仓位（占你自己设定的股票上限的比例）
```

### 4.2 组件打分（每项取 −2 / −1 / 0 / +1，缺数据为 null；支柱分 = 非空组件均值，非空组件不足一半则支柱为 null）

**增长与就业 G**（德鲁肯米勒：就业与盈利；达利欧：增长相对预期；都铎·琼斯）

| id | 指标（FRED） | 打分 |
|---|---|---|
| sahm | 实时萨姆规则 SAHMREALTIME | ≥0.50 → −2；≥0.30 → −1；<0.20 → +1；否则 0 |
| claims | 初请四周均值 IC4WSA ÷ 过去 52 周最低值 − 1 | ≥30% → −2；≥15% → −1；≤5% → +1；否则 0 |
| payrolls | 非农 PAYEMS 近 3 个月平均月增幅（占 3 个月前水平） | <0 → −2；<0.05% → −1；>0.12% → +1；否则 0 |
| indpro | 工业生产 INDPRO 6 个月年化变化 | <−2% → −1；>2% → +1；否则 0 |

**信用 C**（马克斯：风险溢价；德鲁肯米勒：信用利差先行；达利欧）

| id | 指标 | 打分 |
|---|---|---|
| baaLevel | Baa − Aaa（BAA − AAA 月均）在过去 120 个月中的百分位 | ≥90 → −2；≥75 → −1；≤35 → +1；否则 0 |
| baaChange | Baa − Aaa 6 个月变化（百分点） | ≥+0.40 → −2；≥+0.20 → −1；≤−0.15 → +1；否则 0 |
| nfciCredit | 芝加哥联储 NFCI 信用分项 NFCICREDIT：水平与 13 周变化取更差者 | 水平 >0.75 → −2；水平 >0.25 或 13 周升 ≥0.25 → −1；水平 <−0.50 且 13 周变化 ≤0 → +1；否则 0 |

**货币与流动性 M**（德鲁肯米勒：流动性；都铎·琼斯：联储方向、金融条件；达利欧：收紧周期与实际利率）

| id | 指标 | 打分 |
|---|---|---|
| fedPath | 联邦基金利率 FEDFUNDS：12 个月变化 Δ12、6 个月变化 Δ6 | Δ12 ≥ +3.0 → −2；Δ12 ≥ +1.5 → −1；Δ6 ≤ −0.50 → +1；否则 0 |
| curve | GS10 − TB3MS（月均） | 当前 <0 → −1；过去 12 个月曾 <0 而当前 ≥0（解除倒挂）→ −1；>1.0 且过去 24 个月无倒挂 → +1；否则 0 |
| nfci | NFCI 总指数：水平与 13 周变化 | 水平 >0 → −2；水平 >−0.30 且 13 周升 >0.15 → −1；水平 <−0.40 且 13 周变化 ≤0 → +1；否则 0 |
| realRate | FEDFUNDS − 核心 PCE 同比 | >2.0 → −1；<0 → +1；否则 0 |

**通胀 I**（达利欧：增长 × 通胀象限；都铎·琼斯：通胀水平）

| id | 指标 | 打分 |
|---|---|---|
| corePce | 核心 PCE 指数 PCEPILFE：同比 y、6 个月年化 a6 | y ≥4 且 a6 ≥ y → −2；a6 ≥3.5 或（y ≥3 且 a6 > y+0.3）→ −1；a6 ≤2.5 且 a6 ≤ y → +1；否则 0 |

阈值相等时按「更差」一侧（≥ 判负、> 判正）。所有阈值写在模型常量里并输出到 JSON 的 `rule` 文本。

### 4.3 档位

| 档位 id | 名称 | R 区间 | 建议股票仓位（占你股票上限） |
|---|---|---|---|
| offense | 进攻 | R ≥ 0.50 | 100% |
| lean-offense | 偏进攻 | 0.15 ≤ R < 0.50 | 85% |
| neutral | 中性 | −0.25 < R < 0.15 | 70% |
| lean-defense | 偏防守 | −0.75 < R ≤ −0.25 | 50% |
| defense | 防守 | R ≤ −0.75 | 30% |

### 4.4 熔断规则（在 R 分档之后依次应用，取更防守者）

1. `recessionCredit`：G ≤ −1.25 且 C ≤ −0.75 → 防守。
2. `creditStress`：C ≤ −1.25 → 最多偏防守。
3. `sahmTrigger`：sahm 组件 = −2 → 最多偏防守。
4. `inflationSqueeze`：I = −2 且 M ≤ −1 → 最多中性。

### 4.5 战术修正

月末：标普 500 月均价 < 其最近 10 个月均价（含当月）→ 下调一档。当前读数另外展示日频「标普是否在 200 日线下方」作为 B 级预警项，不改变档位（保持与回测同口径）。

### 4.5.1 修复确认（v2.1，回测后加入）

v2.0 回测显示：就业、工业生产、利差变化这些同步指标转差时，市场常已接近底部，「偏防守」一档之后 12 个月平均回报反而达 13%。马克斯（利差宽且不再走阔时承担风险）、德鲁肯米勒（「坏但不再变坏」时进场）、都铎·琼斯（价格回到 200 日线上方）的共同做法是「修复期」重新进攻。规则：最终档位为偏防守或防守，且标普月均价不低于 10 个月均线、企业债利差半年变化未达 +0.20 个百分点、NFCI 信用分项 13 周未上升 → 上调一档。

这是看到 v2.0 回测之后加入的规则（事后），只检验了三种写法，选了改动最小的一种；1973–1999 与 2000–2026 两段都改善（夏普 0.607→0.614、0.753→0.775，年化收益各升约 0.1 与 0.3 个百分点，最大回撤不变）。回测页同时列出 v2.0 结果作对照，并在披露中写明。

修复确认允许越过「衰退+信用」熔断（防守 → 偏防守）：2009 年式的「经济仍差但价格趋势已修复、利差不再走阔」正是马克斯与德鲁肯米勒主张回补的阶段（审查后 manager 决定）。

### 4.5.2 月内趋势预估

当月未结束时，用 FRED SP500 日线算月内至今均价，与「前 9 个完整月 + 本月至今」的 10 个月均价比较，提示「若按此收在月底，将触发/不触发战术修正」。只提示，不改变档位。

### 4.6 发布滞后（「当时可得」）

在日期 D 取每条序列「可得日 ≤ D」的最新观测。可得日：

| 序列 | 可得日 |
|---|---|
| SAHMREALTIME、UNRATE、PAYEMS、INDPRO（月 m） | m+1 月最后一天 |
| PCEPILFE（月 m） | m+2 月最后一天（保守） |
| BAA、AAA、FEDFUNDS、GS10、TB3MS（月均，月 m） | m 月最后一天 |
| IC4WSA（周六 d） | d + 5 天 |
| NFCI、NFCICREDIT（周五 d） | d + 5 天 |
| 标普月均价、股息率（月 m） | m 月最后一天 |
| USREC | 只用于评估，不进信号 |

修订：除 SAHMREALTIME 外都是最新修订值（ALFRED vintage 待接入，列为 D 级）。页面必须披露。

### 4.7 置信度

- agree = 非空支柱中与最终档位方向一致的个数（进攻侧：支柱分 >0；防守侧：<0；中性：|分| < 0.5）。
- 基础：agree ≥ 3 为高，agree = 2 为中，其余为低；与档位相反的 B 级预警 1–2 项降一档，≥3 项降两档（最低为低）；任一核心组件过期（超出该频率允许的过期天数：周频 21 天、月频 75 天，PCE 105 天）。
- B 级预警「相反」：档位在中性以上而某项预警为 warn。

### 4.8 距离改判

- 输出 R 到上一档、下一档阈值的差，以及「哪个组件最接近翻档」：每个组件给出下一个更差阈值和更好阈值（数值 + 大白话），前端展示离阈值最近的 3 个。

## 5. 外圈（不计票）

| 级别 | 含义 | 本版条目（至少） |
|---|---|---|
| B 预警 | 逻辑强、实时有用，但历史短或口径不稳；触发时降低置信度并提示 | HY OAS（≥500bp 或 4 周升 ≥50bp）；CCC−HY 12 周背离 ≥200bp；标普成分股站上 200 日线占比 <50%；VIX ≥30；标普日线跌破 200 日线；美元净流动性 13 周变化（≤ −2%）；10 年盈亏平衡通胀 12 周升 ≥0.30；前瞻 EPS 下修 |
| C 背景 | 长期预期回报/风险预算，择时力弱 | CAPE 百分位；巴菲特指标；股债利差；FINRA 融资余额同比；CFTC 杠杆基金净仓；CNN 恐惧贪婪 / AAII / NAAIM；铜金比；联邦债务/GDP；居民股票配置占比 |
| D 待接入 | 方法上有价值但没有可用数据 | ISM PMI（授权）；ALFRED 历史版本（修订偏差）；当时可得的盈利修正历史；SLOOS 信贷标准；HY OAS 长历史（ICE 授权） |

每项字段：`uncertainty.kind` ∈ 历史太短 / 授权受限 / 修订偏差 / 择时力弱 / 与核心重复 / 尚未接入；`uncertainty.text` 一句话；`promote` 晋级条件（默认：同口径历史 ≥20 年且覆盖 ≥2 次衰退，加入后回测最大回撤或误报改善且 CAGR 不下降）；`masters` 对应大师。

## 6. 回测

- 区间：1973-01 月末起（第一个四根支柱齐全的月份往后）到最近一个完整月。
- 收益：标普总回报 ≈ 月均价变化 + 股息率/12；现金 = TB3MS/12。月末 t 的档位用于 t+2 月的收益（额外滞后一个月，抵消月均价的平滑），不计税费。
- 变体：
  1. `full` 完整模型；
  2. `macro` 去掉战术修正；
  3. `trend` 只用 10 个月均线（上方 100%、下方 50%）；
  4. `static70` 恒定 70%；
  5. `buyhold` 恒定 100%。
- 指标：年化收益、年化波动、最大回撤、夏普（超额于现金）、卡玛、平均股票仓位、每年换档次数。
- 分档统计（full）：月数与占比；未来 3/6/12 个月标普总回报均值、12 个月中位数、12 个月为负的比例、未来 12 个月平均最大回撤。
- 衰退捕捉：NBER 每次衰退起点前 12 个月到后 6 个月内，首次到偏防守或更防守的月份与提前月数。
- 误报：连续 ≥2 个月偏防守及以下、且其后 12 个月内没有衰退起点的段落，附该段起点后 12 个月标普回报与最大回撤（让用户看到「误报」也常伴随大跌）。
- 单项检验：每个核心组件，score<0 时与 ≥0 时的未来 12 个月回报差、score<0 时 12 个月为负的比例。
- 时间线：每月 {日期, 周期档位, 最终档位, 标普月均价, 衰退标记}，前端画带衰退阴影的档位色带。
- 披露：样本内；阈值先验设定未调参；除萨姆规则外为修订后数据；月均价近似；未计税费与交易成本。

## 7. 页面与交互（`/invest/macro-posture`）

顺序（从结论到证据）：

1. **结论卡**：五段档位条（当前段高亮）、档位名、建议仓位（「股票仓位约为你上限的 70%」）、置信度徽标、一句话原因、驱动来源（宏观 / 熔断 / 战术修正）、数据日期。右侧或下方「距离改判」：升一档还差什么、降一档还差什么。
2. **四根支柱**：每根一张卡，分数条（−2…+1）、权重、一句大白话、组件列表（当前值、打分、阈值、对应大师），近 5 年支柱分迷你走势；默认折叠组件明细，点开看。
3. **战术修正与熔断**：哪些规则当前生效。
4. **外圈**：B 预警灯（亮/灭）在上，C、D 折叠；每条写「为什么不计票」与「晋级条件」。
5. **大师怎么看**：九位大师各自一句结论（复用 macro-masters 的 `buildCycleView`），与本指标同向/反向标记；链接到大师页。
6. **回测**：档位色带 + 标普走势 + 衰退阴影；变体对比表；分档统计表；衰退捕捉与误报列表；披露。
7. 方法说明（规则版本、权重、阈值）与免责声明。

交互：顶部锚点导航（吸顶），市场切换（美国 / A股 / 港股：A 股、港股沿用旧视图）；移动端单列，表格横向滚动容器；所有颜色走 CSS 变量，亮暗主题都可读；`prefers-reduced-motion` 尊重。
