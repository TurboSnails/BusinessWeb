# 组合再平衡回测页 · 设计文档

日期：2026-11-21（2026-11-22 修订）　状态：用户已确认（2026-11-22，"根据你的建议来吧"）

## 1. 要做什么、为什么

用户在对话里反复问"把 MSFT 换成 INTC 呢""加一只 AXP 呢""偏离 10 个点呢"，每次都要 manager 临时下载数据、写脚本、算结果。要把这套思路做成网站上的一个页面：选几只股票、填目标权重、选再平衡规则，马上看到和"不动"、和"等权"、和纳指 100 的对比，以及当前离触发线还有多远。价格和分红数据预先存进仓库，定时更新，页面不再临时请求外部接口。

用户是这个站的唯一使用者，本人做投资决策；页面是研究工具，不是买卖建议。

## 2. 目标、非目标、反目标

**目标**

- 投资 › 实验观察下新增页面 `/lab/portfolio-rebalance`。
- 用户能在已存数据的股票里挑 2 到 10 只，填权重（合计 100%），选规则，设起点、成本、初始金额，一键得到结果。
- 结果至少包含：四格对比（自定义权重 / 等权 × 不动 / 动态平衡）加纳指 100；核心指标表；逐年收益；调仓记录；当前各只占比与离上下沿的距离；逐一剔除一只的对比。
- 价格与分红数据存进仓库，由定时工作流更新；数据经两个来源交叉核对。
- 计算引擎与 2026-11-21 已完成并经独立复算的研究脚本结果一致。

**非目标**

- 不做统计显著性检验（自助法太重，页面上明确写"未做显著性检验"）；正式结论仍走 `docs/research/` 的预注册流程。
- 不支持页面上临时输入任意代码去在线取数；新代码由 manager 加进数据清单。
- 不接入真实持仓、不做下单、不做影子账户（影子账户是后续单独任务）。
- 不支持 A 股、港股（本期只做美股与美股 ETF）。

**反目标（做到了也算失败）**

- 页面给出"最优阈值""推荐组合"之类的结论，或把回测最高的规则高亮成推荐。
- 用未经交叉核对或缺分红的数据却不标注。
- 结果里出现前视偏差（当天收盘判断、当天收盘成交而不说明）。

## 3. 约束

- 沿用项目技术栈与规范：React 18 + TypeScript + Vite，页面用 `<Page>`，共享样式与令牌，文字不小于 12px、控件不低于 32px，涨跌色按美股口径（绿涨红跌），见 README"研究口径与界面约定"。
- 不新增 npm 依赖。图表优先用项目已有的 `lightweight-charts`，或简单 SVG。
- 数据文件放 `public/data/`，单文件体积控制在 150KB 以内；页面按需加载所选代码的文件。
- 数据源：Yahoo Finance，经 yfinance 在 GitHub Actions 上采集（与现有财报日历工作流相同的方式与版本，`uv run --python 3.12 --with yfinance==1.8.0`），取完整历史的复权收盘价（含拆股与分红）与原始收盘价、分红、拆股记录。腾讯不复权日线用于逐日交叉核对。本机对 Yahoo 限流，采集只在 Actions 上运行；本地开发用已提交的数据文件。
- 不用 Nasdaq（其条款禁止自动抓取与再分发，数据会进入公开仓库与网站）；Stooq 要求人机验证，不用。
- 数据以整理后的形式存进公开仓库与网站，用户已确认可以接受（与财报日历做法一致）。

## 4. 考虑过的做法

| 做法 | 取舍 | 结论 |
|---|---|---|
| 网站页面，数据预存 | 最方便反复试；要做数据管道和页面 | **用户选定** |
| 命令行脚本出 Markdown | 做得快；每次要在终端跑 | 未选 |
| 页面通过 Vercel 函数实时代理行情接口 | 可查任意代码；受外部接口限流与失败影响，结果不可复现 | 不用，违背"免得每次请求" |

## 5. 设计

### 5.1 数据

**代码清单** `scripts/portfolio-prices/universe.json`（人工维护）：每项 `symbol`、中文名、类型（stock / etf）、腾讯代码（纳斯达克 `.OQ`、纽交所 `.N`、NYSE Arca `.AM`）、分组（成长 / 高波动 / 稳定 / 基准，仅作页面默认分组提示，不影响计算）。首批与 2026-11-21 探索一致：成长 AVGO、META、MSFT、NVDA、AMZN、GOOGL；高波动 RKLB、SOFI、PLTR、TSLA、COIN、HOOD；稳定 CB、KO、PG、JNJ、WMT、COST、GLD、AXP、INTC（后两只为用户试过的替换项）；基准 QQQ、QQEW。

**采集脚本** `scripts/portfolio-prices-fetch.py`（由 `uv run --python 3.12 --with yfinance==1.8.0` 执行，与 `scripts/earnings-calendar-yf.py` 同一方式）：

1. 对每个代码取 2010-01-01 起的完整日线：原始收盘价、复权收盘价、分红、拆股。每次**整体覆盖**写入（新拆股或分红修订会自动反映在全部历史里）。借壳上市的代码在清单里写 `validFrom`（RKLB 2021-08-25、SOFI 2021-06-01），之前的数据不写入。
2. 用腾讯不复权日线做交叉核对（Node 脚本或同一 Python 脚本内实现均可）：最近 2 年日期集合一致；Yahoo 原始收盘价与腾讯收盘价差异不超过 0.5%。腾讯单次最多 2000 条，分段请求。
3. 交叉核对不通过、或单日复权收益超过 ±50% 且不在已知事件清单内的代码，本次不写入（保留上次文件），并在 `index.json` 标记 `status: "stale"` 与原因；脚本最终以非零退出提醒，但其余代码照常写入。
4. 分红缺失（Yahoo 未返回分红而该股历史上有分红）时标记 `dividendStatus: "missing"`，页面提示。

**数据文件** `public/data/portfolio-prices/<SYMBOL>.json`：

```json
{
  "symbol": "AVGO", "name": "博通", "type": "stock", "currency": "USD",
  "asOf": "2026-11-20", "fetchedAt": "2026-11-21T22:50:00Z",
  "source": { "prices": "Yahoo Finance（yfinance 1.8.0），复权收盘价含拆股与分红", "crossCheck": "腾讯不复权日线，最近 2 年 0 处差异" },
  "dividendStatus": "ok", "status": "ok",
  "splits": [["2024-07-15", 10]],
  "dates": ["2010-01-04", "..."],
  "adjClose": [3.12, "..."],
  "close": [31.2, "..."]
}
```

另生成 `public/data/portfolio-prices/index.json`：每个代码的名称、分组、首末日期、状态、分红状态、`asOf`，供页面列出可选股票。单文件目标 150KB 以内，超出时把 `close` 去掉只保留 `adjClose`。

**定时更新** `.github/workflows/portfolio-prices.yml`：美股交易日收盘后（UTC 22:45，周一至周五）运行，有变更才提交；支持手动触发。首批数据由第一次手动触发生成。在 `docs/data-maintenance.md` 增加一节说明口径与维护方法，并接入现有数据新鲜度检查（`scripts/data-freshness-check.mjs`）。

### 5.2 计算引擎

`src/features/portfolio-rebalance/engine.ts`，纯函数，无副作用，页面与测试共用。

- **输入**：代码列表、目标权重、规则、起点、成本、初始金额、价格与分红数据。
- **对齐**：取所选代码与基准都有数据的共同交易日；起点早于最晚上市的代码时，自动改为共同起点并在结果里说明。
- **日收益**：`r_t = (P_t + D_t) / P_{t-1} − 1`。
- **规则**：
  - 不动（买入持有）。
  - 相对偏离 x%：每只的允许区间是 `目标 × (1 ± x%)`。
  - 绝对偏离 x 个百分点：每只的允许区间是 `目标 ± x`。
  - 每月 / 每季固定：期末最后一个交易日决定。
  - 触发判定：任一只占比到达或越过区间边界即触发（含边界）。
  - **大跌切换**（可叠加在任一再平衡规则上）：指定一只稳定资产；QQQ 相对本轮最高收盘回撤首次达到进入阈值（默认 −20%）进入大跌状态，此后每多跌一个档距（默认 5 个百分点）执行一步；每步卖出"进入当日稳定资产市值 × 每步比例"（默认 25%），买入当前权重 ÷ 目标权重最低的非稳定资产；可选"累计卖出上限"（页面默认 50%，依据长期压力测试）与"超时恢复"（默认关闭；压力测试中 18 个月超时结果最差，页面在该选项旁说明）；大跌状态暂停普通再平衡；QQQ 回撤回到恢复阈值以内（默认 −5%）次日全部调回目标，从恢复日重新记最高价。规则与 2026-11-21 探索报告 `docs/research/portfolio-rebalance-explore-2026-11-21/drawdown-switch.md` 一致。
- **执行**：第 t 日收盘判断，第 t+1 日收盘成交，全部调回目标权重；成本 = 单边换手 × 成本率，从净值扣除。（与研究脚本一致。）
- **输出**：每条净值序列；期末金额、年化收益（按日历天数折算年份）、年化波动、最大回撤及起止日、风险调整收益 CER（γ = 3）、调仓次数、年化换手、累计成本、期末各只占比；逐年收益；调仓记录（日期、触发的代码及占比、各只买卖金额）；当前状态（各只占比、区间、其余不动时再涨或再跌多少触发）。
- **派生**：同一组代码的等权版本（相对偏离直接沿用；绝对偏离按"新目标 ÷ 原目标"等比例换算百分点数，与研究报告一致）；逐一剔除一只（剔除者的权重按比例分给其余各只，规则同上）；基准 QQQ、QQEW 买入持有。

### 5.3 页面

`/lab/portfolio-rebalance`，标题"组合再平衡回测"，加入站点地图"实验观察"组。

- **规则区补充**：大跌切换开关及参数（稳定资产、进入阈值、档距、每步比例、恢复阈值、累计卖出上限、超时恢复）；开启时结果区增加"逐轮大跌"表（进入日、步数、恢复日、该轮相对普通再平衡的收益差）。
- **输入区**：从 `index.json` 列出可选代码（按核心 / 投机 / 基准分组显示），选中后填权重，显示合计并在不等于 100% 时禁止计算；"等权填充"按钮。规则单选（相对偏离、绝对偏离、每月、每季）及参数输入。起点（默认所选代码共同最早日）、成本（默认 0.10%）、初始金额（默认 100 万）。所有输入写进网址参数，刷新或分享后恢复。默认打开时预填用户当前方案：AVGO、META、CB 各 25%，SOFI、RKLB 各 12.5%，相对偏离 40%，大跌切换关闭。
- **结果区**（从上到下）：
  1. 四格对比表（自定义权重 / 等权 × 不动 / 动态平衡），每格显示期末金额、年化、最大回撤；下方一行纳指 100（QQQ、QQEW）。
  2. 核心指标表（第 5.2 节的输出指标）。
  3. 净值曲线（自定义权重的两条线加 QQQ，可切换对数坐标）。
  4. 逐年收益表。
  5. 当前状态表（离上下沿的距离），截至数据最后一天。
  6. 逐一剔除对比表。
  7. 调仓记录（默认折叠）。
- **常驻提示**：数据截止日期与来源；缺分红或分红过期的代码逐个列出并说明"该股只算价格涨跌，结果偏低"；"组合是事后选的，回测不代表以后""未做显著性检验""规则之间的收益差异常由少数几次调仓时点决定，不要按回测最高值挑规则""不构成投资建议"。
- **不做**：不高亮"最佳"规则，不给推荐。
- 计算在浏览器里同步完成；10 只股票、10 年数据、逐一剔除共约 25 条模拟，预期在 1 秒内。

### 5.4 验证

- **引擎回归测试**：用已提交的 `data-raw/portfolio-explore/prices-adjusted.json`（腾讯拆股调整价，不含分红）作夹具，必须复现 2026-11-21 探索中四个执行者与 manager 独立程序一致的锚点（期末倍数四位小数、交易次数一致）：AVGO、META、CB 各 25%，SOFI、RKLB 各 12.5%，2021-08-25 至 2026-11-20：买入持有 3.1020 / 0 次，相对偏离 40% 3.6138 / 17 次，大跌切换主设定 4.2821 / 21 次；AVGO、META、CB 各 25%，TSLA、NVDA 各 12.5%，2016-01-04 起：买入持有 29.7227，相对偏离 40% 18.1600 / 16 次；QQQ 买入持有 1.6234。另覆盖：拆股日无跳变、分红日收益、边界恰好触发、次日成交、等权与剔除的权重换算、共同起点自动调整。
