# Human 3.0 人生访谈

入口：自由之路 → 人生规划，路由 `/life/human-3`。页面只包含通用框架与工具，不包含开发对话中的个人资产、健康或家庭记录。

复用 `/api/ask` 的 MiniMax、Supabase 登录、原子额度扣减与失败退款；不新增数据库迁移、模型密钥或 Vercel 函数。请求增加 `mode: human3`、`action: interview | report` 与交替的 assistant/user 历史。服务端验证消息角色、长度、轮数与总量。未知模式拒绝，原来的投研方法问答保持原范围。

目前与 AI 试问共享每天2次模型调用，按北京时间重置；首个问题静态显示免费，追问及报告分别耗1次。不是每天两份完整访谈。至少5轮后可生成初稿，最多24轮；报告证据不足时要求标待判断。用户输入提供的历史并不是真实身份或额度依据，身份始终由服务端向 Supabase 验证。

隐私：默认仅内存，不持久保存；用户勾选后在本机 localStorage 保存，取消勾选或清除重置删除。OAuth 跳转前需用户先选择本机保存或导出，以免页面跳转丢失草稿。导出包含访谈、草稿与报告，文件不自动上传。每轮完整历史会发送到模型服务商；模型输出仅通过 React Markdown 子集渲染，不执行原始 HTML。

登录继续使用已配置的 `/ai` OAuth 回跳，sessionStorage 中的固定标记使 AskLab 取到令牌后返回人生访谈。回跳只允许固定站内目标，不接收任意重定向 URL。原 `/ai` 登录路径保持可用。

本地 Vite 的 `/api/ask` 代理到生产后端；后端新模式未部署前，本地 UI 对生产模型请求会被旧后端拒绝。自动测试通过模拟外部网络验证本地 handler 和界面，不能据此声称线上真实 MiniMax 调用已验证。发布后需要用登录用户在新页面验证一次追问和额度；真实模型质量并不能由提示词字符串测试保证。

模型依据：[Dan Koe 的原始说明](https://thedankoe.com/letters/human-3-0-a-map-to-reach-the-top-1/)。页面为独立实现，不宣称官方评估或经过验证的心理测量。等级按四象限分别给出，需要可引用的用户证据；财富、学历或使用 AI 工具的数量不直接决定等级。

## 页面与交接核对（2026-10-21）

这是既有纸书茶室界面中的操作与阅读工具。已对照 `HumanLifePlan.tsx`、`human-life.css`、`index.css`、共享 `Page` / UI 样式及 `.impeccable/review/human-desktop.png`、`human-mobile.png`：沿用暖纸底、衬线标题、鼠尾草绿操作、细分隔线和共享 Page 宽度；桌面为四象限说明与访谈双栏，760px 及以下将访谈放在说明之前，提交按钮铺满可用宽度。输入与状态提示使用既有浅底和圆角语汇。本次只是局部扩展，不建立新视觉系统，也不改动全局设计文件。

额度刷新在当前页面重新查询，不触发整页重载；草稿与访谈继续保留。报告按钮至少5轮才可用，有未提交草稿时也不可生成。单条回答最多2000字符、顾问消息最多4000字符，提交历史最多48条交替消息、合计60000字符；24轮为访谈上限。服务端对追问和报告分别设置900与5000输出 token 上限；这些限制不保证一次报告完整或结论有效，证据不足仍须标“待判断”。现有每日2次共享额度、本机保存自愿勾选、经 `/ai` 登录回到本页的行为与上述实现一致。

既有产品上下文偏差：根目录 `PRODUCT.md` 目前描述投资研究与综合估值页面，没有覆盖自由之路的人生访谈用途。这是已有文档范围偏窄，本次仅记录，不擅自改写产品定位。截图只作为界面布局与状态文案证据，不据此认定真实登录、额度或模型服务已完成线上验证；交接未收集个人访谈资料。

## 密码阅读个人解析

用户授权把个人解析另存为 `/life/my-analysis`，入口在自由之路的人生规划区域。正文仅以 `src/features/human3/personal-report.encrypted.json` 密文存入项目；访问密码不写入客户端或仓库。页面使用 Web Crypto，在浏览器内以 PBKDF2-SHA256（600000次）派生 AES-256-GCM 密钥；每次生成使用随机16字节 salt 和12字节 IV。没有密码无法直接从网页资源读取明文。密码强度仍决定抵抗离线猜测的能力；这不是服务端账号鉴权或防暴力破解系统。

解锁内容和密码均不持久保存，不发送给问答接口；刷新、离开或重新锁定后需重新输入。报告标记 noindex，站点地图不登记此路由。重新编辑时，把明文放在仓库外，通过 `PRIVATE_REPORT_PASSWORD` 环境变量运行 `scripts/encrypt-life-report.mjs <外部明文路径> <密文输出路径>`，只提交密文；不将密码、明文或解锁截图提交到项目。

本次新增验证：真实正确密码解锁、错误密码拒绝、密文篡改拒绝、重新锁定、刷新后重新锁定，以及手机无溢出。全量190个测试文件、1246个测试通过；类型检查、目标文件lint、Vite生产构建通过。检索源码、公开资源和构建产物未发现密码或报告特征明文。解锁截图仅在项目外临时查看，不作为公开网站资源。

设计交接：对照 `PersonalLifeAnalysis.tsx`、`personal-life.css`、共享 `Page` 的 reading 变体及桌面/手机锁定截图，确认这是纸书茶室体系内的阅读扩展，保留暖纸底、衬线标题、鼠尾草绿控件和760px正文宽度。解锁表单最大360px，移动端随可用宽度收缩；解锁后的工具栏、段落、标题与表格沿用同一阅读层级，宽表在自身容器内横向滚动。项目外的解锁截图仅核对布局，不复制其正文或密码。另已核对浏览器解密与生成脚本的派生参数和密文格式一致，以及重新锁定时清空页面状态；此页不改写全局视觉规范。上述已有 `PRODUCT.md` 范围偏差仍保留待后续整理。

## 可复制的原始提示词

访谈页新增“人生规划提示词”区域，原文保存在 `src/content/human3-interview-prompt.md`。展示与复制共用同一份原文，保留用户的四象限、逐题访谈、识别重点和90天规划要求。按钮可直接复制完整文本；权限不足时自动展开、聚焦并选中只读文本，提示手动复制。此功能无需登录或调用模型。
