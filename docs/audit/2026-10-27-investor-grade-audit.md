# 专业投资平台视角审计（2026-10-27）

分支 `audit/investor-grade-2026-10-27`。范围：数据可信度（A 线）与交互/内容/排版（B 线）。
原则：只改展示层与采集/校验逻辑；不改投资观点、不手改数据文件；拿不准的只记录或只加提示，不动。

## 方法与证据

- 价格：抽样 24 个标的对照腾讯行情；美股 6/6 完全一致。
- 数据：对 `dcf-prefill.json` 的 654 条做勾稽与完整度检查；对 1299 张公司卡片查情景价顺序、价格锚点、评级、标题/备注比值。
- 一手来源：直接取 SEC XBRL（CSX）与东方财富港股报表原始响应（金沙中国、万洲国际、中国石化、腾讯等）核对。
- 独立复算：用 Python 从原始基础单位重算 439 家公司的 DCF，与「预填 → 引擎」全链路对比，全部在 2% 内（说明单位换算与引擎算术正确）。
- 页面：390px 宽度下对 20 个核心路由、190 个公司页测横向溢出、空页、加载错误与占位符。

## A 线：已修复

### A1 港股财报被重复折算汇率（影响最大）
东方财富港股标准化报表恒为港元，采集器却按「报告币种」再乘一次汇率。
- 证据：88 家折算过的港股，存储值 / 一手来源值恰好等于汇率（美元报告 14 家 ×7.845，人民币报告 74 家 ×1.1765）；金沙中国营收来源值 523.2 亿港元，存储 4104 亿。
- 影响：美元报告的港股 DCF 放大约 7.8 倍，人民币报告的放大约 18%。
- 修复：采集端用报表自身币种；消费端对港股恒按港元，已缓存条目无需重抓即可纠正。
- 实采验证（修复前 → 后，DCF/市价）：金沙中国 35.3× → 3.74×，万洲国际 18.5× → 2.35×，新东方 23.4× → 2.04×，腾讯 1.10× → 0.89×。

### A2 A+H 公司用 H 股股数除全公司估值
港股行情总股本只含 H 股，财报是全公司口径。宁德时代 H 股被放大 21 倍、美的 11.7 倍、中国电信 6.6 倍。
- 修复：按同名 A 股总股本（含 H 股）折算，两边相差不足 5% 视为口径一致（中国联通、中国移动因此不动）；用实时行情匹配出 19 家，并写入条目备注。

### A3 美股债务/现金漏取
- CSX 的债务 188.7 亿美元记在 `DebtAndCapitalLeaseObligations` / `LongTermDebtAndCapitalLeaseObligations`，采集器不读并兜底为 0；现金第一个标签停在 2022 年，挡住了后面仍在更新的标签（现金变成空）。
- 修复：读取含租赁的债务标签；现金等时点字段逐标签找、只收足够新的值。用 SEC 原始数据回放：CSX 债务 0 → 188 亿美元，现金空 → 12.2 亿美元。
- 前端同步：非金融公司现金与投资都缺时，状态改为「数据不全」；债务为 0 但有利息支出时只加「请核对」提示，不改数值。

### A4 盘中价标成收盘价
A 股/港股价格在开盘后抓取，却标成当日、来源写「收盘价」（实测偏差最大 8.2%）。采集时记录报价时刻与 `pxLive`，来源改为「盘中价（HH:MM，非收盘价）」。

### A5 看盘页涨跌家数
`metrics` 缺涨跌家数时隐藏涨跌条、情绪档位只能用涨停/跌停判断，而情绪面已有统计。现回退使用 `sentiment.breadth`。

### A6 `[MISSING]` 占位符外露
约 1 万处占位符在详情页原样显示给读者。数据层保留（程序判断依赖），展示层统一为「未取得」（`displayMissing` / `scrubMissing`，整页与综合估值详情整体处理）。

## 发现但按「拿不准就保留」处理（未改动）

- **标题比值与备注比值不一致（123 张卡片）**：如平安银行标题 ≈1.34:1、备注机械复算 1.70:1。备注已声明旧情景未重估，是已披露的设计取舍；统一口径属观点层面，需你决定。
- **债务为 0 但有利息的美股（约 38 家）**：只加了提示，未改值；哪些是真无债要对照 10-K 才能定，等下一次定时任务用修复后的采集器重算后再看。
- **税前利润与归母净利符号/量级不一致（11 家，如华虹宏力、东方盛虹）**：可能是期间口径不同或确有非经常性项目，需对照财报原文。
- **DCF 假设偏乐观的迹象**：修复后金沙中国仍是市价 3.7 倍，且增速封顶 15%、WACC 区间下限 8% 都是规则化假设；是否合理属方法论问题，未改。
- **页面「未取得」密度**：个别公司页同一页出现 14–17 次，信息缺口比较显眼，是否合并或折叠属内容设计，未改。
- **点击目标偏小**：`/industry-etf` 299 个、`/research-notes` 88 个、`/future-trends` 70 个元素高度 < 32px，其中含正文内链接（天然较矮），需在真机上区分后再改。
- **美国 10 年期国债 5.00%、`RUB/USD` 汇率 404**：前者数值合理但未独立核对来源，后者已写入 `issues`，影响面未评估。
- `npm run lint` 有 25 条警告（0 错误），非本次引入。
