## 四个问题，各交付一份证据

| 问题 | 必须回答 | 新增约束 |
| --- | --- | --- |
| 买什么 | 护城河如何转化为现金与资本回报 | ROIC−WACC、增量 ROIC、再投资空间、治理和每股稀释；不用统一 15% 门槛 |
| 什么价格 | 现价要求什么经营结果，哪些估值方法能约束它 | 财务调整桥、主辅锚、逆向 DCF、三情景；标共同假设与价值时点 |
| 什么时候 | 自己的判断比已定价预期多了什么证据 | 共识快照、经营差异、周期传导、催化与证伪日期；宏观仅作条件情景 |
| 买多少 | 研究错误与多资产同时下跌时能否承受 | 压力损失预算、同簇风险、流动性与上限；凯利仅辅助 |

## 采纳与修正

| 原提法 | 项目采用方式 |
| --- | --- |
| 研发与部分获客费用资本化 | 有寿命、留存与回收证据才调整；利润、投入资本、现金税和再投资同步桥接。单纯重分类不增加 FCF，调整利润不等于 Owner Earnings |
| 逆向 DCF | 固定其他假设反解关键要求，给敏感性；不是唯一市场预期，也不构成正向 DCF 之外的独立方法 |
| ROIC 通常超过 15% | 改为相对资本成本的利差、持续期及新增投资回报；金融公司按行业框架 |
| SOTP 与 PEG | 按业务适配；总部成本、债务、税、少数权益与融资投入不得漏算或重复。PEG/PS 为辅锚，不作统一买入阈值 |
| EPS 增长与 PE 扩张 | 作为回报分解与情景假设；倍数改变须有理由，不预设盈利加速必然带来 PE 扩张 |
| 降息利好高久期资产 | 同时压力盈利、信用利差和风险溢价；降息不保证 WACC 下降或成长股上涨 |
| 25% / 50% / 25% 概率 | 有依据才赋值；无依据只给情景范围，不报期望收益或凯利结果 |
| 悲观价保底 | 删除。增加现金耗尽、再融资、监管、技术替代、联合冲击与股权归零压力 |
| 高胜率敢重仓 | 先核实概率来源、损失预算、相关性和流动性，再受已采用策略上限约束；主观确信不能直接转成比例 |

研发经济重分类参考 [Damodaran 的研发分析](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/R%26D.htm)，会计确认边界参考 [IAS 38 官方说明](https://www.ifrs.org/issued-standards/list-of-standards/ias-38-intangible-assets/)。增长与再投资关系见 [增长的基本决定因素](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/growth.htm)。宏观预测边界见 [Marks：Thinking About Macro](https://www.oaktreecapital.com/insights/memo/thinking-about-macro)；凯利与回撤约束的研究见 [Stanford：Risk-Constrained Kelly Gambling](https://web.stanford.edu/~boyd/papers/kelly.html)。项目的规则与阈值是整合选择，不归为这些作者共同提出的体系。

## 原例的算术与含义

以下均为假设演算，不是市场预测：

- EPS 增长 30%、PE 从 15 到 25：价格回报 `1.3 × 25/15 − 1 = 116.67%`。原文“翻倍以上”的算术成立，但需要证明倍数上调的条件；这还不是含分红、汇率与费用的总回报。
- EPS 增长 30%、PE 从 60 到 25：价格回报 `1.3 × 25/60 − 1 = −45.83%`。
- 三情景 −15% / +25% / +80%，按 25% / 50% / 25%：期望收益 `28.75%`，成立前提是这些情景和概率有依据、期限一致。
- 项目价差比 `25/15 = 1.67`，未达到约 2:1 的偏好。以现价 100、Base=125、Bear=85 为例，2:1 门槛研究价为 `(125+2×85)/3 = 98.33`；仍须复核悲观端与尾部，不能为了达标收窄损失。
- 今日内在价值与未来 T 时点价格分列；没有持有期限不能比较兑现效率。期望终值的年化等价不等于期望复合增长率。

## 对 Claude 建议的选择与保留分歧

Claude 独立意见与 manager 就研发现金流、逆向 DCF 的非独立性、统一 ROIC 阈值、概率和保底风险取得共识；manager 通过 Orca 发出初步观点，Claude 在报告第 9 节回应。没有将模型一致视为投资效果验证。

采纳其补充：经营与倍数联合压力、增量资本回报、再投资、每股稀释、同簇持仓、流动性与时间到期后的重评。保留项目既有个人策略，具体新增风险预算不自行编造。

以下建议经 manager 审查后未照搬：

- **基准情景一律禁止倍数扩张**：过于机械。允许有证据的基准再定价，必须分开说明经营贡献与倍数贡献并给不扩张情景。
- **所有公司强制跨现金流/资产/市场法至少两类**：轻资产公司资产法可能无意义。改为适用主辅锚、不同约束与共同假设披露，不为了凑方法使用 NAV。
- **凡关键输入为研究假设就禁止估值**：估值天然包含假设。区分已核事实、管理层/共识、模型假设与判断；缺少关键事实时等待证据，有依据的条件化情景仍可输出。
- **尾部固定给 3%–5% 概率**：仍会制造伪精确。尾部压力必须有，可以不赋概率；只有覆盖并说明概率分布后才计算完整期望值。
- **凯利作为可靠仓位上界**：概率与尾部错误会使所谓上界失效。仅作为假设敏感性工具，不为现有仓位作安全认证。
- **研发 NOPAT 调整一律乘 (1−税率)**：忽略经济重分类与税务扣除的差异。以现金税/递延税桥为准，不机械套税率。

Claude 报告还含自行构造的凯利、租赁、税及相关性近似示例，未逐项验证，未作为正式模型或阈值采纳。独立报告保存在本地 `.dev-team/runs/valuation-framework/reports/review.md`；本文件记录正式采纳结果。
