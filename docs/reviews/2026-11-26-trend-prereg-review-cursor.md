## 1. 必须改（按严重程度）

### 1.1 【高】「部分成立」被放宽到几乎可吞掉 G6–G8 失败

PREREG：部分成立 = G1、G2、G4 满足，但 G5 **或** G6–G8 中某项不满足。  
stats §2.4：部分成立 ≈ G1/G2/G4 过、**仅 G5 不显著**（检验力低是预期）；其他失败应否决。

按现写法，月末复核失败、0.30% 成本下 G1–G3 崩、换手爆表，仍可「部分成立」进影子。这会把确认检验变成软门。

**改法**：改回 stats——部分成立仅允许 G5 未过（Holm 后不显著）；G6/G7/G8 任一失败 → 不通过。若仍想保留「G5 过但 G6 擦边」的中间档，必须另起名称，且禁止在 G7/G8 失败时进影子。

### 1.2 【高】G7 对 C1/C2 不对称，且偏离 stats

| | stats §2.4 | PREREG |
|---|---|---|
| 0.30% 成本下 G1–G3 | 两候选都要 | **只写在 C2** |
| 切换次数 | ≤ 1.2 × B1（对新候选） | C2 ≤ 1.2 × C1（合理）；C1 无此项（合理） |

C1 是现行规则，更应过成本压力；只压 C2 不公平，也留下「C1 过主门槛、一加成本就垮仍算通过」的漏洞。

**改法**：C1、C2 都要求：主成本 0.10% 下年换手 ≤ 0.40；**0.30% 下 G1–G3 仍成立**。切换次数上限只约束 C2（≤ 1.2 × C1）。0.50% 只报告（与 stats 一致）。

### 1.3 【高】同波动 M、L、ΔE、换手的计算顺序未写死（复现分叉）

未规定：

1. **成本扣在波动匹配之前还是之后**：先对候选扣换手成本再估 σ 配 M，还是用未计成本序列配 M、成本只进绩效？两者 L/ΔE 会不同。
2. **σ 定义**：样本标准差（n−1，与 `calibrate.mjs` 一致）还是总体？波动是月收益 σ，还是超额收益 σ？
3. **w_M 搜索区间**：`calibrate.mjs` 允许到 1.5；预注册未写上界。若候选 σ 极低，两人会取不同夹逼停条件。
4. **L 的净值端点**：下跌段「高点月末到谷底月末」——L 用高点月末 **调仓后** 净值，还是高点月 **初** 净值？`calibrate.mjs` 用收益序列累积后的 `vc[peak]`/`vc[trough]`（peak 为见高点的那个收益月下标）。PREREG 需用同一套下标约定，并写明两端是否含当月收益。
5. **ΔE**：全周期内「候选累计收益 − M 累计收益」是净值比相减 `(V_T/V_0−1) − (V^M_T/V^M_0−1)`，还是对数收益差、还是逐月差再加总？符号「逐段为正」跟哪种定义走，必须钉死。

**改法**（建议写死，与标定脚本对齐）：

- 先生成未计成本的候选月收益序列 → 样本 σ（n−1）→ 二分求 w_M∈[0, 1.5]，使 M 的同口径月收益 σ 与候选一致（容差如 |σ_C−σ_M|<1e-12 或 60 次迭代）。
- 再对候选与 M **同样**扣成本（每单位 |Δw| 乘 0.001 / 0.003；M 恒定故成本为 0）。
- L：对各事件 e，跌幅 = V_{trough}/V_{peak} − 1（V 为扣成本后净值）；L = Σ 跌幅_C / Σ 跌幅_M。
- ΔE：同一端点约定下 Σ[(V^C_T/V^C_0 − 1) − (V^M_T/V^M_0 − 1)]；逐段符号用方括号内差值。

### 1.4 【高】安慰剂放置规则不够精确

「保持防守段数和每段长度，不重叠随机放置」未定义：

- **防守段**：信号月 w&lt;w₀ 的连续段，还是 **收益月** 上实际生效仓位 &lt;w₀ 的连续段？A2 下两者错开 2 个月。
- 1914-08–11 冻结月：原序列里这些月是否算入段长？重放时可否盖住冻结月？
- 放置域：收益月 1872-01–1934-12，还是可放信号月再映射？首尾不足一段长度时如何拒绝采样？
- **PRNG**：种子 20261127 未指定算法（JS Math 不可移植）。必须写死可移植生成器（例如 mulberry32 / PCG）与抽样步骤（先抽起点，冲突则重抽，直至 10000 个有效布局）。
- 每次是否 **重算** w_M 与 L：文中有「每次重算同波动 M 和 L」——保留，并写明 M 用该安慰剂路径的 σ。

**改法**：防守段 = 由信号规则产生的、使收益月生效权重等于防守档的连续收益月（含 A2 映射后）；冻结月保持「不调仓」，安慰剂布局不得在冻结月改变权重；PRNG 与拒绝采样写进附录伪代码。

### 1.5 【中高】G8 信号/对照过窄，且 M 的估计窗未定义

现稿：仅 Ken French 1926-07–1934-12 上 **E8**「候选跌幅 &lt; M」且全周期 ΔE≥0；信号为「月末收盘 vs 10 个月均值，下月生效」。

问题：

1. stats 要求月末序列上 **G1/G2 同向**，并尽量覆盖更长月末样本；现稿缩成单事件、无 L 门槛，趋势规则在 1929–32 上 **几乎结构性地易过**，复核信息量接近零。
2. 此窗内的 M：用全确认期席勒 A2 的 w_M 套过来，还是在 1926-07–1934-12 的 KF 收益上 **重新** 同波动？未写则必分歧。
3. 现金用 KF RF；组合 = w×(Mkt-RF+RF)+(1−w)×RF = RF + w×(Mkt-RF)。写明。
4. 道琼斯 1896–1925 月末复核被整段删掉——若因数据未冻结可改为「探索」，但不可静默消失而不说明。

**改法**：

- G8 主条：KF 1926-07–1934-12，用该窗内收益 **重估** w_M；至少报告该窗内 E7+E8（或全部落在窗内的目标事件）的 L&lt;1 与 ΔE≥0；E8 单独可作加严项。
- 明确组合公式与滞后（月末信号 → 次月收益，不是 A2 的 +2）。
- 若不做道琼斯：在「探索」或「已知局限」写一句「1896–1925 月末序列本次不纳入 G8，因输入未冻结」。

### 1.6 【中高】G9 事件表疑似漏 2020；「合并跌幅」口径与确认期不一致

G9 列举 1973–74、1987、2000–02、2007–09、2022，**无 2020**。按日净值上 2020 是标准 ≥20% 事件；漏列会让否决可被钻空子。

「合并跌幅不高于基线」是绝对跌幅之和，还是确认期那种对同波动 M 的比？G9 对照的是 v2.2 基线不是 M——需显式写出，避免实现者套用 L 的公式。

**改法**：事件表与 E1 引擎按日回撤 ≥20% 的段落对齐（至少补 2020，或写明「按日峰谷、列表以 `run.mjs` 冻结表为准」并在提交前贴表）。指标写死为：Σ(候选段内净值跌幅) ≤ Σ(v2.2 基线段内净值跌幅)（两端点规则与确认期 L 相同）。夏普/最大回撤对照「同一 E1 引擎、同一上限假设下的现行 v2.2」。

### 1.7 【中】1914 停市状态机不完整

「8–11 月不更新信号、不调仓，沿用 1914-07 信号」不够：

- 7 月信号在 A2 下作用于哪几个收益月？冻结期收益（P 平坦）如何进净值？
- 12 月复市：12 月月均价已含复市后交易日——是否允许更新信号？stats 倾向 7→12 整体不可交易、信号从复市后第一个完整月再更新。
- 1933-03 银行假日：PREREG 沉默（stats 已点名）。

**改法**：用表格列出 1914-07…1914-12 每个日历月的：是否更新信号、生效权重来源、该月收益是否计入。建议：8–11 收益仍按席勒公式计入（股息），权重锁在 7 月信号经 A2 映射后的生效权重；12 月起恢复更新。1933-03 注明「月度数据不另处理」或「按缺失交易日比例」二选一写死。

## 3. 门槛公平与是否「必过/必挂」

### 3.1 C1 的 0.95 vs C2 的 0.90

与 stats 比例尺一致：门槛 ≈ 1 − 0.25×降幅/w₀ → C1≈0.956、C2≈0.897，取 0.95/0.90 合理。  
标定（已用段）：C1 L_A≈0.95、C2 L_A≈0.85，δ_L 均为负故不收紧——**自洽**。注意：C1 门槛贴着已用段点估计，确认期稍差就挂 G1，并不表示对 C2 不公。

### 3.2 其余门槛

- **G2 的 5/8**：对更深的 C2 更难（V 形踏空），这是设计目标不是不公；但无「C2 不劣于 C1」门（见 4.2）。
- **G3**：两候选同门槛；C2 对 B0=85% 的 −1pp 更易撞线——可接受，因问的是代价。
- **G5**：事件少、效力低，事前已写——OK。安慰剂在定义补全前 **不可复现**，比门槛本身更严重。
- **G8 现状**：有「结构上偏易过」风险（见 1.5），不是数学恒真，但作为硬门偏弱。
- **未发现**哪条门槛按构造恒真或恒假；最接近的是放宽后的「部分成立」政策错误（1.1）。

### 3.3 δ_L

## 4. 候选与探索

### 4.1 C1 / C2 作为确认对

合理：C1 零设计自由度；C2 的 50% 来自说明书「仅十个月均线」下方档，非本段新搜参。回答的两个问题与 PREREG「问题」节一致。  
相对 quant「T1+T2」与 liquidity「双确认+只在收紧期认均线」，现稿把后两者降为探索——在「≤2 候选」约束下可接受，但应在文中 **一句话说明落选理由**（参数/机制更多、先确认幅度再探机制），以免读起来像无视两份设计。

### 4.2 缺「C2 不劣于 C1」

stats §2.2：新候选须不劣于现行 B1。现稿 C2 只对 M，不对 C1。可能出现 C2「通过」但 L 或 ΔE 差于 C1。

**改法**：加报告门（或 G2 附条）：C2 的 L ≤ C1 的 L，且 C2 的 ΔE ≥ C1 的 ΔE；不满足则不得「通过」（可仍「部分成立」仅当其它条允许——更干净是直接不通过）。

### 4.3 探索项

- **X1**：stats §3.1 要求单独报告去掉 k=1 的版本——现稿未写，应补（否则 Working 效应集中在短窗）。
- **X2**：缺 liquidity 强调的同频率对照「破位一律 50%、不问 L」与 L 分块安慰剂；前置诊断（L 占比、高点前 3 个月）已有——保留。L 定义按 2 节改清。
- **敏感性**：原始 CP、底仓 70% 够用；stats 的 `max(CP−1.5,0)` 可作可选第三敏感项。
- 不多余；不建议再塞 T3/T4 进确认。

## 5. 其他会伤可信度的点

1. **换手 / 切换次数单位**：写明年换手 = (Σ_t |Δw_t|) / (确认年数)；切换 = 相邻信号月防守状态变化次数（或收益月生效档变化次数，与防守段定义一致），并报年均。G7 的 1.2× 用同一单位。首月 |Δw| 是否计入换手（成本已说首月不计）——建议换手统计也不计首月，与成本一致。
2. **CER / 夏普差**：写明 x = 月收益 − 现金月收益；var 为样本方差；夏普差 = Shar pe(C)−Sharpe(M)，用循环分块自助的是该差值；块长 12、10000、种子之外加 PRNG。
3. **B0=85%** vs stats 草稿的 70%：与「偏热偏进攻」叙事一致，可保留，但 G3「对 B0」依赖该选择——不要事后改 B0。
4. **学术污染**：文中已承认——好；通过仍是弱证据，结论分级措辞已有，保持。
5. **G9 对 C1「不适用」**：逻辑通（C1=现行），但「通过 = G1–G8 且 G9 不触发」对 C1 等于无现代否决。可接受；若担心现行规则在确认期「通过」被过度解读，结论里已有「规则不变」——保持即可。
6. **交叉评审栏**仍空：采纳本审及另一份审的修改后填写；未填就提交会削弱预注册完整性。
