## 1. 总体判断

结论：**保留框架，修改 2:1 价差比的呈现与年化口径，拒绝把“2:1 研究价”当作买入参考价。**

- 四问框架（买什么 / 什么价格 / 什么时候 / 买多少）作为研究纪律合理，文档对“不用单一分数替代判断”的表述也克制。
- 计算层的公式在其声明的口径内是正确的（见第 2 节算术验证）。问题主要在于：这些公式被包装成了比它们能支撑的结论更强的决策信号。
- 方法论正确性与工具完整度需要分开看：
  - **方法论正确性**：持有期收益、年化、三点期望、价差比、研究价公式均正确；文档对“未折现、未扣税费、概率非胜率”的披露也基本到位。
  - **工具完整度**：没有折现与机会成本、没有期限下限、没有行业门控、没有币种换算、没有尾部情景，导出功能与证据链也存在缺口。这些是“没做完”，不是“做错了”，但其中两项会直接改变用户读到的结论（见问题 1、2）。
- 测试：`npx vitest run src/features/comprehensive-valuation/model.test.ts` 本次独立运行，5/5 通过。测试覆盖了算术口径，但没有覆盖上述呈现层与期限边界问题。

## 3. 按严重程度排序的问题

### 问题 1（高）：2:1 价差比无折现、无机会成本，且对悲观价单点极度敏感

- 位置：`ComprehensiveValuation.tsx:72-73`（结果展示“2 : 1 对应研究价”）、`:76`（“达到 / 未达到”文案）、`:104`（导出行“2:1 对应研究价”）；`model.ts:48-50`。
- 失败情形（只改悲观价，其余不变，现价 100、基准 125）：

  | 悲观价 | 价差比 | 文案 | 2:1 研究价 |
  | --- | --- | --- | --- |
  | 85 | 1.67 | 未达到 | 98.33 |
  | 90 | 2.50 | **达到** | 101.67 |
  | 95 | 5.00 | 达到 | 105.00 |
  | 99 | 25.00 | 达到 | 107.67 |

  悲观价从 85 改到 90，结论从“未达到”翻为“达到”。而 90 与 85 都只是用户的一句主观假设，模型并未给出依据。
- 机会成本缺口：若把 2 年期 8% 的资金成本折入（终值需达到 100×1.08² = 116.64），同一组数据下价差比降为 (125−116.64)/(116.64−85) = **0.26**，研究价降为 **84.30**。即在有机会成本的口径下，现价 100 远不满足 2:1。
- 为什么是高严重度：文档与页面都说“未折现”“不是今日内在价值”（`ComprehensiveValuation.tsx:79`、导出 `:110`），但“2 : 1 对应研究价”这一标签和“达到约 2:1 的初筛偏好”文案，会让用户把它读成买入门槛。导出的 Markdown 研究卡也会把这个数字原样保存。
- 建议：**修改**。
  1. 增加“要求的年化回报/资金成本”输入，把终值折到今天再算比值，或至少把结果改名为“未折现价差比”。
  2. 把“研究价”改为“使价差比为 2 的未来情景价格”，不再使用“研究价”一词。
  3. 在导出行 `:104` 同步附上未折现的限定语。
  4. 在 `model.test.ts` 增加“同一数据、加入折现后比值改变”的用例，并增加“悲观价 85 与 90 的结论翻转”的回归说明。

### 问题 2（高）：年化对期限没有下限，数值会变成没有意义的巨大百分比

- 位置：`model.ts:29`（仅要求 `years > 0`）、`model.ts:43`（年化公式）；测试 `model.test.ts:54` 只拦截了溢出（期限 1e-9 时 Infinity），没有拦截“合法但极短”的期限。
- 失败情形（基准价 125、现价 100，即 +25%）：
  - 期限 1 年：年化 +25.00%
  - 期限 0.1 年：年化 **+831.3%**
  - 期限 0.01 年：年化 **+4.9×10¹¹ %**
  这些数字在数学上没错，但对研究毫无意义，且页面以 `toFixed(2)` 原样显示（`ComprehensiveValuation.tsx:64`），导出也会保存。
- 建议：**修改**。给期限设业务下限（例如 ≥ 0.25 年，或由 UI 说明“短于 1 个月不做年化”），超出则显示“不适用”而非数值；在测试中加入 `years: '0.01'` 的断言。

### 问题 3（中）：三点离散期望没有尾部，且“期望终值年化”展示位置容易被误读

- 位置：`ComprehensiveValuation.tsx:74`（“概率加权持有期收益”）、`:78`（“期望终值的年化等价”）；`model.ts:56-62`。
- 问题：概率只覆盖三个点，三情景之外的损失（融资断裂、股权归零等）未被建模。页面在 `:82` 有警示，但期望数字本身仍是最醒目的结果。概率默认留空，填写后即显示一个精确到 0.01% 的期望，容易给人伪精确感。
- 算术：示例数据的期望持有期收益为 28.75%，年化等价 13.47%，各情景年化后加权为 12.49%。三者口径不同，页面只展示了前两个之一。
- 建议：**保留**计算，但（a）在期望数字旁明示“仅覆盖三点，不含三情景之外的尾部”；（b）删除或折叠“期望终值的年化等价”，避免与“期望 CAGR”混淆。

### 问题 4（中）：行业适配只有文字说明，计算器对所有公司一视同仁

- 位置：`ComprehensiveValuation.tsx:137`（METHODS 表写明“银行保险改用行业资本回报框架”）与 `:140`（计算器无条件渲染）；`investment-valuation-framework.md:24` 同样声明金融公司按行业框架。
- 问题：计算器接受任何公司的“未来每股价格”，不区分金融股、周期股、亏损成长股或 REIT。对周期股，峰值盈利周期的基准价会把 2:1 结论人为放大；对亏损公司，悲观价接近 0 时价差比与研究价的含义完全不同（悲观价 0 时研究价 = 基准价/3）。
- 建议：**修改**。至少在界面上按行业类别提示“本计算不适用于 X 类”，或对金融类直接禁用价差比。文档中“行业适配”应改为“行业适配由用户判断，工具不强制”，避免给人已实现门控的印象。

## 6. 对 Codex 初步反例的回应（协调者转达）

逐条复核后的独立回应：

1. **直接输入三情景，缺少经营→利润→股权桥→每股价的证据链**：同意。这是工具边界，不是公式错误；但 `ComprehensiveValuation.tsx:135` 的小标题“什么价格：先还原财务，再交叉验证”与工具实际能力不符，框架文档 `investment-valuation-framework.md:28` 已写“未实施”，页面未同步。应改标题或加显著说明。
2. **2:1 不足以作为价格决策规则，需要独立的要求回报约束**：同意，并补充算术。P=100、Bear=85、Base=130 时价差比恰为 2.00；持有 2 年年化 1.3^(1/2)−1 = 14.02%，持有 10 年（终值相同）年化仅 1.3^(1/10)−1 = 2.66%。同一个 2:1，期限不同，年化相差 5 倍以上，说明比值与期限脱钩，支持问题 1、2 的修改建议。
3. **概率 90/9/1 时期望约 −10%，2:1 非胜率**：同意。复算 0.90×(−15%) + 0.09×25% + 0.01×80% = −10.45%。页面 `ComprehensiveValuation.tsx:76` 已写“不证明有正期望”，但结果区仍把价差比与期望并列展示，应在视觉上分开。
4. **分红累计终值年化在现金闲置收益为 0 时成立，不等于 XIRR**：同意，但不应定性为公式错误。`model.ts:35,43` 把分红视为期末一次性到账且不再投资，年化是终值口径的近似；若分红在期中到账，真实 IRR 会不同。建议在结果旁标注“按期末一次性到账、现金闲置收益为 0 计”，而不是改公式。
5. **区分研究草稿与经证据核验的结论**：同意。`ComprehensiveValuation.tsx:152` 的导出与 `:155` 的自查清单均由用户自填，文档 `comprehensive-valuation-page.md` 也写明“不代表独立审核”。导出物应标注“草稿，未经独立核验”，与问题 5 的证据链修复保持一致。

不同意之处：无实质分歧。第 3 节中高严重度的两项（价差比折现、期限下限）属于呈现层会误导决策的缺陷，并非工具边界；其余各项归为“工具完整度”或“文档表述”。

## 8. 交叉回应（第二轮，逐条承认或提出理由）

1. **价差比对金融股也适用，行业差异在目标价推导，禁用金融股不成立**：承认。第 3 节问题 4 的“对金融类直接禁用价差比”过重。价差比本身只是未来情景财富的几何量，适用于任何行业；行业差异体现在悲观价与基准价如何推导，这属于用户判断。修正建议：金融、周期、REIT 等类别只做提示，不做禁用。
2. **2:1 门槛代数解出的是今日输入 P，应改名为“使未折现价差比=2 的现价”**：承认，且我原文有误。第 3 节问题 1 建议 2 把它改为“使价差比为 2 的未来情景价格”，这是错的。P=(Base+2·Bear)/3 确实是今日价格，应命名为“使未折现价差比为 2 的现价”，与未来情景价区分开。
3. **保留未折现价差比，另加要求年化回报约束，比悄悄改公式清楚**：承认。我在第 3 节问题 1 建议“折入资金成本后再算比值”，这会让同一个数字含义变化，不如并列展示清楚。修正为：保留未折现比值，另设“要求年化回报”输入，并显示满足该要求的条件现价 P ≤ Base_T/(1+h)^T（如 h=8%、T=10、Base=130 时为 60.22）。0.26 的折现例子仅作说明，不作为替换公式。
4. **短期年化可警示，不必拍定 0.25 年下限**：承认。期限选择属于用户判断，硬下限会挡住合理的短期研究。修正为：期限低于某阈值或年化绝对值超过某阈值时，在结果旁显示警示，并保留数值。第 3 节问题 2 中“必须设下限”的写法应改为“必须设警示”。
5. **历史 45 项未重跑不否定旧记录，产物缺失可标未归档**：承认。第 3 节问题 5 把 45 项写成“不可核查”是过度。正确表述是：本次未复现，旧记录不被否定；缺失产物标“未归档”即可。仍建议文档给出可复现的命令与日期。

**其他报告的一项有价值判断（Kimi 报告 `2026-10-22-comprehensive-valuation-kimi.md` 第 1 节）**：盈亏平衡悲观概率 ≈ R/(1+R)。我独立复算：令期望为零，p·(Bear−P)+(1−p)·(Base−P)=0，得 p=R/(1+R)。R=2 时 p=66.7%。Kimi 的反例（悲观 90、基准 120、乐观 180、概率 85/10/5）复算正确：门槛价 100，期望 −2.5%。这个指标我未提出，值得并入结果区，它把“达到 2:1”与概率假设直接连起来。

**分歧**：Kimi 第 2 节主张门槛价乘折现因子；Codex 主张保留未折现比值并另设约束。我同意 Codex。原因是折现后的“门槛价”与要求回报约束在数学上等价，若直接改公式，用户会看不见原来的比值；并列展示两者更透明。Kimi 第 4 节对分红时点的反例（“价格 60+第 1 年分红 25”与“价格 85+分红 0”在工具中等价）是有效的，支持在文档中声明分红时点口径。
