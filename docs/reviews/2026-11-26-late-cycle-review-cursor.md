## 0. 总判

**「宏观非防守 + 偏热 + 裂缝≥3 → 降一档」这条预警/降仓线应停下。**  
核心证据不在夏普门槛，而在描述统计：高点前 6 个月平均裂缝 0.83（全期 1.45），高点后 2.33——信号与下跌同步或滞后。L-016 价格刹车、L-009 偏热降档、L-022 利差/VIX 趋势已铺垫同一结论。方法上有可挑之处，但**没有一处会把「不通过」翻成「通过」**；继续改裂缝组合属于登记簿禁止的参数变体。

现行落地（v2.2 + 投入资金股票上限 80%）与该结论一致：扩张后段急跌靠风险预算承受，不靠择时。

## 2. 换角度设计（3–6 个；不重复已否写法）

已否、此处不重提为「再试一版」：L-016 四价格刹车；L-023～025 裂缝阈值/删项；L-009 M2/M3 偏热降档；L-019/020 波动率目标；L-021 股债金；「明确不做」里的继续加美股减仓规则。

### 方案 R1 — 仓内结构轮动（不降总权益权重）

- **机制：** G∧H（或仅 H）成立时，股票袖套从标普市值暴露改为防守九行业等权（或低波/质量子集），总权益权重仍跟 v2.2×上限；条件消失回基准。
- **数据：** Ken French 49 行业月收益已在 `trend-overlay-2026-11-25/inputs-industry.json`（1926–2026）；可交易代理需另定（11 行业 ETF 等）。仓库无长历史「质量/低波」官方套件，若用 FF RMW 等需新取数。
- **与已否区别：** 不改仓位档位/降一档；L-012 是**动量最强**卫星，这里是**防守/低波**卫星，假设相反。
- **为何可能有效：** 牛市后段进攻股回撤更深时，同权益下波动与回撤可降；C4 单项无方向，但「强制持有防守」≠「等防守跑赢才信号」。
- **最可能失败：** 1995–1999、2020–2021 偏热时长抱防守大幅少赚；无 ETF 的 49 行业不可执行（L-012 已踩过）；2000 后防守溢价不稳定。

### 方案 R2 — 两阶段：裂缝只做「高点后确认 / 推迟回升档」

- **机制：** 不做提前降仓。当期内已较近期高点回撤 ≥8%–10%（或已破十个月均线）**且**裂缝数 ≥2（参数预注册写死）时，**禁止**下月上调档位（或强制维持当前档至少 2–3 个信号月）。目标：少做 2018-12、2025-04 类「跌完立刻按进攻加回去」。
- **数据：** 与 L-023 同一套日线+裂缝；信号可得时点同现口径。
- **与已否区别：** 假设从「预测高点」改为「确认风险已释放、延迟再进攻」；L-016 是跌途中再降档，这里是**限制回补**。
- **为何可能有效：** W 月大量落在急跌后、反弹前（README）；若问题是回补过早，锁档对准的是另一类错误。
- **最可能失败：** V 形反弹（2020-03 后）锁档代价大；与 L-016「少亏少赚」同一权衡；美国数据已看过裂缝，样本外弱。

### 方案 R3 — 热度→股票上限的风险预算表（非择时声称）

- **机制：** 事先公布映射，例如偏冷上限 100%、居中 80%、偏热 60%–70%（数字预注册锁死），每月按热度取 cap，再乘 v2.2 档位权重。验收标准改为「同等长期收益下回撤/波动是否更浅」或「用户风险问卷一致」，**不以击败基线夏普为成功**。
- **数据：** `combined-strategy.json` 热度 1973–2026；无新序列。
- **与已否区别：** L-009 M2/M3 是在策略内「偏热时改规则搏更高夏普」；这里是**显式风险预算选择**，对标「无条件 80%」（`cap-table` 已有机械关系）。
- **为何可能有效：** 产品层把「我知道偏热危险」落成固定更低暴露，避免临时择时；与用户「增加防守」语义接近。
- **最可能失败：** 统计形状近似已否的偏热降仓；1990 年代后半段长期偏热会显著少赚；易沦为事后选 cap。**若做，应标成风险偏好工具，不要当「研究证实的 alpha」。**

### 方案 R4 — 偏热时的再平衡 / 止盈纪律

- **机制：** 组合层：H 成立时（1）再平衡阈值提高（如月→双周）或（2）单名/卫星超配超过带宽即强制回归，禁止「让赢面继续跑」加码。仓位档位不变。
- **数据：** 需账户持仓路径；研究可用「核心+卫星」模拟（L-012 卫星权重路径），美股日线有；**个人五资产实盘路径短，难做 1973 长回测**。
- **与已否区别：** 不预测顶、不降总仓，管的是行为与集中度。
- **为何可能有效：** 对准「牛市后期仓位和杠杆过高」的行为面，而非宏观裂缝。
- **最可能失败：** 标普单资产回测上几乎无效应；过频再平衡吃成本；与「明确不做」里继续加规则的精神冲突 unless 严格限定为账户操作清单而非信号研究。

### 方案 R5 — 融资/杠杆硬开关（有保证金账户时）

- **机制：** H 或 G∧H 时禁止融资买入、强制保证金率上限；现金账户无操作。不进入 v2.2 档位公式。
- **数据：** 融资余额同比已在拥挤度里；**账户级融资利率与强平路径仓库没有**。
- **与已否区别：** 约束杠杆而非指数仓位择时。
- **为何可能有效：** 用户原话含杠杆；危机中杠杆是毁灭路径，与「指数回撤参与度」不是同一问题。
- **最可能失败：** 无长历史可回测的账户杠杆序列；容易变成无法证伪的「常识建议」。适合写进说明书操作纪律，不适合再开 L-0xx 仓位检验。

### 方案 R6 — 期权领口 / 保护性看跌的成本账户（仅当能取到数据）

- **机制：** G∧H 时对股票名义买 5%–10% OTM put 或领口，持有 1–3 个月滚动；用期权总回报或「VIX 隐含成本 − 实现保护」记账。
- **数据：** 仓库有 VIX/VIX3M/VVIX（1990+/部分更短），**无**跨式/领口长历史成交与报价面板；合成 put 成本误差大。
- **与已否区别：** 买保险而非卖股票；L-016/023 都是减权益。
- **为何可能有效：** 理论上可保留上行、裁尾部；偏热时长买保险最贵（VIX 往往不低也不极端）。
- **最可能失败：** 保险费在多年偏热牛市耗尽；无干净执行数据则回测不可信。**当前不建议开确认检验**，除非先入库可复核的期权代理并单独预注册数据质量门。

### 方案 R0 — 接受「只能靠风险预算」

- **机制：** 不再为「牛市后期预警」开仓位研究；维持 v2.2 + 上限 80%；裂缝/利差仅作面板提示（README 对 C1 的描述性用法）。
- **依据：** L-016 + L-023～025 + 路线图「暂停新研究 / 明确不做继续减仓规则」+ 锁箱几乎耗尽。
- **这是本评审的默认推荐（见 §4）。**

## 4. 推荐

### 4.1 主推荐：停下本线

理由（压缩）：

1. 机制上裂缝是同步/滞后变量，不是领先预警。  
2. 同族写法（价格刹车、偏热降档、利差/VIX、裂缝组合）连续失败。  
3. 美国样本多重比较耗尽；90 天内禁止裂缝参数变体。  
4. 用户要的「增加防守」已有可执行答案：**风险预算上限**，不是新信号。

保留：面板上「偏热 + 利差走阔 → 提示勿加仓、按计划再平衡」——**非仓位规则**。

### 4.2 若协调方仍要 ≤2 个确认候选（可直接预注册的规格）

下面两个**不是**裂缝预警翻案；事前预期均偏不通过。若预期是「停」，可不注册。

---

#### 候选 P1 — 回撤后锁档（两阶段确认，R2）

**信号与参数（写死）：**

- 令 `DD_t` = 信号月末标普收盘相对过去 12 个月最高月末收盘的跌幅。  
- 令 `n_t` = L-023 定义的裂缝数 C1–C5（口径、滞后、阈值**一字不改**）。  
- 触发：`DD_t ≥ 0.10` 且 `n_t ≥ 2`。  
- 动作：触发后的下一期起，v2.2 档位**不得上调**（可下调），持续 **3** 个信号月，或直到 `DD` 收复至 <5%（两结束条件取先到者）。非触发月完全基线。

**数据与可得时点：** 同 L-023/L-016；行业裂缝仍用 t−2。信号月 1973-01～2026-08。

**对照组：**（B0）纯 v2.2；（B1）仅 `DD≥10%` 锁档 3 个月、不用裂缝（回答裂缝有无增量）。

**判定：**  
1. 训练期（～1999-12）：夏普 ≥ 基线 −0.01；按日最大回撤不深于基线 1pp；且（夏普 ≥ 基线 +0.02 **或** 日回撤浅 ≥2pp）。  
2. 验证期（2000+）：夏普 ≥ 基线 −0.01；日回撤不深于基线 1pp。  
3. 全样本扣费年化下降 ≤0.5pp。  
4. 事件：全部 ≥10% 回调的**反弹**参与度中位下降 ≤ 下跌参与度中位下降（防止只靠躲反弹「赢」）；另报「触发月落在高点后 0–3 个月」的比例（描述，不作通过门）。

**事前预期：** **不通过。** 2020 类 V 形会罚锁档；裂缝在跌后堆积，锁档时段与反弹重叠，长期夏普大概率持平或略降。若事件上反弹参与度掉得多、下跌参与度几乎不掉 → 记为「延迟回补有代价」，维持基线。

**与禁令关系：** 不改裂缝阈值/窗口/篮子，动的是**执行语义**（锁上调 vs 降一档），视为新方法而非 L-023 参数变体；但仍占用美国样本一次确认名额。

#### 候选 P2 — 偏热时防守行业袖套（R1，结构）

**信号与参数（写死）：**

- 条件：信号月 `heat === hot`（页面定义，不另设阈）。  
- 动作：下一期股票袖套 = 防守九行业（Food、Soda、Beer、Smoke、Hshld、Hlth、MedEq、Drugs、Util）等权；总权益权重 = v2.2 档位权重 × 用户上限（回测默认 1.0 或与现行 0.8 各报一套，预注册锁死其一）。  
- 非偏热：袖套 = 标普（现引擎）。  
- 成本：换手 0.1%/单位（同 E1）；行业月收益用 Ken French，执行仍 E1 日频引擎（月内行业收益按日均匀摊——预注册必须写明近似）。
