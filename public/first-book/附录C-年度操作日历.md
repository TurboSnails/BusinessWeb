# 附录C 中线投资者的年度操作日历

> 用法：把一年里“固定要做的事”，放进日历，让复盘有节奏，不被行情牵着走。
> **注意**：披露时间、分红与解禁安排，每年可能因监管规则与公司公告而变化，**下表仅为常见的时间框架，使用前须按最新规则与公司公告核对**。
> **与决策记录的分工**：这是时间提醒工具，不是交易档案。每个节点该做的检查，落到统一决策记录（37.4）上完成。

---

## 一、A股定期报告披露的常见时间框架

| 报告 | 常见披露截止时间 | 你要做的 |
|---|---|---|
| 年报 | 次年4月30日前 | 更新公司观察库：增长、现金/利润比、ROE、资本配置；复核统一决策记录（37.4） |
| 一季报 | 4月30日前 | 看增长是否延续，关键指标有无背离 |
| 半年报 | 8月31日前 | 中期复盘：逻辑是否仍然成立，估值区间是否变化 |
| 三季报 | 10月31日前 | 为年度复盘做准备 |

（依据：《上市公司信息披露管理办法》第十三条——年度报告在会计年度结束之日起4个月内、中期报告在上半年结束之日起2个月内编制完成并披露；季度报告在会计年度前3个月、9个月结束之日起1个月内披露（证监会官网公布的现行版本，2026-10-03 访问）。不少公司会提前披露，具体日期看公司公告；规则如有修订，以证监会与交易所现行文件为准。）

## 二、一年的节奏示例（条件示例，不是处方）

| 时间 | 事项 |
|---|---|
| 1月 | 年度复盘：净收益、费用、回撤、方法是否有效（第37章）；修订愿望账本（第38章） |
| 2月到3月 | 检查配置的目标权重和偏离阈值；决定是否再平衡 |
| 4月 | 年报与一季报集中披露：更新公司观察库与逻辑卡 |
| 5月到6月 | 关注年报后的分红方案、除权除息日；检查红利类持仓的现金流 |
| 7月 | 半年度检查：配置是否偏离；备用金是否足够 |
| 8月 | 半年报集中披露：中期复盘 |
| 9月 | 检查下一年度的资金需求（大额支出、应急） |
| 10月 | 三季报披露：为年度复盘收集资料 |
| 11月到12月 | 税费与账户整理；检查观察池，移出长期无研究价值的标的 |

## 三、几个需要提前关注的事项

- **分红**：多数公司的年度分红，在年报披露、股东大会通过之后实施；具体的方案、股权登记日、除权除息日，看公司公告。
- **限售股解禁**：解禁可能增加市场供给，影响股价，具体安排以公司公告和交易所披露为准。
- **指数调整**：宽基指数与行业指数的成分调整，可能影响相关ETF，按指数公司公告核对。
- **跨境ETF/场外基金**：节假日、境外休市期间的净值更新与申赎安排，会影响成交与溢价（第10章）。

## 四、每次复盘，用同一张表

- 本期有什么新信息？
- 我的统一决策记录（37.4）里，哪些条件被验证了？哪些被证伪了？
- 估值区间有变化吗？
- 配置有没有偏离阈值？
- 我要做的动作，是什么？不做的理由，是什么？

---

*披露时间、分红与解禁规则会变化，以交易所与公司公告为准；本表不构成投资建议。*
