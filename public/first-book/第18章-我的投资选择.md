# 第18章 我的投资选择：个人策略匹配表与中长线原则

> 本章一句话：前面讲了很多策略，这一章只做一件事——写下你自己的方案。先认识自己，再选择策略，而不是反过来。
> 本章为工具章；匹配示例是条件示例，不是性格测试结果，也不是个人投资处方。

---

## 18.1 先认识自己：价值观、性格、能力、现实约束

**价值观：投资究竟为了什么？**

- 目标的排序：长期积累、现金流、财务独立、生活自由。收益、时间、压力、家庭责任，该怎么取舍？
- 方法的边界：你愿意承担什么风险？有哪些行业、工具、行为，你不愿意参与？
- 一个自检：我需要的是投资帮助生活，还是愿意把交易作为职业？

**性格：你在真实盈亏中，会怎么行动？**

- 耐心与即时反馈：你能等经营兑现，还是需要频繁的反馈？需要刺激，不等于适合高频交易。
- 独立与从众：你能依据证据坚持判断，也能在证据改变时认错吗？
- 纪律与情绪：你能执行计划、接受连续的小亏损吗？能在持有期内承受大幅波动吗？

**不要靠性格标签来分配策略。** 更可靠的办法，是看你的交易记录、模拟决策和生活里的行为证据。性格倾向可以训练，也会随环境变化。

**能力：你究竟能验证什么？**

| 能力 | 具体内容 | 对应的策略 |
|---|---|---|
| 企业研究 | 财报、估值、治理、商业模式 | 价值、质量、成长 |
| 产业研究 | 技术、竞争、供需、行业数据 | 产业趋势、周期 |
| 交易研究 | 价格规则、市场制度、执行与风控 | 趋势、情绪策略 |
| 数理与系统 | 统计、编程、数据、基础设施 | 自主量化、套利 |
| 委托与产品选择 | 理解费用、底层风险、管理人、适用条件 | 基金、配置 |

**不要求人人都自己选股，或者搭建系统。** 委托和选择产品，也是一种合理的路径。

**现实约束：愿意做、做得到、承担得起，三者要同时满足。**

- 资金期限、应急需求、可投入的时间、工具条件、亏损承受力。
- 区分三件事：**喜欢**一种方法、**理解**一种方法、**具备实施优势**。不要把兴趣，或者过往的一次盈利，当成能力。

## 18.2 回看第1章的五个自检问题

读完了策略地图、环境、配置和中长线之后，回头看第1章留下的五个问题，哪些答案变了？

1. 我投资最想换来什么：财富积累、现金流，还是更多的生活自由？
2. 面对等待、连续亏损和市场波动，我有哪些真实的行为证据？
3. 我能独立理解并验证哪些企业、行业或交易规则？
4. 资金何时需要使用，每周能够投入多少时间，能承担什么损失？
5. 哪些方法超出了我的能力或生活条件，应该暂时排除？

## 18.3 个人策略匹配表（本章核心工具）

这是一张你自己填的表。**填写顺序很重要：先明确目标和约束，再用能力和行为证据筛选策略，不要从“收益幻想”反推选择。**

| 栏目 | 要回答的问题 | 我的答案 |
|---|---|---|
| 1. 目标与价值排序 | 投资为了什么？什么最重要？ | |
| 2. 性格与行为证据 | 我在真实盈亏里怎么行动？有什么记录？ | |
| 3. 已有能力与缺口 | 我能验证什么？缺什么？ | |
| 4. 现实约束 | 资金期限、时间、应急需求、可承受的损失 | |
| 5. 候选策略 | 从第一部分的地图里，哪几类可能适合？ | |
| 6. 环境检查 | 当前市场环境，是否支持这些候选？（第6章） | |
| 7. 验证计划 | 怎样用学习、模拟、小额实践来验证？ | |
| 8. 放弃条件 | 什么情况下，我会放弃或更换这个策略？ | |

填完之后，同时评估成本、回撤、时间和心理负担。

**第6栏怎么填**：读过第6章的，按那里的“环境—策略”矩阵逐项对照；**没读过第6章的（走省心路线）这一栏可以先留空**，只写一句定性判断：我现在是在追涨，还是在别人恐慌时买？如果答不上来，就说明候选策略超出了你当前能维护的范围，退回配置路线。

## 18.4 三个条件示例：同一张表，怎么填

下面是三个**条件示例**，用来展示“同一张表，不同的人，会填出不同的结果”。它们不是性格测试，也不是处方。

| 栏目 | 示例A：时间有限的上班族 | 示例B：有行业经验的工程师 | 示例C：有系统研究能力者 |
|---|---|---|---|
| 目标 | 稳健积累，生活优先 | 积累，同时愿意研究熟悉的行业 | 追求超额回报，愿意投入大量时间 |
| 行为证据 | 不愿盯盘，波动大会焦虑 | 能长期跟踪行业，曾在下跌时坚持 | 有量化基础，记录完整 |
| 能力 | 有限的研究时间 | 对本行业的产业链很熟 | 统计、编程、数据处理 |
| 约束 | 每周投入2小时以内，有房贷 | 每周5小时，有应急金 | 可投入时间多，能承受较大波动 |
| 候选策略 | 配置+再平衡，宽基指数定投 | 配置底仓，加熟悉行业的价值回归/成长 | 配置底仓，加规则化的系统策略 |
| 验证计划 | 记录配置与再平衡，半年复盘一次 | 小额度研究，写统一决策记录（35.4） | 先模拟和小额，样本外检验 |
| 放弃条件 | 若维护不了，就简化为更少的产品 | 若研究连续三次错误，回到配置 | 若成本覆盖后无超额，停止 |

读这张表要注意：

- 不同的人，填出的是**不同的“配置+主动”组合**，不是统一答案。
- **新手优先路径**：以多资产配置与动态再平衡管理主要资金，小仓位尝试中线企业研究。**不要求一开始就成为主动选股者。**
- 学习次序：先确定目标、备用金与配置规则，再学习研究、记录与少量实践。主动额度单独管理，不用底仓或应急金补亏损。

## 18.5 写下自己的投资方案

用一页纸，写清楚：

- **主要策略**：我的主体资金怎么管理？
- **持有节奏**：中线、长线，还是混合？
- **研究清单**：我会研究哪几个行业、哪几类公司？
- **复盘安排**：多久复盘一次，复盘什么？
- **退出依据**：什么情况下，我会卖出或放弃？
- **暂时不做什么**：这一点和“做什么”同样重要。

如果你选择了中长线，请写清楚依据和适用条件，**而不是为了迎合本书的结论。**

## 18.6 中长线原则：把选择落实成可执行的约束

1. **资金期限与风险匹配**，先保障生活和应急需求。
2. **不用借款和杠杆**，放大你无法承受的损失。
3. **在能力圈内研究**，合理分散，设定自己能承担的仓位与风险上限。
4. **写清买入理由、证伪条件和复盘节奏**，减少情绪驱动的交易。
5. **不依赖宏观预测做买卖**（第16章）。

## 18.7 验证与修订

方案写出来之后，不是一成不变的。通过学习、模拟和记录，检验它是否适合你，并按证据更新。**不要因为一次盈亏，就换流派。**

## 18.8 进入第四部分

明确了个人选择，下一步是建立研究能力：产业、公司、财报、估值、周期、趋势、未来产业，最后是积累判断。有了共同的研究框架，再进入选股实操。

> “重为轻根，静为躁君。” ——《道德经》第二十六章

厚重是轻率的根本，安静是躁动的主宰。先确定自己能长期承受的那部分，再谈进取的那部分；认清自己，是所有选择的起点。

## 18.9 时间预算：先试跑，再决定研究范围

下面是作者用于排期的教学建议，不是调查得出的平均耗时或完成质量保证。每周记录实际时间，财报季与重大事件单列；不能维护时先缩范围，不能跳过核查。

| 路径或阶段 | 初步时间安排 | 超预算时怎样缩减 |
|---|---|---|
| 配置首次准备 | 四周各安排1—2小时 | 暂不买入，先完成资金与产品检查 |
| 配置日常维护 | 每月30—60分钟，年度另安排2小时 | 减少产品与重复渠道，保留必要风险检查 |
| 主动首次研究 | 只选一家，连续四周每周2—4小时 | 不够就只观察，不以读完一份报告算通过 |
| 主动持仓维护 | 每周1—2小时，报告或事件另加时间 | 暂停新研究、减少持仓或缩主动额度 |
| 年度对账复盘 | 集中安排2—4小时，按账本复杂度调整 | 先补现金流，再比收益，不省略亏损持仓 |

新增研究前，先问有没有余量更新已有持仓。观察池10—20家和持仓3—5家都不是必须达到的数量；一家研究完整也比同时追踪二十个名称更有用。

**中段导航**：第19—22章未通过经营、现金与价格核查，不能因读得累就跳过研究直接买股。可以转回配置路线、只观察或进入第35章 35.4 填写一份决策记录。第27章提供分类，不替代这些证据；缺时间时主动额度保持为零。

## 18.10 这套方法不适合我的三条判据

前面都在讲“怎么开始”。这一节讲“什么时候该停”。

一本书如果只教人开始、不教人退出，是危险的。**主动投资不是每个人都该做的事，承认这一点不丢人。** 下面是三条判据，满足任何一条，就该考虑退出主动部分——注意是退出主动部分，不是退出投资。

### 判据一：连续两年无法按时间预算维护

18.9 的时间预算，你连续两年都做不到——不是某几个月忙，而是持续地做不到。

这说明的不是你不够努力，而是**这套方法需要的维护成本超过了你的生活能提供的**。这时硬撑的后果通常是：研究质量下降，但因为已经投入了精力，反而不愿意承认看不懂，最后在信息不足的情况下做决定。

### 判据二：回撤时反复破坏自己写下的规则

不是一次两次，而是**每一次**中等以上的回撤，你都没能按原规则行动：该再平衡时没动、该止损时扛着、该检查时改了规则。

如果连续三次出现这种情况，问题不在纪律不够强，而在于**这套规则的波动超出了你能承受的范围**。改波动比改性格容易——降低权益比例，或者退出主动部分。

### 判据三：三年后仍说不清自己的收益来自哪里

做完年度复盘（35.8），你仍然说不清收益是来自配置、来自选的行业、还是来自运气。

这说明研究方法没有形成可复现的链条。继续下去，你是在用钱买经验，但经验并没有积累成能力。

### 三条退出路径（由轻到重）

| 路径 | 怎么做 | 保留什么 |
|---|---|---|
| **降低频率** | 把季度检查改为半年，把每周维护改为每月 | 保留全部持仓与配置结构 |
| **缩小主动额度** | 主动额度降到 5% 或零，只留配置底仓 | 保留配置与再平衡，退出个股研究 |
| **全部转为配置** | 只留一只低费宽基＋一只债基，按检查日再平衡 | 保留投资本身，退出所有主动决策 |

三条都不是失败。**从“自己做”退到“买市场”，是从高风险路径退到低风险路径，是进步不是退步。**

### 退出之后

- 已经持有的主动仓位：不必因为决定退出就立刻清仓。按33章的卖出条件正常处理，避免在情绪下做决定。
- 已经投入的学习时间：不浪费。你会更容易识别那些“听起来很专业”的销售话术。
- 回到第38章 38.6 的里程碑表，继续用过程指标对账。

**最重要的提醒**：退出之后，不要因为看到别人赚钱又回来。如果三年后仍想尝试，把它当作一次全新的开始——重新做时间预算，从主动额度为零起步。
