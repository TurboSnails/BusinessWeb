# 第1章 全球投资地图：十二大体系，十二种赚钱逻辑

> 本章任务：让你知道，投资界有哪些主要体系、各自靠什么获得收益、代表人物是谁，以及什么样的人适合研究和执行。**只建立地图，具体操作留给后续章节。**
> 本章为概览章，只做地图式介绍。分类存在交叉，不宣称是“全部种类”；“适合人群”是本书的条件分析，不是收益保证；人物是方法入口，不用大师的业绩证明方法有效。A股超短策略树与情绪周期放在第5章。

---

## 1.1 读图说明：分类不是十二个互斥的盒子

先分清四个维度：**资产对象、收益逻辑、实施方法、持有周期。** 不要把“股票”“量化”“长线”放在同一层比较，它们不是同一类东西。

本章用十二个体系作为“学习目录”：价值、质量、成长、产业/主题、周期、宏观、趋势/动量、逆向/均值回归、事件驱动、中国式短线情绪、量化/套利/衍生品、资产配置。

它们有交叉：GARP连接价值与成长；量化可以实施质量、趋势、均值回归；困境反转可以兼具逆向与事件驱动的属性。此外，指数/被动、红利/收益、固定收益，是跨体系的标签。

**持仓周期是常见的观察尺度，不是硬性定义。**

## 1.2 ① 价值投资：买价格与价值之间的差

- **核心逻辑**：判断内在价值与安全边际，等待价值修复；低倍数只是筛选线索。
- **代表人物**：格雷厄姆（价值投资奠基者，强调安全边际）；巴菲特（由低价资产研究，拓展到优质企业）；卡拉曼（《安全边际》作者，重视下行风险）。
- **典型周期**：年。**执行难度**：中高，依赖财报、估值与治理判断。
- **适合**：能读财报、独立估值、耐心等待，愿意承认估值错误的人。
- **风险**：价值陷阱、资产缩水、修复迟迟不发生。

## 1.3 ② 质量投资：让优秀企业持续创造价值

- **核心逻辑**：企业持续创造高质量现金流，并有效再投资；买入估值影响最终回报。
- **代表人物**：巴菲特、芒格（伯克希尔长期实践中重视竞争优势与合理价格）；阿斯内斯及AQR团队（将质量特征纳入系统化研究）。
- **典型周期**：年到十年。**难度**：中高。
- **适合**：愿意长期研究生意模式、接受阶段性落后，能区分质量与高估值的人。
- **风险**：护城河衰退、治理恶化、买入价格过高。

## 1.4 ③ 成长投资：在增长兑现之前研究增长

- **核心逻辑**：收入、利润、现金流的增长兑现；增长不自动转化为股东收益。
- **代表人物**：林奇（富达麦哲伦基金前经理，结合业务观察、增长与估值）；以其合理价格成长的思路解释GARP。
- **典型周期**：季度到年。**难度**：中高。
- **适合**：熟悉产品或行业，愿意追踪增长质量、竞争和财报的人。
- **风险**：伪成长、股权稀释、增长降速与估值压缩。

## 1.5 ④ 产业/主题投资：抓住变化，找到真正获益的企业

- **核心逻辑**：产业规模与渗透率提高，带来盈利机会；要区分“产业发展”与“企业赚到钱”。
- **代表人物**：凯瑟琳·伍德（ARK创始人，以颠覆式创新的主题研究构建组合）。
- **典型周期**：月到年。**难度**：高。
- **适合**：具备产业知识，能验证商业化与盈利传导，承受主题集中波动的人。
- **风险**：概念炒作、技术路线失败、利润被竞争侵蚀、估值透支。

## 1.6 ⑤ 周期投资：在供需错位中判断位置

- **核心逻辑**：供给约束、需求变化与产能滞后，导致利润起伏。
- **代表人物**：林奇（将周期型公司纳入选股分类）；马克斯（橡树联合创始人，通过备忘录讨论周期与风险位置）。
- **典型周期**：年。**难度**：高。
- **适合**：有特定行业经验，能持续跟踪库存、产能与成本的人。
- **风险**：拐点误判、周期拉长、高点利润误导。

## 1.7 ⑥ 宏观投资：交易经济变化与预期差

- **核心逻辑**：宏观变量与已计入价格的预期出现差异；Carry还包含承担融资、信用等风险的补偿。
- **代表人物**：索罗斯（全球宏观代表，讨论反身性）；达利欧（桥水创始人，研究经济环境与资产关系）。
- **典型周期**：月到年。**难度**：高，依赖跨市场知识、工具与风险管理。
- **风险**：因果链失误、时点错误、政策突变、杠杆风险。
- **本书的态度**：理解宏观的风险环境，但不把预测宏观当作主要工具（第16章）。

## 1.8 ⑦ 趋势/动量：跟随已经发生的价格变化

- **核心逻辑**：价格趋势或相对强弱持续；区分时间序列趋势与横截面动量。
- **代表人物**：理查德·丹尼斯（海龟交易实验的重要发起者）；阿斯内斯及AQR团队（动量研究）。
- **典型周期**：周到年。**难度**：中高，纪律与仓位控制要求高。
- **风险**：震荡市反复止损，跳空与滑点。

## 1.9 ⑧ 逆向/均值回归：判断偏离是否能够修复

- **核心逻辑**：悲观预期、价格或价差偏离之后修复；基本面逆向与统计均值回归使用不同证据。
- **代表人物**：邓普顿（全球逆向价值投资代表）。
- **典型周期**：日到年。**难度**：高。
- **风险**：接落刀、历史关系断裂、回归前资金耗尽。

## 1.10 ⑨ 事件驱动：等待明确的催化剂

- **核心逻辑**：事件改变现金流、权利结构或市场定价；要分别分析发生概率、等待时间与失败结果。
- **代表人物**：加贝利（将企业价值研究与并购机会结合）；马克斯、卡什（橡树联合创始人，困境债与重组研究的实践代表）。
- **难度**：高，部分情景需要法律与债权结构知识。
- **风险**：审批延迟、事件失败、清偿顺序、股权稀释。

## 1.11 ⑩ 中国式短线情绪与题材博弈：交易资金注意力与接力

- **核心逻辑**：题材聚集注意力，资金形成价格反馈，再由接力买卖影响短期价格；盈利依赖进入与退出价格，不由“情绪标签”保证。
- **代表实践**：A股游资与职业超短交易者。**具体人物案例，须核查可归属的公开材料，不把论坛传言当作本人战法或收益记录**。
- **典型周期**：日到周。**难度**：高，盘中精力、规则执行和交易条件要求高。
- **风险**：退潮、无法成交、跳空、滑点、拥挤接力、情绪失控。
- 超短策略树与情绪周期，较为专业，放到第5章（交易派）。

## 1.12 ⑪ 量化、套利与衍生品：数据、结构与风险定价

- **核心逻辑**：因子风险补偿、统计偏差、相对价格偏离、流动性供给和波动率定价；并非全部都是Alpha。
- **代表人物**：西蒙斯（数学家，文艺复兴科技创始人）；阿斯内斯（AQR联合创始人，系统化因子与组合研究）。
- **难度**：高到极高。
- **适合**：具备统计、编程、交易机制和持续维护能力的研究者与团队。
- **概念边界**：量化是实施方法，套利是策略，衍生品是工具。**市场中性与期权卖方，都不等于低风险。**

## 1.13 ⑫ 资产配置：管理长期收益与风险来源

- **核心逻辑**：底层资产的风险溢价、长期经营增长与现金流；分散、再平衡管理风险，不保证额外收益。
- **代表人物**：达利欧（全天候配置思路代表）；博格（先锋创始人，低成本指数投资代表）。
- **典型周期**：年到几十年。**入门难度**：中。
- **适合**：希望围绕资金用途与长期目标建立组合，愿意分散和定期再平衡的人。
- **风险**：相关性变化、股债同跌、通胀、汇率、再平衡成本。

## 1.14 收益机制地图：我究竟靠什么获得回报

| 收益来源 | 对应体系 | 要追问的 |
|---|---|---|
| 企业经营与现金流 | 价值、质量、成长 | 增长是否兑现为现金？ |
| 产业扩张 | 产业/主题 | 新增价值归谁？ |
| 周期与宏观变化 | 周期、宏观 | 是盈利变化，还是预期变化？ |
| 趋势延续 | 趋势/动量 | 价格信号，不直接证明企业价值 |
| 错误定价修复 | 价值、逆向、均值回归 | 修复依据与失效条件？ |
| 事件重估 | 事件驱动 | 成功概率与失败后的价值？ |
| 交易者之间的博弈 | 龙头、情绪、接力 | 成交、流动性与退出条件？ |
| 风险承担与市场结构 | Carry、波动率、做市 | 风险补偿，还是结构性优势？ |
| 长期市场参与 | 指数与资产配置 | 回报来自底层资产 |

这是一张“来源地图”，**不把所有投资简化为“赚某个人的钱”**。

## 1.15 带着五个问题往下读：先认识策略，再认识自己

策略不仅要有收益逻辑，也要和你的目标、行为习惯、可验证的能力匹配。完整的“价值观—性格—能力—现实约束”框架，放在第18章。这里只留五个问题，带着它们往下读：

1. 我投资最想换来什么：财富积累、现金流，还是更多的生活自由？
2. 面对等待、连续亏损和市场波动，我有哪些真实的行为证据？
3. 我能独立理解并验证哪些企业、行业或交易规则？
4. 资金何时需要使用，每周能够投入多少时间，能承担什么损失？
5. 哪些方法超出我的能力或生活条件，应该暂时排除？

**过渡**：先记录答案，不急于确定策略；先在第6章补上“什么环境适合什么策略”，再进入第二部分建立动态平衡方案，第三部分比较短线、中线与长线，再到第18章填写个人策略匹配表。
