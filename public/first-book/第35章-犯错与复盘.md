# 第35章 犯错与复盘：最后的对手是你自己

> 本章一句话：前面二十四章讲的都是如何战胜市场，这一章讲的是唯一真正需要战胜的东西——你自己。

---

## 引子：技术三天能学会，心态三年未必

有一个残酷的对称性：投资的所有技术，都可以在几周内讲完——怎么分类公司、怎么读财报、怎么设卖出条件。一个高中生智力上完全够格。

但同一个市场里，掌握同样技术的人，收益天差地别。差在哪？不在知识，在**知识的执行者**。

巴菲特说过一句被引用到烂的话，但大多数人只引用半句：

> "别人贪婪时我恐惧，别人恐惧时我贪婪。"

少有人引用它的下半句逻辑——**贪婪和恐惧并不长在别人脸上，它们长在你自己心里。** 行情软件里没有"贪婪指数"给你看，你能看到的只有价格；让你出手或收手的，从来不是价格本身，而是价格在你心里激起的东西。

所以本章不谈方法，只谈修心。好消息是：在这个领域，东西方的顶级投资者们和两千五百年前的老子，结论惊人地一致。

---

## 22.1 第一敌：贪婪——巴菲特的"能力圈"与老子的"知足"

**贪婪的伪装最好。** 它从来不以"我想发财"的面目出现，而是以"这个机会很好""别人都在赚"的面目出现。

巴菲特的解药是"能力圈"：只投你真正理解的生意。**能力圈表面是知识边界，实质是欲望边界**——承认自己有很多钱赚不到，是克制贪婪的唯一办法。

老子把这件事说得更狠：

> **"祸莫大于不知足，咎莫大于欲得。"**

投资里最大的灾祸，不是选错股票，而是"不知足"：赚到了估值修复的钱，又想要成长的钱；赚到了成长的钱，又想要题材的钱。仓位越来越重，杠杆越来越高的那批人，无一不是从"再赚一点就收手"开始的。

**解药落地为一条纪律：写下你的"够了"——每个持仓买入时就写下目标估值，到了就分批卖，不因" momentum 还在"而修改。** 事先写下的"够了"，是贪婪来时唯一挡得住它的东西。

## 22.2 第二敌：恐惧——邓普顿的"最大悲观点"与老子的"众人熙熙"

恐惧最狡猾的地方：**它在底部最真实。** 顶部时人人兴奋，你的恐惧是假的；底部时新闻全是坏消息，你的恐惧有了"充分的理由"，于是它显得无比理性。

约翰·邓普顿（John Templeton）是逆向投资的开山宗师。他的名言：**"要在最大悲观点时买入。"** 操作方法简单粗暴：等市场恐慌到极点、所有人都在抛售时，列一张清单，把跌得最惨但基本面无恙的公司挨个买。

老子见过同样的人群，写得更形象：

> **"众人熙熙，如享太牢，如春登台。我独泊兮其未兆，如婴儿之未孩。"**

众人都兴高采烈，像参加盛宴、像春日登台；唯独我淡泊宁静，像还不会笑的婴儿。邓普顿的"最大悲观点"，翻译成道德经的语言就是：**在"众人熙熙"时离场，在"众人弃之"时"独泊"。**

**解药落地为一个检验：当你最想卖出时，问自己——"此刻的恐惧，是因为公司变差了，还是因为价格变低了？"** 前者是信号，后者是噪音。两者的区别，本书第18章的"检验三问"已经给过你。

## 22.3 第三敌：自负——芒格的"误判心理学"与老子的"自知者明"

这是心态三敌里最危险的一个，因为它在**赚钱之后**才登场。

查理·芒格用一生研究人类误判心理学，结论是：人在赚钱后会系统性地高估自己的能力——把运气归功于水平，把周期归功于眼光。自负的下一步是必然的动作变形：加仓、集中、加杠杆，然后在下一轮周期里把之前赚的全部还回去。

老子两千五百年前就标注了这个心理漏洞：

> **"知人者智，自知者明。胜人者有力，自胜者强。"**

了解别人是聪明，了解自己才是明白；战胜别人是有力气，**战胜自己才是真正的强大。** 芒格读了这句话大概会鼓掌——他一辈子倡导的"逆向思考"（invert, always invert），本质就是先战胜自己脑子里的错误，再谈战胜市场。

段永平——中国投资人里把这套心法用得最纯粹的人——有句大白话：**"平常心。"** 买入时当生意看，涨了不狂，跌了不慌，看不懂就不碰。他的"不为清单"（stop doing list）和道德经"为学日益，为道日损"是同一个东西：高手不是多会做什么，而是清楚地不做什么。

**解药落地为一个动作：每次大赚之后，强制做一次"运气复盘"——把盈利中"运气贡献"和"能力贡献"分列两栏，逼自己诚实。** 这个动作很反人性，所以它有效。

## 22.4 修心三工具：把心态从"修为"变成"流程"

心态光懂没用，得落到纸面上。三个工具，每天/每周/每季各一个：

### 工具一：投资日记（每天三分钟，写给自己）
只记三件事：今天**想**做什么操作、为什么、做完后心情如何。
它的威力在三个月后才显现——翻回去看，你会发现自己的"想"高度重复：涨了想追，跌了想割。看见模式，才能不被模式控制。

### 工具二：决策复盘表（每笔交易一张，事前填）
| 项目 | 内容 |
|---|---|
| 买入理由（一句话，禁含宏观） | |
| 属于四类中的哪一类 | |
| 预期持有时间 | |
| 卖出条件（写具体数字，非"看情况"） | |
| 如果下跌30%，我会______ | 事先填好！ |
| 情绪状态（红绿灯，见下） | |

最后一栏最关键：**"如果下跌30%"必须在买入前填**。恐惧来临时你是没法理性决策的，此刻的你只是在执行过去的你签下的合约。

### 工具三：情绪红绿灯（贴在电脑边）
- 🟢 **绿**：平静、无感 → 可以正常决策
- 🟡 **黄**：频繁刷盘、FOMO、睡不踏实 → 只允许减仓，不允许加仓
- 🔴 **红**：恐慌想全清 / 狂热想全仓 → 48小时内只允许读，不允许操作

**规则只有一条：红灯亮起时，你的手从键盘上拿开。** 老子的版本更短："致虚极，守静笃。"——虚到极点，静到实处，才动。

## 22.5 收束全书：投资是修身的道场

写到这里，这本书的方法论已经交完：放弃短线和宏观（第二部分），只做四种公司（第三部分），拿住、会卖、节食、守纪律（第四部分）。

但你要知道一件事：**以上全部，都有人懂，依然有人亏。** 原因在于方法可以在书上学，心态只能在事上磨。

道德经第三十三章，是全书的最后一句话，也是投资的第一句话：

> **"知人者智，自知者明。胜人者有力，自胜者强。知足者富，强行者有志。不失其所者久，死而不亡者寿。"**

看懂别人，是聪明；看懂自己，是明白。赢过别人，是有力；**赢过那个贪婪、恐惧、自负的自己，才是强大。** 知道何时足够，才是真正的富有。不离开自己的能力圈，才能走得长久。

市场还是那个市场，K线还是那些K线。变了的，是你。

慢即是快。

## 本章一页纸清单

**心态自检清单（每季度做一次）**

- ☐ 我上一次违反自己定下的纪律是什么时候？当时情绪是黄灯还是红灯？
- ☐ 我的盈利里，多少该归功于运气？（强制分列两栏）
- ☐ 我现在最想加仓/清仓的冲动，背后是公司事实，还是价格画面？
- ☐ 我的每个持仓，卖出条件是否早已写成具体数字？
- ☐ 我是否说过"再赚一点就收手"？——说了几次？
