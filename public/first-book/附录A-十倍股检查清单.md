# 附录A 十倍股检查清单（一页纸）

> 用法：对一家你认为有“快速增长”潜质的公司，逐条打钩。**没有哪一条是“保证”，它们只是帮你避开假成长，并把判断说清楚。** 对应第21章。可单独传播。
> 提示：本清单只帮助研究，不构成投资建议；十倍是小概率事件，多数“看起来像”的公司，最终并没有成为十倍股。
> **与决策记录的分工**：这是一张筛选用的方法卡（见 37.4 的“分工”说明）。打钩通过、决定买入之后，把要点转入统一决策记录（37.4）的“经营依据／估值／退出”栏，只留下一份档案。

## 一、先算账：十倍意味着什么

| 时间 | 十倍需要的年化增长 |
|---|---|
| 3年 | 约115% |
| 5年 | 约58.5% |
| 10年 | 约25.9% |

- [ ] 我理解：十倍，几乎总是需要“多年”，而不是“一两年”。
- [ ] 我不指望估值倍数，一直提升；可靠的，是盈利本身的增长。

## 二、市场与模式

- [ ] 这家公司所在的市场，足够大吗？它目前占了多少？
- [ ] 它的成功模式，可以复制吗（新地区、新门店、新产品）？
- [ ] 我能用一句话，讲清楚它怎么赚钱吗？

## 三、增长的质量

- [ ] 收入增长，来自量，还是来自价？
- [ ] 利润、经营现金流，与收入同步增长吗？（不是“增收不增利”）
- [ ] 增长，主要来自自身业务，而不是靠并购堆出来的吗？
- [ ] 增长，不是靠高负债、高费用、价格战换来的吗？

## 四、竞争与护城河

- [ ] 赛道不拥挤？同行的价格战，是否已经出现？
- [ ] 它的优势，有证据吗（毛利率、复购、份额）？
- [ ] 竞争对手，能否轻易复制它？

## 五、财务与治理

- [ ] 资产负债表健康吗？现金够撑过一个差年份吗？
- [ ] 资本配置记录良好吗？管理层承诺兑现吗？
- [ ] 有没有关联交易、资金占用、频繁融资等红旗？

## 六、估值

- [ ] PEG是多少？增长率的口径是什么（历史/预测，单年/多年）？
- [ ] 当前价格，隐含了怎样的增长预期？我能用证据支持吗？
- [ ] 如果增长放缓一半，价格会怎样？

## 七、卖出与证伪

- [ ] 增长逻辑，被什么事件证伪？我写下来了吗？
- [ ] 增长明显放缓、估值远超增长所能支撑时，我会减仓或退出吗？
- [ ] 单一仓位的上限，是多少？（第36章）
