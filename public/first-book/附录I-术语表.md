# 附录I 术语表：一句话白话，和“在哪能看到”

> 本附录一句话：遇到看不懂的词，先来这里查一句白话；查完仍不确定，回到正文对应章节看它怎么用。

本表只给**够用的解释**，不给完整定义。同一术语在不同数据商、不同财报里口径可能不同，看到数字时先确认口径，再看解释。

---

## 一、价格与估值

| 术语 | 一句话白话 | 在哪能看到／要注意 |
|---|---|---|
| 市盈率 PE | 价格 ÷ 每股收益，粗看“按当前盈利多少年回本” | 行情软件；注意用静态、TTM 还是预测口径 |
| 市净率 PB | 价格 ÷ 每股净资产 | 银行、保险、重资产常用；净资产含不含商誉要看口径 |
| PEG | PE ÷ 盈利增速 | 增速必须与 PE 同一口径，否则无意义 |
| 股息率 | 每股分红 ÷ 价格 | 一次性特别分红会把它抬高，要看是否可持续 |
| 市销率 PS | 市值 ÷ 营业收入 | 未盈利公司常用；不代表它将来会盈利 |
| 市值 | 股价 × 总股本 | 与“流通市值”不同 |
| DCF（现金流折现） | 把未来能拿到的钱，按要求的回报率折成今天的价值 | 结果对折现率与终值假设极敏感（第28章） |
| 终值／永续增长 | DCF 里对“最后一段”的假设 | 常常占估值大头，必须单独做敏感性 |
| 反向 DCF | 不问“值多少”，而问“现在的价格意味着市场假设了多高的增长” | 同上 |
| WACC（加权平均资本成本） | 公司用债务和股权两种钱的平均成本，常作折现率的起点 | 年报不会直接给，是估算值 |
| 单位经济模型 | 单个门店／单个客户／单笔订单赚不赚钱，再乘以数量 | 招股书、业绩说明；关键是“单店”能否复制到全国 |
| 内含价值（EV） | 保险公司常用的“调整后净资产＋有效业务价值” | 保险公司年报；口径各公司不同 |
| 年化 | 把一段时期的收益换算成一年的口径 | 必须写明起止日期；不到一年的年化不可靠 |

## 二、财报与经营

| 术语 | 一句话白话 | 在哪能看到／要注意 |
|---|---|---|
| 归母净利润 | 属于上市公司股东的利润 | 年报利润表 |
| 扣非净利润 | 扣掉卖资产、补贴等一次性损益后的利润 | 年报“非经常性损益”表；看主业用它 |
| 加权 ROE | 按净资产占用时间加权算出的净资产收益率 | 年报主要指标；**与“摊薄 ROE”不是同一个数** |
| 摊薄 ROE | 用期末净资产算的 ROE | 两章引用不同口径会造成矛盾（第27、28章） |
| 权益乘数 | 总资产 ÷ 净资产，衡量用了多少杠杆 | 杜邦拆解的一环 |
| 少数股东权益 | 子公司里不属于上市公司股东的那部分 | 合并报表“所有者权益”项下 |
| 递延所得税 | 会计与税务确认时间不同造成的暂时性差异 | 资产负债表；突然变大会影响利润质量 |
| 受限资金 | 保证金、监管账户等不能随便动用的现金 | 年报“货币资金”附注；**它让“现金很多”打折** |
| 关键审计事项 | 审计师认为最需要提醒你的项目 | 审计报告；先看它，再看报表 |
| 经营现金流 | 主营业务真正收进来的钱 | 现金流量表；与净利润的差异要能解释（第27章） |
| 商誉 | 并购时多付的那部分钱 | 减值会突然吃掉利润 |
| 在建工程 | 还没转为固定资产的投入 | 长期不转固，可能是问题信号 |
| 同比／环比／累计 | 与去年同期比／与上期比／年初至今 | 三个数不一样，引用时必须标明（第13章） |

## 三、债券、利率与汇率

| 术语 | 一句话白话 | 在哪能看到／要注意 |
|---|---|---|
| 久期 | 债券现金流回收的平均时间；用它粗估利率影响：久期 × 利率变动 ≈ 价格变动 | 基金季报或债券条目；是估算不是精确 |
| 到期收益率 YTM | 持有到到期能拿到的年化收益（假设不违约、再投资同利率） | 行情软件；与“票面利率”不同 |
| 信用利差 | 信用债比同期限国债多出的那部分收益，用来补偿违约风险 | 利差扩大通常意味着风险偏好下降 |
| 名义利率／实际利率 | 票面标明的利率／扣掉通胀后的真实购买力增长 | 长期资金要看实际利率 |
| 汇率敞口 | 持有外币资产时，汇率波动带来的那部分盈亏 | QDII 产品；涨跌可能来自汇率而非标的 |

## 四、基金与交易

| 术语 | 一句话白话 | 在哪能看到／要注意 |
|---|---|---|
| 价格指数／全收益指数 | 是否把分红再投资算进去 | **两者不能直接比较**，全书多处强调 |
| 跟踪误差 | 基金与指数收益差异的波动大小 | 基金定期报告；越小越贴合 |
| IOPV | 场内 ETF 的盘中参考净值，每若干秒刷新 | 行情软件；是参考，不是保证成交价 |
| 溢价／折价 | 场内成交价高于／低于参考净值 | 溢价买入后即使净值不跌也可能亏（10.6） |
| A 类／C 类份额 | A 类收一次性申购费；C 类免申购费但按年收销售服务费 | 持有时间长短决定哪类划算（10.4） |
| QDII | 境内募资、投资境外市场的基金，受外汇额度约束 | 会限购、暂停申购，且确认与到账更慢 |
| T+1／T+2 | 交易后第 1／第 2 个工作日确认或可用 | 赎回到账天数各产品不同 |
| 滑点／冲击成本 | 实际成交价与预期价的差／大额下单把价格推走的成本 | 频繁交易的隐性成本（第12、17章） |
| 最小交易单位 | 场内通常 1 手 = 100 份 | 小额分批时，最低佣金会让成本率飙升 |
| 分位（估值分位） | 当前估值在历史区间里所处的位置 | 要标明起止日期与口径，否则不可比 |

## 五、风险与统计

| 术语 | 一句话白话 | 在哪能看到／要注意 |
|---|---|---|
| 最大回撤 | 从最高点到之后最低点，最大的那段跌幅 | 比“波动率”更贴近你的真实体验 |
| 波动率 | 收益的离散程度，常用标准差 | 需标明频率（日／月） |
| 相关系数 | 两个资产同涨同跌的程度，−1 到 +1 | **必须标频率与起止日**（附录F 口径表） |
| 时间加权收益／资金加权收益（XIRR） | 前者看策略本身，后者看你实际投入时点的体验 | 有进出金时两者不同（37.7） |
| 再平衡 | 比例偏离目标后调回 | 第8章 |
| 定投 | 固定时间投入固定金额 | 第3、6章；它不保证更好，只是纪律 |
| 炸板 | 涨停被打开 | 第5章；不要把它当胜率指标 |
| 中位数 | 把一组数从大到小排，正中间那个 | **比“平均数”抗极端值**；看行业估值常用它 |
| 复权（前复权／后复权） | 把分红送转还原进历史价格，使价格可比 | 不复权的价格会因分红“跳空”，比较长期涨跌必须用复权 |
| 持有期 | 从买入到卖出实际持有的时间 | 基金赎回费、红利税都按它分档（10.9） |
| 申购／赎回（申赎） | 场外向基金公司买入／卖出份额 | 按当日或下一日净值成交，成交价下单时未知 |
| ROIC（投入资本回报率） | 公司投入的全部资本（含债）赚多少 | 比 ROE 更不易被高杠杆抬高 |
| 凸性 | 利率变动对债券价格影响的“弯曲程度” | 久期只给直线近似，大幅变动时误差靠它修正 |
| 归因 | 把一段收益拆成“来自哪个决定” | 用于复盘，不是评价收益高低（第37章） |
| SAE J3016（自动驾驶分级） | L0—L5 六级，L3 以下驾驶员仍负主要责任 | 第31章；宣传里的“自动驾驶”多数是 L2 |
| Gartner 炒作周期（Hype Cycle） | 新技术常见的“过热—幻灭—复苏”节奏 | 只作提醒，不用来判断时点 |
| 学习曲线（赖特定律） | 产量每翻一倍，成本按固定比例下降 | 是经验规律，不是物理定律，需自行验证 |

## 关于本书的练习：需要什么工具

- 全部练习只需要**纸笔和加减乘除**；不涉及编程，引用过的数据脚本只是作者的复核工具，读者不需要运行。
- 遇到“开方”（如三年累计换算年化），用第28章末尾的**试算法**：先试一个整数百分比，算两三次乘法，逼近即可。误差零点几个百分点，不影响任何判断。
- 遇到 XIRR（资金加权收益率），券商或基金 App 大多已按该口径展示，你只需核对口径，不必自己算（见第37章 37.8）。

## 三个最容易搞混的口径

1. **年化 vs 累计**：三年涨 30% 不是“年化 30%”，也不是“每年 10%”。正确算法是 **（1＋30%）开三次方，再减 1**，约 **9.1%**。公式：年化 =（1＋累计涨幅）^（1÷年数）−1。反过来说，年化 30% 连续三年，累计是 1.3³−1≈**120%**，不是 90%（见第28章练习）。
2. **价格指数 vs 全收益指数**：前者不含分红，后者含。拿基金收益去比价格指数，会凭空多出差异。
3. **加权 ROE vs 摊薄 ROE**：分母不同。同一家公司一年，两个数字可以差一两个百分点——引用时必须写清是哪一个。

**说明**：本表为“够用解释”，不是会计或金融的完整定义。涉及具体决策的口径，以公司年报、基金合同与数据商的原始说明为准。
