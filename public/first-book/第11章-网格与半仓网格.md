# 第11章 普通人的另类选择：网格，还是“半仓＋网格”

> 本章一句话：网格赚的是区间里的价差，不是方向；它在震荡市里有一点优势，在单边行情里要付代价。想清楚这一点，再决定要不要用。

## 11.1 为什么网格这么吸引人，又为什么容易用坏

网格的吸引力很具体：规则写得清楚，不需要预测方向，每次成交都有一笔小小的盈利，账户里总有“事情在发生”。

它的陷阱也在这里。频繁的小赚，很容易盖住一次大回撤；成交次数多，会让人误以为收益也多；亏了之后，最容易想到的办法是把格子加密、再多买一点来摊平成本。

先把立场说在前面：**网格是一件可选的小工具，不是本书推荐的主路径。** 主路径仍然是配置加再平衡（第8章）。

## 11.2 网格到底在赚什么

每一格的净利润，是这一格的价差，减去往返的成本（佣金、买卖价差、适用税费）。

所以网格赚的是波动，不是方向。价格在区间里来回，它有得赚；价格一路向一个方向走，它要么踏空，要么越买越套。

它和另外两种方法的区别：

- 和定投不同：定投按时间持续买入，网格有买有卖。
- 和动态再平衡不同：再平衡按目标权重的偏离来触发，网格按价格触发（第8章）。

还有一条前提：网格不会让差资产变成好资产。标的本身要经得起长期持有，或者至少长期处在一个相对稳定的中枢里（第3章）。

## 11.3 两种形态

**纯网格**：手里先是现金。价格每跌一格就买一份，每涨回一格就卖掉那一份。资金是随着下跌逐步投进去的。

**半仓＋网格**：先持有约一半的底仓，另一半是现金。价格每涨一格就减一点仓位，每跌一格就加一点仓位，让仓位在一个区间里浮动（例如25%到75%，仅为示例）。它本质上是在股票和现金之间做固定比例的再平衡。

| | 纯网格 | 半仓＋网格 |
|---|---|---|
| 起始状态 | 全部是现金 | 一半底仓、一半现金 |
| 单边上涨 | 几乎踏空 | 部分参与，但逐格减仓 |
| 单边下跌 | 越跌越买，最终仍被套 | 越跌越加仓，亏损会被放大 |
| 区间震荡 | 有价差收益 | 有价差收益 |
| 维护难度 | 中 | 较高（要管仓位区间） |

## 11.4 一次示意模拟：同样的资金，四种市场，五种做法

下面不是历史数据，是用计算机生成的价格路径做的示意，只用来说明机制。每种路径各生成300条随机走势，取结果的中位数。

**模拟设定**（均为假设）：
- 本金100，路径长度500个交易日，日波动约1.2%。
- 单边成本按0.1%计。
- 网格格距5%；纯网格共8格，每格投入八分之一本金；半仓＋网格的仓位每格变动6.25个百分点，在25%到75%之间浮动。
- 再平衡为每季度（63个交易日）调回50/50。
- 四种路径：单边上涨（终点中位数约1.49）、单边下跌（约0.62）、区间震荡（约1.00）、先跌后涨（约1.05）。

**结果（期末资产中位数 / 最大回撤中位数 / 成交次数中位数）**

| 路径 | 买入持有 | 半仓持有 | 季度50/50再平衡 | 纯网格 | 半仓＋网格 |
|---|---|---|---|---|---|
| 单边上涨 | 149.0 / 17% / 1 | 124.5 / 10% / 1 | 123.4 / 9% / 8 | 100.3 / 0% / 2 | 117.0 / 6% / 99 |
| 单边下跌 | 61.7 / 44% / 1 | 80.9 / 23% / 1 | 79.5 / 24% / 8 | 83.6 / 22% / 12 | 72.7 / 32% / 100 |
| 区间震荡 | 99.7 / 17% / 1 | 99.8 / 9% / 1 | 100.1 / 9% / 8 | 102.5 / 1% / 8 | 104.9 / 8% / 100 |
| 先跌后涨 | 104.5 / 35% / 1 | 102.3 / 18% / 1 | 103.5 / 19% / 8 | 104.5 / 13% / 14 | 105.3 / 25% / 100 |

**从这张表能读出什么**

1. **半仓＋网格，只有在区间震荡里才明显优于“半仓持有”**：104.9对99.8，差约5个点。
2. **在单边行情里，它反而不如“半仓持有”**。上涨时少赚（117.0对124.5）；下跌时因为越跌越加仓，亏得更多、回撤更深（72.7对80.9，回撤32%对23%）。
3. **纯网格在单边上涨里几乎踏空**（100.3对买入持有的149.0），在下跌里亏得比买入持有少，是因为它资金是逐步投入的，并非更聪明。
4. **季度再平衡几乎不输给网格**：在这些路径下，它的结果和半仓持有接近，成交次数却少得多。这也是第8章把再平衡放在主路径的原因。
5. **成交次数大不一样**：半仓＋网格约100次，再平衡约8次。次数多，意味着成本、盯盘和操作失误的机会都更多。

**成本和参数的敏感性**（半仓＋网格，区间震荡路径）：
- 单边成本从0.1%提高到0.3%，优势从约5个点降到约4个点（103.5对99.6），方向不变但变薄。
- 在这个设计里，格距从2%改到8%，结果变化很小，因为仓位变动幅度是跟着格距同比例缩放的。这是这套模拟设定的性质，不能推广成“格距不重要”。

**必须强调的边界**：
- 上面是合成路径，区间震荡路径被设定为向中枢回归，现实中的震荡不一定这样。
- 结果取决于波动大小、成本和仓位规则；换一套假设，数字会变。
- 因此合成模拟只回答“机制是什么”。下一节用真实指数数据检验。

### 11.4.2 用真实指数数据复算

**做法**：用沪深300、创业板指、中证红利三条真实的价格指数日线（2013年起，截至2026年9月30日），取所有长度为250个交易日的滚动窗口（每20个交易日取一个起点），按窗口终点的涨跌幅分成“上涨（超过+15%）”“下跌（低于-15%）”“震荡（正负5%以内）”“其他”四类，分别统计五种做法的**期末资产中位数 / 最大回撤中位数**（本金100）。

规则与合成模拟相同：格距5%，单边成本按0.05%计（这是对ETF场内交易的粗略假设；提高到0.1%后结果几乎不变）。

**沪深300（共155个窗口）**

| 区间类型 | 窗口数 | 买入持有 | 半仓持有 | 季度再平衡 | 纯网格 | 半仓＋网格 |
|---|---|---|---|---|---|---|
| 上涨 | 53 | 125.6 / 13% | 112.8 / 8% | 112.6 / 7% | 100.0 / 0% | 111.9 / 5% |
| 下跌 | 28 | 80.3 / 29% | 90.2 / 15% | 89.8 / 15% | 97.8 / 8% | 88.0 / 19% |
| 震荡 | 22 | 99.5 / 18% | 99.7 / 10% | 100.2 / 10% | 101.3 / 1% | 103.2 / 9% |
| 其他 | 52 | 100.3 / 16% | 100.1 / 9% | 100.4 / 9% | 100.6 / 2% | 102.5 / 9% |

**创业板指（155个窗口）与中证红利（155个窗口）**的完整表格见 `附件-数据/rolling.py` 的输出。把全部窗口合并后，“半仓＋网格”相对“半仓持有”的期末资产差：

| 标的 | 平均差 | 中位差 | 跑赢窗口占比 | 网格成交次数（中位） | 再平衡成交次数（中位） |
|---|---|---|---|---|---|
| 沪深300 | -0.9 | +0.4 | 53% | 45 | 4 |
| 创业板指 | -2.9 | -1.0 | 41% | 69 | 4 |
| 中证红利 | -0.2 | +1.3 | 74% | 41 | 4 |

**真实数据告诉我们的**

1. **和合成模拟的方向一致，但差距小得多。** “半仓＋网格”只在震荡窗口里明显领先“半仓持有”（沪深300：103.2对99.7）；上涨时略少赚，下跌时略多亏（88.0对90.2，回撤19%对15%）。
2. **整体看，没有稳定的超额收益。** 三个标的里，平均差为负或接近零；只有中证红利这类低波动标的，跑赢的窗口占多数（74%），但平均优势只有零点几个点。
3. **季度再平衡几乎等于“半仓持有”**（平均差约-0.1），成交次数只有网格的十分之一。
4. **纯网格的“抗跌”不是聪明，是没投满。** 下跌窗口里它亏得少（97.8），因为大部分资金还在现金里；上涨窗口里它几乎一直踏空（100.0）。
5. **标的越波动、趋势越强（创业板指），网格越吃亏。**

**这一节的边界**：价格指数不含分红；用指数代替ETF，没有计入跟踪误差、买卖价差和溢价；窗口之间相互重叠，真正独立的样本比155个少得多；格距、仓位区间都是一组假设。结论是“在这组设定下没有看到稳定的超额收益”，不是“网格一定没用”。

## 11.5 设计五要素

1. **标的**：流动性好、长期不容易归零的宽基或行业ETF。不用个股，不用强周期品种，不用高杠杆产品。跨境ETF先看溢价（第10章）。
2. **区间**：依据历史波动和估值来定，并且**先写下失效条件**——跌破下沿或突破上沿，就视为区间失效。
3. **格距**：至少要覆盖往返成本，并与标的的波动匹配。本书不给固定数字。
4. **单格份额与最大投入**：价格触及下沿时，总投入不能超过你能承受的额度。
5. **底仓比例**：“半仓”只是示例，按自己的风险承受力调整。

## 11.6 失效场景与应对

- **单边下跌**：事先写好最大投入和停止加格的条件，不无限摊平。规则用完，就转回配置，**不用底仓和备用金去补仓**。
- **单边上涨**：卖飞的部分由底仓承担，要接受“跑输持有”。
- **区间迁移**：重设区间必须有书面规则，不能为了回本随手移动格子。
- **交易约束**：最小交易单位、停牌与流动性、税费、溢价，逐项按现行规则核对。

## 11.7 网格的近亲与变体

- **价值平均**：按预设的市值增长路径调整每期投入，低于路径多买、高于路径少买。可以放进11.4的对比里验证。[待补]
- **趋势过滤与动态区间**：用长期均线或波动率调整区间，减少单边伤害；代价是规则更复杂、更容易过拟合。
- **倍投、金字塔加码、马丁格尔**：越跌买得越多，是把小概率的大亏损藏在平时小赚里的典型做法。**本书不推荐**，仅作警示。
- **做T、高频**：成本高、依赖盯盘，不适合作为普通人的日常方法。
- 可转债轮动、期权收益增强、打新等，门槛和风险结构不同，本章不展开。

## 11.8 回测与实盘的差距

回测只能排除明显的错误，不能证明未来有效。常见偏差有：滑点和未成交、最小交易单位、费用低估、挑选有利的数据区间、幸存者偏差、参数过拟合。

做法：做样本外检验；改变起止时间和参数看敏感性；先用小额度实盘，并记录下来。

## 11.9 成本与现金安排

- 成本检查表：佣金与最低收费、买卖价差、适用税费、跨境ETF溢价。格距设计时先扣掉这些。以现行规则为准。
- 现金部分：闲置现金放进低风险的现金管理工具，并计入整体收益；网格现金不能占用备用金，也不要因为“等格子”而长期闲置。

## 11.10 何时关闭网格

把退出也写进规则：

- 价格跌破下沿或突破上沿且区间已经失效；
- 标的的逻辑变了；
- 达到阶段目标；
- 维护精力或资金用途发生变化。

关闭之后：回到配置与再平衡，或按计划转为长期持有。不要因为一次盈亏就随意重开。

## 11.11 和全书主线的关系

- 资金归属：网格资金属于主动额度或卫星部分，不侵占底仓和备用金（第7到9章）。
- 市场环境：区间震荡相对适应，趋势市受压（第6章）。
- 放弃宏观：不预测方向，但要持续判断区间是否仍然成立（第16章）。

## 11.12 谁适合，谁不适合

- 适合：有时间维护、接受收益有限、能严格执行规则并做记录的人。
- 不适合：期待网格稳定翻倍的人、亏损时想加大格数的人、没有现金安全垫的人。

## 11.15 我的建议

1. **先用再平衡。** 无论合成路径还是真实指数，季度再平衡的结果都和“半仓持有”接近，成交次数却少得多；它是主路径（第8章）。
2. **网格不要指望超额收益。** 真实数据里，“半仓＋网格”相对“半仓持有”没有稳定优势；它真正能提供的，是一套有纪律的买卖规则，以及在低波动标的上略多一点的震荡收益。
3. **如果仍想用，优先半仓＋网格，标的选低波动的宽基或红利类，只用小额度。** 避开创业板这类高波动、强趋势的标的。
4. **是否扩大，由你自己的实盘记录决定**，不由一段顺手的行情决定。
