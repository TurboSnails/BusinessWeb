# 第六轮审稿：把它当成"一本给普通投资者的书"来看

审阅日期：2026-10-03。视角切换：不再问"这句话对不对、数字准不准"，而是问——**一个没受过金融训练、每周只有 1—2 小时、存款几万到几百万的中国普通投资者，拿到这本书，会读下去吗？会用起来吗？**

已读：第三—五轮修订记录、第三轮审稿、优化待办、全书大纲；通读开篇、第1—38章、三篇专题、附录 A—H。
本轮**不重复**数据口径、数字待核、真实案例缺失那条线（见待办 T4／T8／T9），只谈读者可用性。

---

## 一、总体判断：方法越来越扎实，但还不是"产品"

第三到第五轮做的事，是**加深**：判断链、算术推演、口径、反例、证据边界。这些都对，书稿的严谨度已经超过大多数同类书。

但五轮下来没有做过一次**减负**。于是出现三个结构性问题：

**1. 形式与主张相反。** 全书主张"少做、慢做、放弃短线与宏观"，可它的体量是 38 章 + 3 篇专题 + 8 个附录，读者要"读完"才能动手。**一本教人少做的书，自己要求读者做最多的事。** 这是最该先解决的矛盾。

**2. 读者不知道"先做哪一件事"。** 开篇给了四条阅读路线，已经是进步；但路线仍要求读 8—10 章才到"可行动"，且没有一句话回答"如果今年只做一件事，做什么"。

**3. 全书没有一次"真做给你看"。** 附录H 是压力演练，案例章是教学假设，公司数字是接口/年报切片，T4 的真实完整复盘仍未落地。读者学完一整本书，没见过作者完整地做过一遍。**一本教人做事的书，自己一次都没真做过，说服力会打折**——这一条与 T4 是同一件事的两面。

还有一个容易被忽略的：**全书没有"作者的话"**。没有作者简介、没有自序、没有"我犯过什么错"。读者会问"你凭什么写这本"，书里没有回答。

## 二、按优先级排列的不足

### P1｜没有"最小可行路径"（开篇）
- 现状："怎样读这本书"给的是三天的填表作业与四条路线；"主动额度可以为零"写成了退路，不是正面选项。
- 为什么是硬伤：普通读者的放弃点在第 3 天。他需要的是"我今天就能完成的一件事"。
- 补法：开篇新增《如果只能做一件事》（300—400 字）：留够应急金 → 长期钱买一只低费宽基 + 一只纯债 → 定一个季度检查日 → 其余全部暂缓。并把"主动额度为零"改写成**大多数读者的默认选项**。

### P1｜附录H 是"压力演练"，不是"买入演练"
- 现状：H.3 的新增投入结论是"留作研究"，全书没有一处演示一笔钱怎么真正投出去。
- 为什么是硬伤：读者最真实的卡点是"我知道该买指数了，然后呢？"——开户、选哪一只、买多少份、花多少费用、什么时候确认、什么时候再看，全都没写。
- 补法：附录H 新增一节《第一笔钱怎么投出去》（800—1200 字）：从"决定投入 1 万元"到下单、成交份额、费用、确认、下一次查看日，逐步演示，并列出会被卡住的地方（限购、溢价、到账、非交易时段）。

### P1｜完全没有账户层面的实务（第10章）
- 现状：全书只有第17章一句"佣金、买卖价差、税费、滑点"，第9章把"额度、到账"写成回测限制；第10章声明费率均为教学假设。
- 空缺：场内 ETF 一手多少份、佣金与最低收费、场外申赎确认与到账天数、QDII 限购与溢价、**股息红利税的持有期差别**、个人换汇额度、买卖单位与到账时间。
- 补法：第10章新增 10.9《账户与交易条件清单》（1500—2000 字，一张表）：开户渠道／场内场外／最小单位／费用／税费／到账／额度，每项标"以现行规则为准，买入前自查"。

### P1｜"不给承诺"之后留下了空白（全篇）
- 现状：全书正确地拒绝承诺收益与年限，但**没有给出替代物**：读者不知道"我在正轨上"是什么样子。
- 补法：开篇或第38章补《第 1 个月／第 1 年／第 3 年各检查什么》，用**过程指标**而非收益：是否按计划投入、是否写下了决策记录、回撤时有没有破坏规则、耗时是否超出预算、生活有没有被影响。这既守住不承诺，又给读者抓手。

### P2｜没有退出机制
- 现状：只有"主动额度可为零"，没有判据。
- 补法：第18章或第38章补《这套方法不适合我的三条判据》（200—300 字）+ 退出路径：全部转指数、降低频率、或承认自己不适合自主决策。给读者一条体面的退路，反而增加信任。

### P2｜缺"防被收割"清单
- 现状：全书只有第37章一句"关闭荐股消息"。荐股群、付费课、假冒 App、保本承诺、场外配资、代客理财——**这是中国普通投资者最现实的亏损来源**，书里几乎是空白。
- 补法：第7章或第37章加《五条红线》（一页，400 字）。成本极低，收益极高。

### P2｜术语表缺失，练习门槛过高
- 未解释即使用：权益乘数、加权 ROE、扣非利润、少数股东权益、**单位经济模型**、WACC、久期、内含价值、IOPV、溢价、分位、SAE J3016。
- 练习：第22章要求开三次方（(18.60÷12)^(1/3)−1），第17章要求跑脚本，第25.9 要求自己找三类历史材料却无样例。
- 补法：①新增附录I《术语表》（一页，白话 + 在哪里能看到）；②第22章练习补"不用计算器的逼近法"（1.15³=1.52、1.16³=1.56）；③每章练习前写明"最低工具：手机计算器 + 一个能查三年财报摘要的渠道"。

### P2｜没有"亏损已经发生"的完整处置流程
- 现状：分散在第33、35章与正念专题（"如果下跌30%，先检查"），没有一条从头到尾的流程。
- 补法：补一张《当日—48小时—7日》流程表：暂停新增交易 → 查用款与硬风险 → 核公司/产品事实 → 决定持有/缩减/退出 → 记录并约下次检查日。

### P3｜真实的人性场景缺席
- 连续两三年不赚钱怎么办、跑输朋友怎么办、牛市里别人翻倍怎么办、伴侣质疑怎么办——普通读者一定会遇到，书里几乎没写。
- 补法：第32章或第36章各写半页演练，并附上**给家人的一段说明稿**（可照抄）。

### P3｜可信度：缺"作者的话"
- 补法：开篇前加 300 字：我是谁、我做过什么、我犯过什么错（要具体）、为什么写这本、**我不提供什么**（不荐股、不代客、不承诺）。不吹，只建立边界。

## 三、结构建议：做"一册两用"

| 现状 | 建议 | 理由 |
|---|---|---|
| 第1—6章（策略地图，大纲自拟"选读"）排在最前 | 压成 1 章《地图》，或移到第11章之后 | 读者真正要的分钱、配置、选产品被挡在 1.5 万字之后 |
| 附录H（家庭全过程）在书末 | 前置为"引子案例"，或作为案例快读路线的第一站 | 它是最好的钩子，放最后浪费了 |
| 专题-资产基础 | 升为正式章，放在第7章前 | 这是核心内容，不该叫"专题" |
| 附录A 十倍股清单 | 并入第29章，缩为 6 问 | 独立存在意义弱 |
| 附录C 年度日历 | 并入第38章 | 读者在结尾最需要它 |
| 附录G 观察表 | 并入第25章，只填一个方向的样板 | 空表无示范作用 |
| 附录E 凯利公式 | 移线上或保留选读 | 与目标读者距离最远 |
| 附录B 道德经36张卡 | 压缩为 6—8 张边栏，每句只配一个动作 + 一个误读警告 | 36 张容易变成说教，且"静/等待"会被误读成"继续持有的理由" |
| 第26章（观察库） | 26.1—26.5 劝谕部分删去，26.6 模板并入第34章 | 与第18章、正念专题重复 |
| 第35章 35.4 七栏母版 | 保留，但**另给"只记 3 行"极简版** | 每周 1—2 小时的读者会弃填 |

## 四、这周就能做完的四件事

1. 开篇加《如果只能做一件事》+《作者的话》（约 700 字，最高杠杆）。
2. 第10章加《账户与交易条件清单》表（1500 字）。
3. 附录H 加《第一笔钱怎么投出去》（800—1200 字）。
4. 新增附录I《术语表》（一页）+ 第7章加《五条红线》。

做完这四件，这本书就从"严谨的稿子"变成"能交付给读者的产品"。

## 五、验收标准（读者视角）

找两位**不做投资的朋友**试读：开篇 → 附录H → 第7章 → 第10章 → 第38章。读完请他们回答三个问题：

1. 我今天要做的第一件事是什么？
2. 我这套组合一年可能跌多少？跌了之后我该做什么？
3. 我下一次看账户是什么时候？

三个人里有两人答不上来，就继续改。这个测试比任何内部审稿都准。
