# 第26章 看多了，就认得“美女公司”：用研究积累减少焦虑

> 核心比喻：好公司就跟美女一样，你看多了，就知道什么公司是“美女公司”。这里的“看多了”，指有标准地研究、比较和验证，不是多看行情、多刷消息，也不是凭第一眼喜欢就买入。

## 26.1 焦虑从哪里来

投资的焦虑，大多来自三个地方：

1. **看不懂**：不知道公司怎么赚钱，也不知道风险在哪。
2. **没有比较的标准**：不知道什么是好、什么是普通、什么是差。
3. **把短期价格，当成唯一的答案**：价格涨了就安心，跌了就慌。

研究，可以减少其中一部分不确定感，**但不能消除投资风险。** 它做到的，是让你在波动面前，有一个自己的判断标准。

## 26.2 从“看起来漂亮”，到“知道好在哪里”

“美女公司”不是靠第一印象，而是靠**解释**：

- 商业模式：它怎么赚钱，为什么别人赚不走？
- 现金流：赚的利润，是真的现金吗？
- 资本回报：每一块钱投入，能产生多少回报？
- 竞争优势：证据是什么？
- 治理：管理层可信吗？

能讲出“好在哪里”，才叫认识；只觉得“看起来不错”，只是印象。

## 26.3 见得多，比较才有参照

认识“好”，要靠**比较**：

- **同行比较**：同一行业里，谁更好？为什么？
- **跨公司比较**：不同行业里，好公司有什么共同点？
- **同一公司的历史比较**：它自己，现在比过去更好，还是更差？

要积累的不只是“赢家”的样本，还有**普通的、差的**样本。只看赢家，你会觉得成功很容易复制；见过差的，你才知道陷阱长什么样。

## 26.4 “美女公司”也会有缺点

好公司，也会有问题：

- 它可能**太贵**；
- 它可能会**变差**；
- 它也会遇到**周期**。

**认出经营质量，不等于认出便宜价格。** 好公司和好投资，是两件事（第20章、第22章）。

## 26.5 熟悉不是证据

最常见的认知偏差：

- **品牌偏爱**：因为熟悉的品牌，就觉得它是好公司。
- **故事吸引**：被一个好听的故事说服，忽略了数据。
- **确认偏误**：只找支持自己观点的信息。
- **过度自信**：觉得自己看懂了。

对策：**主动寻找反例和反对的证据。** 买入之前，问自己：如果我错了，最可能是错在哪里？

## 26.6 建立“公司观察库”

把你研究过的公司，放进一个统一的表格里，每家公司记录：

| 栏目 | 内容 |
|---|---|
| 产业 | 所在产业与阶段 |
| 模式 | 一句话讲清楚怎么赚钱 |
| 财报 | 增长、现金、债务、回报的要点 |
| 周期 | 它处在周期的什么位置 |
| 趋势 | 产业、经营、价格趋势 |
| 估值 | 估值区间与当前价格 |
| 疑问 | 我还没弄明白的事 |
| 下次验证事项 | 下一次财报要看什么 |

**不追求名单的数量。** 逐次更新判断，比名单长更重要。

## 26.7 用研究节奏，代替无尽的盯盘

设定：

- **固定复盘**：每月或每季度，一个固定时间。
- **财报更新**：财报出来后，更新观察库。
- **重大信息触发**：重大公告出现，核查一次。

你不需要对每天的价格变化，都作出解释。

## 26.8 一页纸：“我为什么认为它好”

- 三条可验证的依据：
- 两个关键风险：
- 价格条件（什么价格以下，我才认为值得）：
- 证伪条件（什么事发生，说明我错了）：

**说不清，就继续研究，不急于买入。**

## 26.9 收束

真正让人安定的，是**能解释、能验证、能认错**的判断能力。带着这份研究清单，进入第五部分的选股与买卖。

> “孰能安以动之徐生？” ——《道德经》第十五章

安稳之中慢慢生长。研究的积累，也是这样一点点生出来的。
