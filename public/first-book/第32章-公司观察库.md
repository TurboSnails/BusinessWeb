# 第32章 看得多了，就认得好公司：建自己的观察库

> 本章一句话：判断力来自有标准地研究、比较和验证，不是多看行情、多刷消息，也不是凭第一眼喜欢就买入。本章把前面零散的研究，收进一张可以长期更新的表。
> 本章为方法章。观察库的示例需标注“历史案例，非投资建议”；下面用的是模板，不是任何具体公司。

---

## 32.1 焦虑从哪里来

投资的焦虑，大多来自三个地方：

1. **看不懂**：不知道公司怎么赚钱，也不知道风险在哪。
2. **没有比较的标准**：不知道什么是好、什么是普通、什么是差。
3. **把短期价格，当成唯一的答案**：价格涨了就安心，跌了就慌。

研究，可以减少其中一部分不确定感，**但不能消除投资风险。** 它做到的，是让你在波动面前，有一个自己的判断标准。

## 32.2 从“看起来漂亮”，到“知道好在哪里”

有人把好公司比作“美女”：看得多了，就认得出。这个比喻只在一点上成立——**认识靠的是见过足够多的样本，并且比较过**；它不意味着“好看就买”，也不意味着第一眼的感觉可信。本书用“好公司”指有证据支撑的经营质量，不靠印象：

好公司不是靠第一印象，而是靠**解释**：

- 商业模式：它怎么赚钱，为什么别人赚不走？
- 现金流：赚的利润，是真的现金吗？
- 资本回报：每一块钱投入，能产生多少回报？
- 竞争优势：证据是什么？
- 治理：管理层可信吗？

能讲出“好在哪里”，才叫认识；只觉得“看起来不错”，只是印象。

## 32.3 见得多，比较才有参照

认识“好”，要靠**比较**：

- **同行比较**：同一行业里，谁更好？为什么？
- **跨公司比较**：不同行业里，好公司有什么共同点？
- **同一公司的历史比较**：它自己，现在比过去更好，还是更差？

要积累的不只是“赢家”的样本，还有**普通的、差的**样本。只看赢家，你会觉得成功很容易复制；见过差的，你才知道陷阱长什么样。

## 32.4 好公司也会有缺点

好公司，也会有问题：

- 它可能**太贵**；
- 它可能会**变差**；
- 它也会遇到**周期**。

**认出经营质量，不等于认出便宜价格。** 好公司和好投资，是两件事（第26章、第28章）。

## 32.5 熟悉不是证据

最常见的认知偏差：

- **品牌偏爱**：因为熟悉的品牌，就觉得它是好公司。
- **故事吸引**：被一个好听的故事说服，忽略了数据。
- **确认偏误**：只找支持自己观点的信息。
- **过度自信**：觉得自己看懂了。

对策：**主动寻找反例和反对的证据。** 买入之前，问自己：如果我错了，最可能是错在哪里？

## 32.6 建立“公司观察库”

把你研究过的公司，放进一个统一的表格里，每家公司记录：

| 栏目 | 内容 |
|---|---|
| 产业 | 所在产业与阶段 |
| 模式 | 一句话讲清楚怎么赚钱 |
| 财报 | 增长、现金、债务、回报的要点 |
| 周期 | 它处在周期的什么位置 |
| 趋势 | 产业、经营、价格趋势 |
| 估值 | 估值区间与当前价格 |
| 疑问 | 我还没弄明白的事 |
| 下次验证事项 | 下一次财报要看什么 |

**不追求名单的数量。** 逐次更新判断，比名单长更重要。

### 一个填好的示例：教学公司甲

下面用第25到28章一直在用的设备公司甲，把前面各章的结论收进一张表。全部数字都来自那几章的教学假设（非真实公司，金额为亿元），这里只演示“怎样收进来”。

| 栏目 | 甲的记录（截至年报公开后） |
|---|---|
| 产业 | 设备制造，处在客户扩产与更新的链条中；新增产能与更新需求要分开看（第25章） |
| 模式 | 收入10，其中新设备8、维修备件2；毛利率30%和50%，维修约贡献29%的毛利；订单依赖客户投资预算（第26章） |
| 财报 | 净利润1.05，经营现金流1.4，其中应付增加0.65；扣0.9的长期资产支出后余量0.5；若应付不再增加，余量为−0.15（第27章） |
| 周期 | 设备业务占主导，订单与利润处在周期的什么位置，尚未查清（第28章28.1、第29章） |
| 趋势 | 产业、经营、价格三种趋势都还没有逐项核查，价格趋势不作判断依据（第30章） |
| 估值 | 价格18元，静态PE约17.1倍；基准情景三年后条件价格18.60元，按10%回报要求倒推约13.97元（第28章） |
| 疑问 | 应付增加是正常规模扩大，还是拖欠供应商？维修能否留在甲手里？ |
| 下次验证事项 | 下一份财报看应付与应收的变化、维修收入占比、新设备订单 |

结论栏只写一句：继续观察，不买入。 现金改善是否可持续，需要供应商账期、应收与库存证据，价格也高于按要求回报倒推的条件价格。

下次财报出来后，不覆盖这一版，而是在旁边新增一栏“更新”，把“疑问”里已经查清的事划掉，并写明是什么证据改变了判断。

## 32.7 用研究节奏，代替无尽的盯盘

设定：

- **固定复盘**：每月或每季度，一个固定时间。
- **财报更新**：财报出来后，更新观察库。
- **重大信息触发**：重大公告出现，核查一次。

你不需要对每天的价格变化，都作出解释。

## 32.9 收束

真正让人安定的，是**能解释、能验证、能认错**的判断能力。带着这份研究清单，进入执行部分：组合、拿住与卖出。

> “孰能安以动之徐生？” ——《道德经》第十五章

安稳之中慢慢生长。研究的积累，也是这样一点点生出来的。
