## E.1 凯利要解决什么问题

在一个**可以重复**的、有正期望的机会里，每次下注占本金的多大比例，才能让**长期的几何增长**最快？

凯利的目标，是最大化“预期对数财富”，也就是长期复利增长，而不是下一笔的期望利润。

## E.2 二元下注：f★ = p − (1−p)/b

设：

- 胜率p，败率1−p；
- 获胜时，每1单位下注，赚b单位；失败时，损失全部下注；
- 每次下注占本金比例为f。

每次下注后，财富的对数增长率为：

> G(f) = p·ln(1+bf) + (1−p)·ln(1−f)

对f求导并令其为零：

> G′(f) = pb/(1+bf) − (1−p)/(1−f) = 0

解得：

> **f★ = (bp − (1−p)) / b = p − (1−p)/b**

当公式结果不为正（没有优势）时，不应下注（在不做空的约束下）。

## E.3 数值例子：p = 60%，b = 1

全凯利 f★ = 0.6 − 0.4/1 = 20%。下面是不同下注比例下，每次下注的对数增长率G(f)：

| 下注比例f | G(f) | 占最大增长的比例 |
|---|---|---|
| 5% | 0.00876 | 43% |
| 10%（半凯利） | 0.01504 | 75% |
| 15% | 0.01885 | 94% |
| 20%（全凯利） | 0.02014 | 100% |
| 30% | 0.01475 | 73% |
| 40%（2倍凯利） | −0.00245 | −12% |
| 50% | −0.03398 | −169% |

**读法**：

1. **半凯利（10%），保留了全凯利约75%的增长。**
2. **超过全凯利越多，增长下降越快，到2倍凯利（40%）时，长期增长已经变成负的。** 即：下注太多，比下注太少，代价大得多。
3. 这不是说“20%是股票该买的比例”。这只是这个二元模型的结果。

## E.4 连续时间近似：为什么半凯利约保留75%的增长、一半的波动

在连续时间、小收益的近似模型里，设资产的期望超额收益为μ，波动率为σ，持有比例为f，则长期的对数增长率约为：

> g(f) ≈ r + fμ − f²σ²/2

对f求导，最优比例：

> f★ = μ / σ²

此时超额增长为 μ²/(2σ²)。取半凯利 f = f★/2：

- 超额增长 = f★μ/2 − f★²σ²/8 = μ²/(2σ²) · (1 − 1/4) = **75%** × 最大超额增长；
- 波动率 = fσ = f★σ/2，是全凯利的**一半**；方差是**四分之一**。

**这个结论只在上述近似模型下成立。** 它不能推广成“所有股票策略，半凯利都保留75%增长”的固定结论。

## E.5 投资为什么不能机械套用下注公式

1. **模型不是二元的**：真实的股票收益有多种结果，可能跳空；停损可能无法按价成交。一般形式，是最大化E[ln(1+wR)]，其中R是持仓的随机收益。
2. **估计会错**：胜率、盈亏幅度、分布，都是估计。**高估优势，会导致过度下注。** 估计误差，通常比公式本身，更危险。
3. **多资产相关**：不能给每只股票独立地算一个凯利比例，再简单相加。多资产的情形，需要用协方差来求解。
4. **尾部与环境变化**：厚尾、相关性在危机中上升、流动性约束，都会让现实比模型糟糕。
5. **生活目标不同于对数效用**：回撤、用款需求、心理负担，会影响你能否长期执行。

## E.6 从公式到仓位纪律

1. 先确认**可验证的优势**，再谈下注比例。
2. 保守地估计；对估计出来的比例，**折减**（半凯利、四分之一凯利），并施加**组合层面的风险约束**（单一仓位上限、行业上限、相关性）。
3. 比较不同胜率、收益分布的假设下，结果的敏感性；**不要凭主观信心，填参数。**
4. 估计不可靠时，以资金的用途和可承受的损失，限制风险。

## E.7 一个提醒

半凯利，不是“半仓”，也不是“留一半现金”，更不能“因为打了五折，就保证安全”。**模型错了，打几折都不安全。**
