# 《慢即是快：彼得·林奇的道德经投资笔记》全书大纲

> 定位：一本写给普通散户的中线投资实操书。
> 主线：道德经为"道"（心法与节奏），彼得·林奇为"术"（选股与买卖），A股案例为"器"（落地证据）。
> 每章固定结构：一句经文 → 白话解读 → 林奇对应方法 → A股案例 → 一页纸清单。

---

## 第一部分 地图：投资的全部种类（看懂江湖再进门）

> 本部分回答一个问题：**投资的世界里到底有哪些玩法？** 不讲观点，只讲事实，让读者自己得出结论。

### 第1章 按"时间"分：短线、中线、长线
- 1.1 短线（几天~几周）：赚谁的钱？（情绪与流动性）
  - 打板、龙头战法、日内T+0可转债
  - 参与者画像：职业游资、量化、全职散户
- 1.2 中线（3个月~3年）：赚谁的钱？（业绩与估值修复）
  - 成长股持有、困境反转、周期波段
  - 参与者画像：基金经理、理性散户
- 1.3 长线（3年以上）：赚谁的钱？（国运与企业复利）
  - 价值投资、指数定投、股息再投资
  - 参与者画像：巴菲特式资金、家族办公室
- 1.4 一张对比表：资金门槛 / 时间投入 / 信息要求 / 胜率来源 / 手续费损耗

### 第2章 按"资产"分：你能买的所有东西
- 2.1 权益类：A股、港股、美股、行业基金、指数基金
- 2.2 固收类：国债、银行理财、债基、可转债
- 2.3 实物类：房产、黄金、大宗商品（原油/铜/猪）
- 2.4 另类：REITs、加密资产、外汇、衍生品（期货/期权）
- 2.5 风险收益全景图（配一张"梯子图"）：从余额宝到期权，逐级讲清风险在哪

### 第3章 按"策略"分：市场上活着的九种打法
- 3.1 价值投资（低买高卖的好公司）
- 3.2 成长投资（买未来，林奇的主场）
- 3.3 趋势/技术派（跟着钱走）
- 3.4 量化交易（用代码收割规律）
- 3.5 套利交易（赚确定性的薄钱）
- 3.6 事件驱动（重组、并购、政策）
- 3.7 宏观对冲（自上而下，机构游戏）
- 3.8 指数定投（承认平庸，获取平均）
- 3.9 网格/高抛低吸（震荡市专用）
- 3.10 每种策略一句话总结：赚什么钱、凭什么赢、谁最适合

### 第4章 按"玩家"分：你的对手盘都是谁
- 4.1 国家队与主权基金：不以盈利为目的
- 4.2 公募基金：有排名压力的聪明人
- 4.3 私募与游资：狼
- 4.4 量化基金：机器狼
- 4.5 外资：远处的猫头鹰
- 4.6 散户（你自己）：人数最多、武器最差、但有一个隐藏优势
- 4.7 核心结论：**知道自己是谁，比知道买什么更重要**（为第二部分埋伏笔）

### 第5章 残酷的算术：散户亏钱的原因排行榜
- 5.1 手续费与摩擦成本（高频交易的数学死刑）
- 5.2 信息不对称（你看到的都是第四手消息）
- 5.3 时间劣势（你无法盯盘，机器可以）
- 5.4 情绪劣势（恐惧与贪婪被实时收割）
- 5.5 资金劣势（跌50%要涨100%才回本）
- 5.6 用一张表回答：以上劣势，哪种玩法能最大程度绕开？→ 引出第二部分

## 第二部分 选择：为什么中线是普通人的最优解

> 本部分回答一个问题：**在第一章所有玩法里，为什么"中线 + 林奇式选股"是普通人的最优解？** 这是全书立论的核心，要写得像数学证明一样不可逆。

### 第6章 时间账本：你每周能给投资几个小时？
- 6.1 普通人的生活现实（上班、家庭、睡眠）
- 6.2 每种玩法需要的时间投入对比（短线=第二份全职工作）
- 6.3 道德经第一句："无为，故无败；无执，故无失"——不天天折腾，反而少错
- 6.4 案例：一个上班族把短线当副业的三个月结局（真实样本型故事）

### 第7章 胜率拆解：中线赚钱的三个来源
- 7.1 来源一：业绩增长（EPS增长，公司替你干活）
- 7.2 来源二：估值修复（PE从10回到20，市场情绪送你钱）
- 7.3 来源三：股息与复利（不起眼但最确定）
- 7.4 为什么说3个月~3年恰好是"业绩兑现"的周期（财报节奏：年报/中报/季报）
- 7.5 经文："大曰逝，逝曰远，远曰反"——周期是市场的呼吸

### 第8章 对手盘分析：你在这个战场上的相对优势
- 8.1 短线的战场：你和量化拼速度，必输
- 8.2 长线的战场：你和机构拼耐心与资金成本，难赢
- 8.3 中线的战场：**拼的是常识、生活观察、和"拿得住"**——这恰是散户三大隐藏优势
- 8.4 林奇的原话逻辑：散户比基金经理多的五个自由
  - 可以只买10只股票（基金不能这么集中）
  - 可以等（基金有排名和赎回压力）
  - 可以买小盘股（基金有规模限制）
  - 可以用生活常识（基金经理的圈子是卖方研报）
  - 可以空仓（基金有仓位下限）
- 8.5 经文："圣人后其身而身先，外其身而身存"——不与强者争锋，在自己的节奏里取胜

### 第9章 放弃宏观：从大奖章到林奇的共同选择
- 9.1 宏观的诱惑：为什么新闻越刷越想预测（每天的信息流全是宏观）
- 9.2 大奖章基金的启示：史上最强业绩不预测宏观，只收割微观统计
- 9.3 巴菲特："我们不试图预测"——宏观知识对选股没有帮助
- 9.4 彼得·林奇："一年花在经济学上的时间超过13分钟，就浪费了10分钟"
- 9.5 宏观的四重陷阱：不可证伪、传导断裂、反向反应、等待的复利成本
- 9.6 泰特洛克研究：专家的宏观预测 barely 比黑猩猩掷飞镖强
- 9.7 A股例外论：政策周期能用什么、不能用什么（政策底→市场底规律、信贷脉冲领先性，但指标正在失灵；宏观只做仓位钟，不做选股尺）
- 9.8 你该看的三个"可知"：财报、估值分位、自己的能力圈
- 经文收束："其出弥远，其知弥少"——看得越远越热闹，知道得越少

### 第10章 复利的数学：中线为什么是"慢即是快"
- 10.1 年化15%十年是4倍，二十年是16倍——算给读者看
- 10.2 为什么追求"翻倍"的人十年归零（亏50%要赚100%的数学）
- 10.3 巴菲特99%的财富是60岁后赚的——时间是唯一公平的杠杆
- 10.4 中线 vs 短线的十年模拟对账（同样本金、同样行情、两种风格）
- 10.5 经文："合抱之木，生于毫末；九层之台，起于累土"——慢不是缺点，是机制

### 第11章 中线宣言：给普通人的投资宪法（本部分总结）
- 11.1 五条宪法：
  1. 用闲钱（三年以上不用的钱）
  2. 不杠杆（借钱投资=把命运交给别人）
  3. 集中持有3~10只看得懂的公司
  4. 只在能力圈内下注
  5. 每年交易次数 ≤ 10次
- 11.2 宪法背后的道德经总纲："为学日益，为道日损。损之又损，以至于无为"
- 11.3 过渡页：接下来，教你怎么选那3~10只（进入第三部分）

## 第三部分 选股：只教四种——散户能赢的林奇战法

> 每章结构：经文引入 → 林奇方法论 → A股案例（2正1负） → 自检清单
> 本部分开篇即亮观点：林奇六类公司，散户值得做的只有四种，另外两种要么可被指数基金平替、要么你没有验证能力。

### 第12章 总纲：先分类，再下注——"知不知，上"
- 12.1 林奇的核心洞察：买前先分类，分类决定预期、决定卖法
- 12.2 六类总览与"散户适配度"评分表（本章的重头：一张表说清为什么只教四种）
- 12.3 被砍掉的两类：缓慢增长型（红利指数基金平替之）与隐蔽资产型（需要实地调研能力，散户验不了真假）
- 12.4 不同类型，买卖纪律完全不同（不能拿成长股的卖法卖周期股）
- 12.5 自检：你手里的股票属于哪一类？说不清=不该持有

### 第13章 价值回归：最简单的一招，先学这个
- 经文："知其白，守其黑"——知道它好，等它便宜
- 方法：好公司 + 坏价格 = 机会；PE-Band（估值区间带）的画法与用法
- 30倍PE以下买入、50倍以上警惕；跌了买、热了减
- A股案例：白酒/调味品龙头的三轮完整估值回归复盘
- 反面教材：价值回归≠捡垃圾，"便宜"必须有质量兜底

### 第14章 快速增长型：十倍股长什么样
- 经文："合抱之木，生于毫末"
- 方法：小市值 + 高增长 + 可复制模式；PEG<1的核心逻辑
- A股案例：从某个细分行业（如CXO、扫地机）跑出的三年十倍股解剖
- 反面教材：伪成长的三个特征（增收不增利、靠并购堆收入、赛道拥挤）

### 第15章 困境反转型：别人恐惧时你的机会
- 经文："反者道之动"
- 方法：区分"可逆的困境"（行业出清、政策错杀）与"不可逆的困境"（技术淘汰、造假）
- A股案例：某乳业/某航空的困境反转全过程
- 排雷清单：什么样的便宜不能捡（ST、造假嫌疑、资不抵债）

### 第16章 周期型：最容易让聪明人翻车的类型（选修）
- 经文："祸兮福之所倚，福兮祸之所伏"
- 16.1 周期股本质：供给刚性滞后（蛛网模型），核心看供给不看需求
- 16.2 周期地图：基钦/朱格拉/库兹涅茨/康波嵌套；库存周期四阶段（散户主战场=基钦）
- 16.3 林奇口诀的A股修正："高PE买低PE卖"被数据证伪（PE与价格高低点重合）→ PB Band为主
- 16.4 供给侧仪表盘：能繁母猪领先10~12个月等行业指标表
- 16.5 完整案例：2018-2021猪周期全解剖（股价领先猪价2~3个季度）
- 16.6 五条铁律：不长期持有/不恋战/仓位≤30%/不信"这次不一样"/不懂供给不做
- 红线：周期股不能"长期持有"，不懂不做

### 第17章 组合搭配：四种战法怎么配——"少则得，多则惑"
- 17.1 一个普通人的标准配置：价值回归打底 + 成长进攻 + 反转/周期小仓位试错
- 17.2 配比建议与再平衡节奏（以年度为单位）
- 17.3 什么时候只用一招就够了（资金量<10万的人，先把价值回归练熟）
- 17.4 案例：三种不同性格投资者的四种配比方案

## 第四部分 执行：卖出与仓位（纪律层）

### 第18章 怎么拿住：波动是你的朋友
- 经文："飘风不终朝，骤雨不终日"
- 方法：林奇的"股价下跌≠公司变差"检验三问（基本面变了吗？逻辑变了吗？行业变了吗？）
- 案例：一只好股票一年内的三次腰斩与新高

### 第19章 什么时候卖：比买入难十倍
- 经文："功成身退，天之道"
- 方法：林奇的四个卖出信号（逻辑证伪/估值泡沫/更好标的/公司变质）
- 反例：因为"涨太多了"而卖飞牛股的统计
- 纪律：预设卖出条件单，而不是临场决策

### 第20章 仓位与纪律：持而盈之，不如其已
- 经文："持而盈之，不如其已"——持仓别太满，见好要知道收
- 方法：3~10只的上限逻辑；单一持仓不超过30%；行业不超过3个
- 案例：持有50只基金的"分散幻觉"vs 持有5只真懂的
- 现金仓位：永远留一颗子弹的意义

## 第五部分 修心：不再每天看盘的自由（本书的灵魂）

> 本部分回答全书最贴近读者生活的一个问题：**如何戒掉看盘，把投资从每天的折磨变回每月一次的例行公事？**
> 主线：看盘痛苦的科学解释（行为金融学）→ 信息戒断 → 替代仪式 → 情绪管理 → 大师与道德经的心法收束。
> 本部分开头放一张跨页总表："投资大师心态智慧 × 道德经对照表"——
> 格雷厄姆/巴菲特（市场先生）×"万物并作，吾以观复"｜芒格（误判心理学）×"知人者智，自知者明"｜
> 林奇（波动是朋友）×"祸兮福所倚"｜马克斯（钟摆与周期）×"反者道之动"｜
> 邓普顿（最大悲观点）×"我独泊兮其未兆"｜凯恩斯（动物精神）×"胜人者有力，自胜者强"｜
> 段永平（平常心/不为清单）×"为学日益，为道日损"

### 第21章 看盘的代价：为什么越看越亏（痛苦篇·病因）
- 经文："五色令人目盲，五音令人耳聋"
- 21.1 看盘的生理痛苦是真实的：损失厌恶（卡尼曼）——亏1元的痛感≈赚2元的快感，盯盘=每天反复体验小额损失
- 21.2 随机性的折磨：短期价格像醉汉走路，盯盘者被迫对随机波动持续做"解释"和"反应"，决策质量必然下降
- 21.3 铁证：Barber & Odean《交易有害财富》——交易频率与收益率显著负相关；看盘是交易的近亲
- 21.4 算账：每天看盘2小时 × 250个交易日 = 每年500小时，十年5000小时的机会成本
- 21.5 结论：看盘不是研究，看盘是消费——消费你的时间、情绪和收益

### 第22章 信息戒断：为道日损的实操（痛苦篇·断瘾）
- 经文："为学日益，为道日损。损之又损，以至于无为"
- 22.1 戒断清单：关行情推送、卸载/藏起App、取关大V、退出股票群（全部给出具体操作步骤）
- 22.2 信息分级：只看三类信息——财报、公告、月度行业数据；其余一律视为"噪音配送到家"
- 22.3 工具：一页纸财报速读法（林奇式十分钟看报表），把"研究"压缩到每月一次
- 22.4 戒断反应期：前两周手痒怎么办（替代行为：设固定的每周复盘时段）

### 第23章 看盘仪式：用日历和清单代替盯盘（痛苦篇·替代）
- 经文："治大国若烹小鲜"
- 23.1 设计你的"投资日历"：一年只有12个决策点（每月一次复盘 + 财报季四次精读），其余时间不操作
- 23.2 替代仪式清单：想刷行情时做的五件事（看持仓公司年报、读一本财报、写下一次买入条件……）
- 23.3 自动化的力量：预设条件单/定投计划，让系统代替你的手（"无为"的技术实现）
- 23.4 实验：两周不看盘对照记录（情绪、时间、收益三维对比）——本章的可传播素材

### 第24章 情绪红绿灯：少数必须看盘时刻的护身符（痛苦篇·防复发）
- 经文："致虚极，守静笃"
- 24.1 什么时候必须看盘：设定的复盘日、预设条件单触发、持仓公司出重大公告
- 24.2 情绪红绿灯：绿（平静）正常决策／黄（FOMO、手痒）只减不加／红（恐慌、狂热）48小时只读不动
- 24.3 投资日记法：每天三分钟记录"想做什么、为什么、心情如何"，三个月后发现自己的情绪模式
- 24.4 决策复盘表：每笔交易事前填写（含"如果下跌30%我会___"的事前签约）

### 第25章 最后的对手：你自己（收官，详见初稿）
- 经文："胜人者有力，自胜者强"
- 25.1 心态的三大敌人：贪婪（巴菲特能力圈×"祸莫大于不知足"）/ 恐惧（邓普顿最大悲观点×"众人熙熙"）/ 自负（芒格误判心理学×"自知者明"）——赚钱之后才登场的敌人最危险
- 25.2 段永平的"平常心"与不为清单：中国投资人最纯粹的心法样本
- 25.3 全书收束：投资是修身的道场；道德经第三十三章全文收尾

## 写作规范备忘
