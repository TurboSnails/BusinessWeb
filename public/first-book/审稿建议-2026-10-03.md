# 《正念投资》审稿建议

审阅日期：2026-10-03。依据工作区正文、大纲及部分计算脚本。此为结构与方法审稿，不代表所有公司数字、引语和研报已经逐项核实。未修改正文。

## 总判断

全书最值得保留的主线是：生活目标 → 资金安排 → 配置为主 → 有限额度研究企业 → 按证据执行 → 回到生活。愿望账本、主动资金边界和逻辑卡，能够构成一套连贯的方法。

当前主要问题是内容成熟度不均衡：市场地图和回测较详尽，企业研究与三种选股方法仍偏提纲。正文已有约十万字符量级，但不能据此认为接近十五至二十三万字的出版目标。下一轮应先完善证据、案例和流程，再润色扩写。

## 一、优先修正：影响可信度或实际执行

### 1. 第9章：跨市场回测的年化口径

`附件-数据/ref_plan.py` 取五个市场共同日期，然后用 `len(r)/243` 计算年数。原始共同日期从2020-07-27至2026-09-30，1416个收益观测被算成5.827年，实际经过约6.177年。

表中期末资产1.520，按实际期限换算年化约7.01%，不能沿用7.5%。这里仅用已四舍五入的期末值作复核，最终应按脚本完整精度重算。波动率也不能直接沿用243倍年化而不说明观测间隔。

建议：CAGR用实际日期；组合回撤用各市场交易日并集、非交易日保持已有估值，明确汇率和时区；跨市场相关性用统一月末数据。股息、债券利息、汇率和产品费用分别注明。第9章相关系数称为月度，但该脚本输出日度；若有另一脚本，必须明确引用。

### 2. 第13、28章：事后盈利与当时可知估值分开

“年末价格÷当年全年EPS”可以描述事后的价格与盈利分解，但该年年报通常尚未在年末公布。第28章用同样算法教读者画历史PE区间，容易形成前视偏差。

建议保留事后分解，但明确标为“事后全年盈利口径”；历史买卖案例使用当时已披露的TTM、上一年度静态EPS或当时公开的预测，并写明披露日期。2021年EPS优先查年报，不宜用净利润增速反推后作为精确历史基础。

### 3. 第22章：反向DCF的企业价值与市值混用

例子先算“企业价值”，随后用“市值1500”反推增长，尚未交代净债务。若采用FCFF，先把市值加净债务转成企业价值；若采用FCFE，全程使用股权价值和股权资本成本。教学简化也应明确“假设净债务为零”。

### 4. 第32章：指数负收益不等于账户亏损

表格统计不重叠区间的指数涨跌，却写成“打开账户看到亏损的概率”。账户累计盈亏还取决于买入日期、现金流、持仓和成本；这组数据也没有测量实际情绪。

建议改成“不同观察间隔内，指数出现负收益的历史比例”。“红色亏损”也不适合A股常见红涨绿跌界面。关于少看账户减少情绪负担，另引行为研究或用明确标注的行为示例，不由价格数据直接推出。

### 5. 第33章：中位数、均值与事前识别

表中19.4%是随后收益中位数，正文却写“平均会错过19.4%”。应改为“该样本随后收益的中位数为19.4%”，也不能等同于真实投资者卖出后的损失。

“事前不知道自己买的是哪一种”不准确：指数名称事前已知，未知的是未来会经历哪种行情。应改成“历史上不同指数结果不同，未来也未必重复”。

### 6. 第34章与附录D：仓位分母和损失边界

附录D“仓位上限30%”没有分母，可能被理解为总资产30%，与主动额度20%、单股4%—5%发生冲突。明确它是主动额度内的比例还是另有安排；若前者，按20%主动额度换算是总额6%，仍需服从单股、行业和相关风险上限。

第34章“即使判断完全错了，也不会伤到整体”过强。5%仓位下跌50%拖累2.5%，归零则拖累5%；多个持仓共同下跌可能叠加。改成“限制单个标的对组合的直接损失贡献”，并补一个相关风险案例。

### 7. 第35章：冷静期不得覆盖必要风险处理

“红灯48小时不允许操作”与第32、37章风险触发后及时行动存在冲突。改成暂停临时、冲动的新交易；事先约定的风险处置、资金核对和必要用款处理继续执行。

该章仍有旧稿残留：“四类”与主战法三类不符；“前面三十四章都是战胜市场”与配置主线不符。年度收益、适当基准、费用、回撤、判断错/执行错/运气差等大纲要求尚未充分落实。

### 8. 附录D：应重新审证据，再开放给读者

这一附录的确定性明显高于正文，包括“口诀被数据证伪”“三选二即执行”“下一轮不会复制”等。文中的“有人系统回测过”没有提供可复核样本和方法，不能支撑普遍结论。

建议逐条核对研报原文、页码、样本和时间区间；母猪存栏数字需核对统计口径和对应日期；领先期写成历史样本中的范围。营收和存货还受价格、收购、季节性及会计因素影响，不能仅凭两科目同比方向自动确定买卖。PB不是通用的周期股操作轨道。

### 9. 第16章与附录F：人物和书籍引用

第16章“史上最强”“前无古人”、基金66%/39%和巴菲特约20%的对照，需要统一期限、费用、资金条件与出处。机构成绩不能证明普通人不做宏观预测就能获益。

附录F将《战胜华尔街》标为 One Up on Wall Street，书籍对应混淆。出版社分别列有 One Up on Wall Street 与 Beating the Street：

- https://www.simonandschuster.com/books/One-Up-On-Wall-Street/Peter-Lynch/9780743200400
- https://www.simonandschuster.com/books/Beating-the-Street/Peter-Lynch/9780671891633

中文译名和页码按实际采用的合法版本统一。第33章“四个卖出信号”既然是本书归纳，标题也应表明归纳性质。大师原话、作者转述和作者延伸解释需明确区分。

## 二、结构优化：让主要读者更早得到可用的方法

1. 在开篇后增加两页“怎样读、第一周做什么”：生活资金 → 可投资资金 → 配置路线或研究路线。大纲已有路线图，应进入读者实际阅读入口。
2. 第一部分保留地图功能，压缩人物和策略罗列。第6章的大矩阵和详细回测可放专栏或附录，正文只保留环境判断如何影响主动额度、如何不影响底仓规则。
3. 第12—15章减少反复说明中长线优点，集中回答研究依据、资金期限、持有方式和退出方式。不用“普通人的最优解”概括所有人。
4. 第19—22章应成为主干。现在产业、公司章都只有约一千余字符，读者知道该问什么，却还不知道怎么查、怎么判断。
5. 第25章未来产业作为选读或定期更新内容；核心工具先讲清楚。第26章“美女公司”建议改为“建立公司判断力”或“建立公司观察库”，使标题准确传达内容。
6. 第36—38章可以简短，保留生活收束。无需为了统一篇幅扩到每章4000—6000字。

## 三、最值得补充的内容

### A. 一个贯穿全书的研究案例

选一家有完整公开资料的历史公司，逐章展示：产业地图 → 生意模式 → 财报 → 估值 → 投资分类 → 仓位 → 跟踪 → 卖出 → 复盘。每一步限制在当时已公开的信息，并展示真实的不确定性。

贯穿案例降低重复讲解成本。另配失败案例和最终决定“不买”的案例，避免读者把研究流程理解为寻找买入理由。

### B. 三种战法各补一次完整决策

第28章目前主要展示估值压缩；第29章展示盈利变化；第30章尚无实证案例。它们没有完整演示各自的方法如何执行。

统一案例格式：观察日期、已知信息、当时估值、买入/不买依据、反对证据、仓位限制、跟踪指标、退出触发、含分红费用的结果、可能做错的地方。不必每章机械凑“2正1负”，但每种核心方法至少需要完整成功与失败对照。

### C. 财报和估值的实际操作

补充在哪里找到原始报告、如何核对合并口径、归母与扣非利润、经营现金流与自由现金流。用具体数值完成一份财报清单，而不是只给空模板。

估值补一个增长放缓、估值中枢永久下降的案例；PEG给出不同增长假设下的结果。困境反转增加现金消耗、到期债务、受限现金和融资稀释的教学测算。

### D. 家庭资金入口

明确“参考总额”的定义：是否包含备用金，是否扣除短期负债，哪些资产可投资。第7、9、15章统一分母和用词。

愿望账本区分“当前工资帮助积累本金”和“停止工作后仍持续的收入”。退休目标不能用未来不再领取的工资抵扣支出缺口。

### E. 执行异常和年度复盘

补充定投失败、产品暂停、跨境溢价过高、再平衡无法成交、新增资金和临时提款的处理示例。

年度复盘明确区分有现金流时的资金回报和策略回报；主动部分与预先选择的基准比较，并记录费用、最大回撤、维护时间。停止主动研究的条件不能仅用几次亏损判断，应结合过程质量与足够观察期。

## 四、表达修改示例

| 原表述 | 建议方向 |
|---|---|
| 不预测未来 | 不依赖短期行情预测；企业研究仍需要假设，并按事实修订 |
| 困境反转的逻辑是物极必反 | 困境存在可验证的缓解路径，且公司有能力撑到改善 |
| 好公司遇上坏价格 | 好公司遇上低于合理估值区间的价格；“坏价格”容易被理解为买贵 |
| 技术三天能学会 | 框架可以较快理解，判断与执行需要长期练习 |
| 增收不增利就是伪成长 | 先检查投入阶段、价格、产品结构和持续性，再判断增长质量 |
| 半仓网格是固定比例再平衡 | 按价格触发的仓位调整；与按目标权重触发的再平衡有相似处，但规则不同 |

道德经宜作思考的引子，解释标明是本书借用，不承担证明方法有效的任务。减少“唯一”“必然”“无一例外”等句式；免责声明不能替代证据和适用条件。

## 五、建议修订次序

1. 修正年化、历史信息时点、DCF口径、统计解释、仓位分母和风险处置冲突。
2. 建立数字与引用核对表：章节、论断、原始来源、页码或公告日期、计算脚本、核验状态。
3. 补第19—22、28—30、33、35章的完整演示。
4. 整合逻辑卡、估值卡、仓位卡和复盘表，减少读者重复填写。
5. 压缩重复内容、统一书名术语，清除编辑备忘与待补标记，再同步网页版本。

下一轮衡量完成度的标准：读者能否从一笔生活之外的钱出发，完成一份可复核、可执行、可认错的投资方案。
