# 资产基础：每类资产赚什么，怕什么？

> 本专题一句话：先看收益来源、损失机制和兑现条件，再决定它在家庭资金中的用途。

本专题接第7章。资产类别与基金产品分开理解：债券和债券基金、黄金与黄金ETF，都不是完全相同的付款安排。第10章再比较实际产品。

## 资产.1 现金：先确认能否按时支付

现金类安排的首要任务是付款与流动性。余额看起来稳定，不意味着可以忽略购买力下降、冻结限制、提前支取条件或赎回时间。

假设本金100元、年收益1%、物价上涨3%，一年后购买力相对变化为1.01÷1.03−1≈−1.94%。名义余额增长，购买力仍下降。这是教学算术，不是实际利率或通胀预测。

存款、货币基金和其他现金管理产品，应分别核对合同、底层资产与退出条件。不能把显示日收益或历史净值平稳直接当作本金保证；具体保障与规则查产品原文，不混用。

林家的8万元确定支出和12.6万元应急储备，先要求在付款时可用。为了多一点收益延长锁定期，需要先解释付款如何覆盖。

## 资产.2 债券：利息与本金都依赖条件

债券通常按合同支付利息与到期本金，投资者还承担发行人不按约付款、利率变化、提前偿还与转售不畅的风险。[Investor.gov债券说明](https://www.investor.gov/introduction-investing/investing-basics/investment-products/bonds-or-fixed-income-products/bonds)介绍了这些基本条件。

若市场要求的收益率上升，既有固定付款的债券价格可能下降。假设修正久期为5，收益率上升1个百分点，忽略凸性等影响，价格变化可粗估为−5%。这只是小幅变化下的近似，不是承诺。概念说明见[FINRA久期说明](https://syndication.finra.org/content/duration-what-interest-rate-hike-could-do-your-bond-portfolio)。

单只债券的到期安排与普通开放式债券基金不同：基金可能持续换券，没有一个“到期全额还给你”的统一承诺。[债券基金风险说明](https://www.investor.gov/introduction-investing/investing-basics/glossary/bond-funds-and-income-funds)也列出信用、利率与提前偿还风险。

看债基至少查债券类别、久期、信用暴露、杠杆、集中度和赎回条件。“纯债”描述投资范围，不能单凭名称认定没有亏损；债券指数历史低波动也不能直接替代产品风险分析。

## 资产.3 股票：经营结果还要经过价格

股票持有人分享企业价值，但经营利润、分红与股票价格是不同项目。利润留在公司再投资是否有价值，要看资本回报；股东得到的每股份额，也会受增发等事项影响。

在无送转等股本变化的简化情况下，一段持有的总回报可从卖出价格、现金分红与成本计算。假设100元买入、90元卖出、收到3元分红，未计税费时总回报为−7%，不是只看价格的−10%。

宽基基金降低对单家公司结果的依赖，仍有整体估值、行业集中和市场下跌风险。红利与低波动指数也是股票资产，不能因为名称平稳就自动划入生活备用金。

## 资产.4 黄金：没有企业利润表的资产

黄金本身不产生企业经营利润或合同利息。持有结果取决于价格变化与费用；黄金ETF还要查跟踪方式、底层持有安排和交易条件。

黄金可以成为不同风险来源的一部分，但不能预设每次股市下跌它都会上涨，也不能把通胀担忧直接换算成固定黄金收益。林家压力情景中黄金也下跌，就是为了检查这种预设。

若买黄金相关股票，其结果还依赖企业成本、矿产经营、负债与治理，不等同于黄金价格。商品资产与相关企业要分别研究。

## 资产.5 境外资产：计价货币不等于风险货币

人民币购买基金，不证明底层已经没有汇率风险。要看资产和负债的币种，以及产品是否采取汇率对冲、如何执行和收费。

假设境外资产以外币上涨10%，同期间外币对人民币贬值8%，忽略分红、费用与对冲，人民币回报为1.10×0.92−1＝1.2%。不能直接用10%减8%，也不能只看境外指数。

国内指数与境外指数的比较，要统一币种、分红、费用与观察期间。否则看起来更好的年化，可能来自口径差异。

## 资产.6 分散：找共同风险，而不只数产品

| 林家的暴露 | 可能的共同冲击 | 应继续核查 |
|---|---|---|
| 工资与主动股票同属制造行业 | 行业订单收缩，同时影响收入与投资 | 行业敞口、储备期限 |
| 多只同指数基金 | 同一篮子公司共同下跌 | 合并底层权重 |
| 股票与债券类基金 | 利率或融资冲击可能共同影响 | 久期、信用与权益暴露 |
| 境外权益与外币现金 | 汇率变化影响人民币价值 | 支出币种、对冲与费用 |

历史相关系数是某个样本中的描述，不是未来对冲合同。不能凭一段历史里接近1的相关系数，推出两个资产每天都同涨同跌；也不能凭过去接近零，保证未来一定有缓冲。引用相关系数时，必须同时写明频率与起止日（口径见附录F）。

第7章压力计算把几类资产同时下跌，意在检查现金余地；第33章继续汇总主动股票共同风险。组合可以减少某些风险，也可能留有集中与流动性风险。

## 资产.7 选资产时交付什么

| 判断项目 | 必须能解释的内容 |
|---|---|
| 收益来源 | 利息、经营、分红或价格变化 |
| 损失机制 | 违约、估值、利率、汇率或无法兑现 |
| 资金匹配 | 最早用款日能否满足，损失能否承担 |
| 产品传递 | 产品怎样持有资产，有哪些额外费用和约束 |
| 共同风险 | 与其他持仓及工资、负债是否相关 |

把结论接回第7章资金表和第37章决策记录。金融品种的名字不是用途：一项资产适不适合，取决于这笔钱的任务与产品实际条件。

**练习**：某境外资产外币收益−10%，外币对人民币升值5%，人民币结果是多少？

**核对**：0.90×1.05−1＝−5.5%，未计其他事项。汇率缓冲了一部分跌幅，没有把损失自动变成盈利。
