# 小说与写作 Skills 使用说明

| 文件夹 | 名称 | 适合的任务 |
| --- | --- | --- |
| novel-editor | 长篇连载总编 | 开书规划、世界观与角色、大纲、续写、事实账本、伏笔与一致性审查，也支持短篇和局部润色 |
| literary-writing-mentor | 纯文学写作领路人 | 中文短篇与中篇的结构、意象、人物、叙事声音诊断，语言打磨、评分与版本比较 |
| tomato-novel-coach | 番茄小说创作教练 | 选题、书名简介、黄金三章、情绪兑现、章节钩子、连载节奏与阅读数据诊断 |

## 安装与使用

1. 下载单套 ZIP 或写作合集，解压后保留完整 Skill 文件夹，包括 `SKILL.md`、`references/` 和 `agents/`。
2. 将文件夹放进项目的 `.agents/skills/`（Codex）、`.claude/skills/`（Claude Code）或 `.opencode/skills/`（OpenCode）。这些包来自本机 Codex 安装版本，其他助手使用时按实际工具能力执行。
3. 重新打开会话，提问时指定 Skill 名称，提供创作目标、设定或稿件；修改已有作品时说明修改范围。
4. 小说正文、事实账本和版本记录保存在作品项目中，不放入 Skill 方法库。

## 示例

- 用 novel-editor 检查前五章的人物状态、时间线和伏笔，指出矛盾位置并给出修改方案。
- 用 literary-writing-mentor 阅读这篇短篇小说，依据原文选出三件最值得修改的事。
- 用 tomato-novel-coach 为都市悬疑小说设计书名、简介和前三章细纲。

## 资料范围

下载包保留当前已安装版本的全部文件与来源说明。长篇连载总编的方法资料与小说项目状态分开维护；遇到源资料缺失，按包内 Codex 适配说明回退。

番茄教练的来源资料含 01–05 篇完整内容、第 06 篇开头及迁移补充的创作流程，**不是完整 48 篇资源库**。现行平台政策、投稿要求和收益规则需要核实官方最新信息。

这些 Skill 用于辅助创作和编辑，不保证录用、签约、爆款或收益。上传、发布和投稿需用户另行授权。

## 项目内重新打包

在 BusinessWeb 目录执行 `python3 scripts/package-writing-skills.py`。默认读取本机 `~/.codex/skills/`；其他来源目录可通过 `--source /path/to/skills` 指定。
